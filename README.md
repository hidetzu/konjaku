# 今昔 — この土地は、昔なんだったのか？

[![検査](https://github.com/hidetzu/konjaku/actions/workflows/check.yml/badge.svg?branch=main)](https://github.com/hidetzu/konjaku/actions/workflows/check.yml?query=branch%3Amain)

場所を指すと、その土地が昔なんだったかを国土地理院の資料から判定し、
読んだ資料とともに表示するウェブサービスです。

**[今昔を開く](https://konjaku.hidetzu.work/)**

![今昔の画面](public/ogp.png)

## できること

- 地名・駅名・施設名から場所を探す
- **その場所が昔なんだったかを、見出しで答える**
  - 明治期の地図に区分があれば、それが見出しになります（「ここは 河川・湖沼・海面 でした」）
  - 資料が無いときは、無いと書きます。⚠ **「無い」と「読めなかった」を分けます**
- 明治期から現在までの空中写真を年代順に見る（その地点に残っているぶんだけ）
- **なぜそう言えるかを開く** — 読んだ資料・区分コード・限界
- 気になった場所を保存し、別の端末で続きを読む（合言葉で受け渡し）
- **深掘り**（`/deep`）— 年代ごとの変化、成り立ちと起こりうること、
  この一帯はどうだったか、近くに残る災害の記録、この画面が読んだ資料

Google マップが「いま、そこに何があるか」に答えるのに対し、
今昔は「そこがどういう土地なのか」に答えます。

## 大切にしていること

### 根拠を表示する

判定はブラウザが国土地理院のタイルを読み、画素から行います。
読んだ資料、区分コード、判定に使ったタイルと画素、既知の限界を確認できます。

### 取れなかったことを「無い」と言わない

取得結果を「読めた」「本当に無い」「通信などで読めなかった」に分けます。
読めなかったときは断定せず、根拠を表示せず、再試行できるようにします。

### 原典の字を、そのまま出す

成り立ちと起こりうること、災害伝承碑の災害名・種別は、
国土地理院の記述のまま表示します。要約も言い換えもしません。

### 場所をこちらへ送らない

Cookie も利用者識別子も使いません。**誰がどこを見たかは数えていません。**
判定はブラウザ内で完結します。

こちらのサーバへ送るのは、**別の端末で見るために自分でボタンを押したときだけ**です。

ただし、調べた場所はブラウザのアドレス欄（URL）に入ります。
その URL を開くと、アドレスの一部として配信元（Cloudflare）に届きます。
こちらの記録には残りません。

詳しい仕様と限界は [`docs/SPEC.md`](docs/SPEC.md) を参照してください。

## 開発・貢献

ローカルでの起動、検査、Issue・PRの手順は
[`CONTRIBUTING.md`](CONTRIBUTING.md) を参照してください。

⚠ **このバッジが見ているのは `main` の静的検査・実描画・検索の並びです。**
⚠ **外部リンクの生死は含みません**（相手先の一時的な不調でこちらを止めないため、
到達できなくても緑のままになります）。リンクが腐っていないかは実行ログを見てください。
検査が何件走ったかは、走らせると走者自身が名乗ります（`docs/SPEC.md` には書きません）。

## 主なデータ

- **国土地理院** — 地形分類、明治期の低湿地、標高、年代別空中写真、住所検索、
  逆ジオコーディング、自然災害伝承碑
- **国土交通省** — 土地利用細分メッシュのコード表
- **東京都港湾局／浦安市** — その地域について公式資料に書かれている記録

出典、加工物、個別の利用条件は [`LICENSES.md`](LICENSES.md) にまとめています。
