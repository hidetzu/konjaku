## 1. 誰が何を持つか

```text
┌─ 端末（画面）──────────────┐        ┌─ サーバ（Worker + D1）──────┐
│ 同じ場所か（50m）           │        │ 誰のものか（Google の sub）  │
│ どう混ぜるか                │  HTTP  │ 預かる                       │
│ いつ混ぜるか                │ ←──→  │ 返す                         │
│ 画面に出す言葉              │        │ ⚠ 判断しない                 │
└─────────────────────────────┘        └──────────────────────────────┘
```

- MUST: ⚠ **サーバは、⚠ 記録の中身で振る舞いを変えない。**
  ⚠ **`name` が空でも、⚠ `value` を知らなくても、⚠ そのまま預かる。**
- MUST: ⚠ **端末は、⚠ サーバが返した行をそのまま画面へ出さない。**
  ⚠ **`KonjakuSaved.merge` を通してから出す。**

## 2. 記録の形

⚠ **正本は [`../public-next/saved.js`](../public-next/saved.js)。**⚠ **ここは写し。**
⚠ **食い違ったら `saved.js` が正**（⚠ 検査が突き合わせる）。

```jsonc
{
  "id":    "01J...",       // ⚠ 端末が作る。保存した瞬間に決まり、二度と変わらない
  "lat":   35.65531,       // ⚠ 5 桁（およそ 1m）
  "lon":   139.79672,
  "name":  "東京都江東区豊洲三丁目",  // ⚠ 取れなかったときは null（"" にしない）
  "value": "旧水部",                  // ⚠ 足元の区分。⚠ 取れなかったときは null
  "at":    1756400000000   // ⚠ 保存した時刻（端末の時計）
}
```

- MUST: ⚠ **`id` を座標から作らない。**⚠ **座標は動く**（⚠ 同じ場所を別の端末で押すとずれる）。
- MUST: ⚠ **`null` と `""` を分ける。**⚠ **`null` は「取れなかった」。**⚠ **`""` は使わない。**
- MUST NOT: ⚠ **`gloss`（画面に出す文）を送らない。**⚠ **言葉は端末が作る**（`.claude/rules/domain.md`）。

## 3. 口（4 つ）

⚠ **すべて `konjaku-next` の下。**⚠ **静的配信と同じ生地に足す**（⚠ 別の Worker を建てない）。

| 口 | 何をするか | ログイン |
|---|---|---|
| `GET /auth/start` | Google へ送り出す。`state` を発行する | 不要 |
| `GET /auth/callback` | 戻りを受ける。session を張る | 不要 |
| `GET /api/places` | その人の行を全部返す | ⚠ **要** |
| `POST /api/places` | 行を預ける（⚠ 足すだけ） | ⚠ **要** |

### `GET /api/places`

```jsonc
// 200
{ "places": [ { "id": "...", "lat": 35.65531, "lon": 139.79672,
                "name": null, "value": "旧水部", "at": 1756400000000 } ] }
```

### `POST /api/places`

```jsonc
// 送る
{ "places": [ /* 上と同じ形。⚠ 1 回 200 件まで */ ] }
// 200
{ "stored": 12, "already": 3 }   // ⚠ 足した数と、⚠ 既にあった数
```

- MUST: ⚠ **同じ `id` を 2 回送っても、⚠ 行は増えない。**⚠ **エラーにもしない。**
- MUST: ⚠ **知らない鍵は落とす。**⚠ **落としたことをエラーにしない**（⚠ 端末が先に進むことがある）。

### 失敗の返し方

⚠ **ここが掟に直接触る**（`CLAUDE.md` §1）。⚠ **「取れなかった」と「無い」を、⚠ 別の形で返す。**

| 事態 | 返す | ⚠ 端末が出す言葉（案。⚠ Owner 判断が要る） |
|---|---|---|
| ログインしていない | `401 {"error":"no_session"}` | ⚠ **「まだつないでいません」**（⚠ 「無い」と言わない） |
| 預かれなかった | `503 {"error":"store_unavailable"}` | ⚠ **「いまは預かれませんでした。この端末の保存はそのままです」** |
| 形が違う | `400 {"error":"bad_shape","at":"places[3].lat"}` | ⚠ **画面には出さない**（⚠ こちらの不具合） |

- MUST NOT: ⚠ **「0 件」と「取れなかった」を、⚠ 同じ返しにしない。**
  ⚠ **`{"places":[]}` は「預けたものが 1 件も無い」。**⚠ **読めなかったときは 200 を返さない。**

## 4. どこで切るか（⚠ 触るファイルが重ならないようにする）

```text
サーバ側（B）                        端末側（A）
  worker-next.js                       public-next/saved.js      ⚠ id を足す
  wrangler.next.jsonc                  public-next/top.js        ⚠ 導線と混ぜ方
  migrations/*.sql                     public-next/index.html
  test/check/sync-server.mjs           public-next/top.css
                                       test/check/saved.mjs
                                       test/render/next.mjs
```

- MUST: ⚠ **同じファイルを 2 人で触らない。**⚠ **重なるのは `docs/` と、⚠ この文書だけ。**
- MUST: ⚠ **`public/`（β 版）には、⚠ どちらも触らない**（[`adr/0050`](<adr/0050-v0.1.0 は別の Worker で作り、β 版に触らない.md>)）。
- MUST: ⚠ **`wrangler.next.jsonc` に `main` と D1 を足すのは B。**
  ⚠ **A は触らない**（⚠ 競合すると CI が走らなくなる）。

## 5. 待たずに進むための偽のサーバ

⚠ **A は、⚠ B の実装を待たない。**⚠ **契約どおりに答える偽のサーバを、⚠ 検査の中に持つ。**

```text
test/render/sync-stub.mjs     ⚠ 上の 4 つの口を、⚠ 契約どおりに返すだけのもの
test/check/sync-contract.mjs  ⚠ 偽と本物の両方へ、⚠ 同じ主張を当てる
```

- MUST: ⚠ **偽と本物を、⚠ 同じ検査で突き合わせる**（`CLAUDE.md` §3）。
  ⚠ **偽だけに通る実装は、⚠ 本物では動かない。**
- MUST: ⚠ **契約を変えるときは、⚠ この文書と検査を先に直す。**⚠ **実装より先。**
