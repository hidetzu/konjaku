⚠ **これは「どこで切るか」を決める文書。**⚠ **判断の理由は
[`adr/0072`](<adr/0072-端末をまたぐのは引換券にし、アカウントを作らない.md>)と
[`adr/0071`](adr/0071-同期は判断を端末に置き、サーバは足すだけの箱にする.md)。**⚠ ここには書かない。
⚠ **何が言えるかは [`SPEC.md`](SPEC.md)、⚠ どう作業するかは [`../CLAUDE.md`](../CLAUDE.md)。**

⚠ **この契約が固まっていれば、⚠ 2 人が相手を待たずに進められる。**
⚠ **固まる前に書き始めると、⚠ 必ず片方が作り直しになる。**

## 1. ⚠ サーバは中身を読まない

```text
┌─ 端末（画面）──────────────┐        ┌─ サーバ（Worker + D1）──────┐
│ 何を保存するか              │        │ 荷物を預かる                 │
│ どう詰めるか                │  HTTP  │ 合言葉を出す                 │
│ 同じ場所か（50m）           │ ←──→  │ 期限を見る                   │
│ どう混ぜるか                │        │ 返す／消す                   │
│ 画面に出す言葉              │        │ ⚠ **中身を読まない**         │
└─────────────────────────────┘        └──────────────────────────────┘
```

⚠ **端末が渡すのは、⚠ 1 本の字**（`payload`）。⚠ **サーバはそれを預かって返すだけ。**

### ⚠ `payload` の中身は、⚠ 保存した場所そのもの

⚠ **ここを取り違えない。**⚠ **「サーバは中身を読まない」は、⚠ 「座標を送らない」ではない。**

```text
⚠ 送っている    緯度・経度・町名・足元の区分・保存した時刻   ⚠ 保存した件数ぶん全部
⚠ 置いている    期限が来るまで、⚠ D1 の 1 行の中に
⚠ していない    サーバのコードが、⚠ その中を解いて読むこと
```

⚠ **`payload` は、⚠ `toText` が「詰めて・圧縮して・base64url にした字」。**
⚠ **圧縮は隠すためではない**（⚠ 誰でも解ける。⚠ 短くするためだけ）。
⚠ **預かっているあいだ、⚠ その人が歩いた場所は、⚠ こちらのサーバに在る。**

- MUST: ⚠ **画面でそう言う。**⚠ **「◯分で消えます」だけでなく、⚠ 何を預けるのかを言う**
  （[`adr/0045`](<adr/0045-最小体験に「別の端末で続きから」を足す.md>) の表。
  ⚠ **「こちらに 1 件も残らない」は、⚠ 預けているあいだは言えない**）。
- MUST NOT: ⚠ **「サーバは中身を読まない」を、⚠ 安全の説明に使わない。**
  ⚠ **これは作りの話**（⚠ 同じ判断を 2 か所に持たないため）。⚠ **秘密にしている話ではない。**

### ⚠ 読まないと何が良いか

- MUST: ⚠ **サーバは `payload` を解釈しない。**⚠ **形が変わっても、⚠ サーバは直さない。**
- MUST: ⚠ **`payload` の作り方・読み方は
  [`../public-next/saved.js`](../public-next/saved.js) の `toText` / `fromText` の 1 か所**
  （⚠ 既に在る。⚠ 手渡しの URL で使っているものと同じ）。
- MUST: ⚠ **端末は、⚠ 受け取った `payload` を `KonjakuSaved.merge` に通してから画面へ出す。**

⚠ **この形にすると、⚠ サーバ側の人は「50m」も「座標の桁」も一度も考えなくてよい。**

## 2. 口（2 つ）

⚠ **`konjaku-next` の下に足す。**⚠ **静的配信と同じ生地。**⚠ **別の Worker を建てない。**

| 口 | 誰が | 何をするか |
|---|---|---|
| `POST /api/handoff` | スマホ | 荷物を預け、⚠ **合言葉を受け取る** |
| `GET /api/handoff/{合言葉}` | PC | ⚠ **荷物を取り出す**（⚠ 期限内なら何度でも） |

### `POST /api/handoff`

```jsonc
// 送る
{ "payload": "2H4sIAAAA…" }          // ⚠ 保存した場所の一覧を、⚠ toText が詰めた字
                                     // ⚠ 中身: [[緯度, 経度, 町名, 区分, 時刻], …]
                                     // ⚠ 先頭 1 文字が版（1 = 生、2 = 圧縮）
// 200
{ "code": "K7QM3XVR",                // ⚠ 合言葉。⚠ 8 文字
  "expires_at": 1756400300000,       // ⚠ ミリ秒。⚠ 画面はここから残り時間を出す
  "ttl_sec": 300 }                   // ⚠ 使える長さ。⚠ 画面の文はここから作る
```

- MUST: ⚠ **`ttl_sec` を返す。**⚠ **画面に「◯分で消えます」を直書きしない**
  （⚠ 設定を変えたとき、⚠ 画面だけ前の数字のまま残る。`CLAUDE.md` §3）。
- MUST: ⚠ **合言葉がぶつかったら、⚠ 出し直す**（⚠ D1 の一意制約に任せて、⚠ 失敗したら再試行）。

### `GET /api/handoff/{合言葉}`

```jsonc
// 200
{ "payload": "2H4sIAAAA…", "expires_at": 1756400300000 }
```

- MUST: ⚠ **期限内なら何度でも返す。**⚠ **取り出しても消さない**（2026-08-29。Owner 判断）。
  ⚠ **PC とタブレットの両方に入れたい人が居る。**⚠ **個人の情報は預かっていないので、
  ⚠ 1 回きりにする理由が無い。**
- MUST: ⚠ **期限が切れているのを見つけたら、⚠ その場で消して `410`**（2026-08-29。Owner 判断）。
  ⚠ **消すので、⚠ 2 回目からは `404` になる。**⚠ **これは仕様であって不具合ではない。**
- MUST: ⚠ **だから `404` の字を「打ち間違い」だけにしない**（⚠ 下の表）。
  ⚠ **期限切れの 2 回目も `404` に来る。**⚠ **「打ち間違いです」と言い切ると、
  ⚠ 切れただけの人に嘘を言うことになる**（`CLAUDE.md` §1）。
- MUST: ⚠ **大文字と小文字を区別しない。**⚠ **`-` と空白は落としてから照合する**
  （⚠ 画面がそう言っている）。

### 失敗の返し方

⚠ **ここが掟に直接触る**（`CLAUDE.md` §1）。⚠ **「無い」と「切れた」を、⚠ 別の形で返す。**

| 事態 | 返す | ⚠ 画面が出す言葉（⚠ 正本は `adr/0072`） |
|---|---|---|
| 期限が切れていた（⚠ 1 回目） | `410 {"error":"expired"}` | ⚠ **期限が切れています／スマホで出し直すと新しく出ます** |
| 合言葉が無い（⚠ 打ち間違い ／ ⚠ 期限切れの 2 回目） | `404 {"error":"not_found"}` | ⚠ **この合言葉は使えません／期限が切れたか、打ち間違いかもしれません／出し直すと新しく出ます** |
| 試しすぎ | `429 {"error":"too_many","retry_after":60}` | ⚠ **しばらく待ってから、もう一度** |
| 荷物が大きすぎる | `413 {"error":"too_large"}` | ⚠ **件数が多くて渡せません** |
| 預かれなかった | `503 {"error":"store_unavailable"}` | ⚠ **いまは預かれませんでした。この端末の保存はそのままです** |

- MUST NOT: ⚠ **`410` と `404` を同じ字にしない。**⚠ **`410` は「切れた」と言い切れる。**
  ⚠ **`404` は言い切れない**（⚠ 打ち間違いと、⚠ 期限切れの 2 回目が、⚠ 同じところへ来る）。
  ⚠ **分けると「その合言葉は在った」ことが総当たりする側にも伝わる**が、
  ⚠ **試行回数を制限する前提で、⚠ 利用者に分かるほうを採る**（`adr/0072`）。
- MUST: ⚠ **どちらの字にも「出し直すと新しく出ます」を入れる。**
  ⚠ **どちらの事態でも、⚠ 利用者がすべきことは同じ**（⚠ 打ち直しても、⚠ 切れていれば通らない）。
- MUST NOT: ⚠ **読めなかったときに `200` を返さない。**⚠ **空の荷物は「0 件を預けた」の意味。**

## 3. 合言葉

```text
長さ    8 文字
使う字  ⚠ **紛らわしい字を抜いた 32 文字**（⚠ 0/O・1/I/L・U を使わない）
```

⚠ **実測ではなく計算**（2026-08-29）。

```text
組み合わせ  1,099,511,627,776 通り（⚠ 40 ビット相当）
同時に 1000 本生きているとき、次の 1 本がぶつかる確率   9.09e-10
総当たりを 1 万回やって当たる確率                       9.09e-06
```

- MUST: ⚠ **試行回数を制限する**（[RFC 8628](https://www.rfc-editor.org/rfc/rfc8628) が名指しで求めている）。
  ⚠ **上の数字は、⚠ 制限が在ることを前提にしている。**
- MUST: ⚠ **合言葉そのものを D1 に置かない。**⚠ **ハッシュを置く。**
- MUST NOT: ⚠ **通し番号にしない。**⚠ **時刻から作らない。**

## 4. 期限と掃除

```text
既定        ⚠ 5 分（2026-08-29。Owner 判断）
変え方      ⚠ **環境変数で変えられるようにする。**⚠ 画面もサーバも
判定        ⚠ **API で見る。**⚠ 取り出すときに期限を見て、⚠ 切れていたら消して 410
掃除        ⚠ **Cron は最初は置かない。**⚠ 必要になってから
```

### ⚠ 「消えます」と言わない

⚠ **取りに来なかった荷物は、⚠ 期限が切れても行が残る**（⚠ 消す機会が来ない）。
⚠ **Cron を置かないと決めた以上、⚠ 「◯分で消えます」は言えない**（`CLAUDE.md` §1）。

```text
⚠ 言える    ⚠ **「5 分で使えなくなります」**
⚠ 言えない  ⚠ 「5 分で消えます」   ← ⚠ Cron を置くまでは嘘になる
```

- MUST: ⚠ **画面は「使えなくなります」と言う**（2026-08-29。Owner 判断）。
- SHOULD: ⚠ **書き込みのついでに掃除する**（⚠ `POST` の中で、⚠ 期限切れを少しだけ消す）。
  ⚠ **Cron を置かずに、⚠ 実際に減る。**⚠ **ただし「必ず消える」保証にはならない**
  （⚠ 発行が止まれば残る）。⚠ **だから上の言い方は変えない。**
- MUST: ⚠ **期限の判定を、⚠ 掃除に頼らない。**⚠ **掃除が動かなくても、⚠ 期限切れは使えない。**
- MUST: ⚠ **画面は `ttl_sec` から文を作る。**⚠ **数字を 2 か所に持たない。**
- MUST NOT: ⚠ **最初から Cron を置かない。**⚠ **要るかどうかは、⚠ 溜まってみないと分からない。**
  ⚠ **置くと決めたら、⚠ そのとき初めて「消えます」と言える。**

## 5. D1

⚠ **表は 1 つだけ。**⚠ **1 つの荷物が 1 行。**⚠ **場所ごとの行を作らない。**

```sql
CREATE TABLE handoff (
  code_hash  TEXT    PRIMARY KEY,   -- ⚠ SHA-256 の 16 進。⚠ 合言葉そのものは置かない
  payload    TEXT    NOT NULL,      -- ⚠ 保存した場所の一覧を詰めた字（⚠ 座標が入っている）
  created_at INTEGER NOT NULL,      -- ⚠ ミリ秒
  expires_at INTEGER NOT NULL       -- ⚠ ミリ秒
);
CREATE INDEX handoff_expires ON handoff(expires_at);
```

⚠ **場所ごとの表を作らない理由は 3 つ。**

```text
⚠ 検索しない      ⚠ 合言葉で 1 件引くだけ。⚠ 場所で引く問いが無い
⚠ 数えない        ⚠ 集計しない。⚠ 誰のものかも持たない
⚠ 2 か所になる    ⚠ 列に分けると、⚠ 座標の桁や欠損の扱いを、⚠ サーバにも書くことになる
                  （`CLAUDE.md` §3。⚠ 端末側は `saved.js` が既に持っている）
```

⚠ **場所ごとに問い合わせたくなったら、⚠ そのときに表を分ける。**
⚠ **いまは要らない**（[`adr/0071`](adr/0071-同期は判断を端末に置き、サーバは足すだけの箱にする.md)）。

- MUST: ⚠ **β 版の DB に刺さない。**⚠ **別の DB を作る**
  （[`adr/0050`](<adr/0050-v0.1.0 は別の Worker で作り、β 版に触らない.md>)。
  ⚠ **`tick` と混ざると分母が壊れる**。`CLAUDE.md` §6）。
- MUST: ⚠ **`payload` に上限を置く。**⚠ **実測（2026-08-29）: 500 件で 9172 文字、
  ⚠ 700 件で 12829 文字。**⚠ **上限も環境変数にする。**

## 7. 待たずに進むための偽のサーバ

⚠ **A は、⚠ B の実装を待たない。**⚠ **契約どおりに答える偽のサーバを、⚠ 検査の中に持つ。**

```text
test/render/handoff-stub.mjs    ⚠ 上の 2 つの口を、⚠ 契約どおりに返すだけのもの
test/check/handoff-contract.mjs ⚠ 偽と本物の両方へ、⚠ 同じ主張を当てる
```

- MUST: ⚠ **偽と本物を、⚠ 同じ検査で突き合わせる**（`CLAUDE.md` §3）。
  ⚠ **偽だけに通る実装は、⚠ 本物では動かない。**
- MUST: ⚠ **契約を変えるときは、⚠ この文書と検査を先に直す。**⚠ **実装より先。**
