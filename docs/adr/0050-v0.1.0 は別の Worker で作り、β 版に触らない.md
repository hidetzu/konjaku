# 0050. v0.1.0 は別の Worker で作り、β 版に触らない

- 状態: 採用（⚠ **決めたのは Owner。**⚠ 2026-08-28）
- 日付: 2026-08-28

## 背景

⚠ **v0.1.0 は β 版の画面・機能・データ構成を前提にしない**（`tmp/next-konjaku.md`）。
⚠ **スマホは街で見つける場所、⚠ PC は深掘りする場所**（`docs/adr/0049`）。

⚠ **作り直すには、⚠ 置き場が要る。**⚠ **同じ場所に混ぜると、⚠ 前提にしないと決めたものが混ざる。**

⚠ **測ったこと**（2026-08-28）:

```text
配信の入口     wrangler.jsonc 1 つ（⚠ name: konjaku ／ assets: ./public）
検査の走者     scripts/serve.mjs が public/ を配る（⚠ 1 か所を前提にしている）
SW の登録      /sw.js を scope 既定で登録  ⚠ **`/` 全体を受け持つ**
```

⚠ **同じドメインに `/next/` を作ると、⚠ β 版の SW が新しい画面まで拾う**（⚠ 古いものを返しうる）。

## 決めたこと

⚠ **別の Worker にする**（`konjaku-next`）。

```text
public-next/            ⚠ v0.1.0 が配るもの
wrangler.next.jsonc     ⚠ name: konjaku-next ／ assets: ./public-next
                        ⚠ **main を書かない**（⚠ 静的配信だけで始める）
                        ⚠ **D1 を繋がない**
```

⚠ **同じ repo に置く。**⚠ **別リポジトリにしない。**

## ⚠ なぜ別リポジトリにしないか

⚠ **掟・`.claude/rules/`・検査・Skill が、⚠ このリポジトリの資産。**
⚠ **分けると、⚠ それが効かなくなる。**⚠ **同じ repo なら、⚠ そのまま使える。**

## ⚠ なぜ β 版に触らないか

⚠ **β 版の観測が続く必要がある。**

⚠ **`docs/adr/0047` の 3〜5 段目**（⚠ 保存イベントを測る → ⚠ 使われなければ需要を疑う →
⚠ 使われるなら別端末を確かめる）は、⚠ **実際の利用者がいる場所でしか成り立たない。**
⚠ **利用者がいるのは β 版だけ。**⚠ **v0.1.0 には、⚠ まだ誰もいない。**

画面        ⚠ 引き継がない
