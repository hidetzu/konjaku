# 余白は「縦の間」だけ段にし、「箱の内側」は段にしない

- 状態: 採用
- 日付: 2026-08-27
- 関連: hidetzu/konjaku#312（hidetzu/konjaku#92 から切り出した）。[0039](0039-色を1か所に集め、色みを定義だけ置く.md) と同じ進め方

## 決めたこと

| # | 決めたこと |
|---|---|
| 1 | ⚠ **`margin`（縦の間）は段にする。**⚠ **段から選ぶ**（`--gap-sub` / `--gap-row` / `--gap-block`） |
| 2 | ⚠ **`padding`（箱の内側）は段にしない。**⚠ **くり返されている 2 つだけ**をトークンにした |
| 3 | ⚠ **検査は、⚠ 段に無い `padding` の数を名乗る。**⚠ **「まだ」とは言わない**（⚠ 未対応ではない） |

## 1. ⚠ なぜ片方だけなのか

⚠ **測ったら、⚠ 2 つは違う種類のものだった**（実測 2026-08-27・`main` = `e217da9`）。

### ⚠ `margin`（縦の間）— ⚠ **概念は 1 つ、サイズだけが揺れていた**

⚠ **57 か所を読んだら、⚠ 4 つの意味にきれいに割れた。**

```text
添え字（直前の行にくっつく）  2 / 3 / 4px          10 件
行と行の間（同じまとまり）    5 / 6 / 7 / 8px      33 件
まとまりとまとまりの間        9 〜 14px            14 件
節と節の間                    22 / 26 / 34px        3 件
```

⚠ **最頻値へ揃えたら、⚠ 36 か所が動いて ⚠ 最大 5px・ほとんどは 1〜2px。**
⚠ **幅が変わった要素は 0 件**（＝ 折り返しは 1 か所も変わっていない）。

### ⚠ `padding`（箱の内側）— ⚠ **揃える根拠が無かった**

```text
2 値の padding 39 件
  縦（上下）  3px×6  8px×5  7px×4  4px×4  5px×4  2px×3  10px×3  11px×3 …
              ⚠ **13 種がほぼ平坦。**⚠ 最頻値でも 6 件
  横（左右）  10px×14  6px×4  11px×4  12px×4  9px×4 …
```

| 揃え先 | 動く | 最大 |
|---|---|---|
| 縦を 3px（最頻値）に | 33/39 | ⚠ **12px** |
| 縦を 8px に | 34/39 | ⚠ **7px** |
| 横を 10px に | 25/39 | 6px |

⚠ **縦の間が最大 5px で収まったのに対し、⚠ こちらは 7〜13px 動く。**
⚠ **同じ扱いにはできない。**

⚠ **さらに 22 件は `0` を含む形**（`0 12px` / `2px 0` / `0 calc(50% - 44px)`）で、
⚠ **「横だけ」「縦だけ」の指定**であって、⚠ **段の話ですらない。**

### ⚠ 言葉にすると

```text
margin   「2 つのものの間」   → ⚠ 概念は 1 つ。⚠ **サイズが揺れているだけ**
padding  「この箱の内側」     → ⚠ **箱ごとに、⚠ 正当な理由で違う**
```

⚠ **だから `margin` は段になり、⚠ `padding` はならない。**

## 2. ⚠ 「くり返されている 2 つ」は残す

⚠ **段にしないことと、⚠ 同じ値を 5 回書き写すことは別。**

```css
--pad-sm: 6px 9px    /* .share-msg / .era-miss / .coarse / #stateMiss / #cands button */
--pad-md: 9px 11px   /* .verdict .peel-cta / #list .lh.fold / .here-msg / .retry-msg / #memo */
```

⚠ **この 2 つは、⚠ 同じ宣言が 5 回ずつくり返されていた。**⚠ **値は変えずに 1 か所へ集めた。**
⚠ **役割の名前は付けていない**（⚠ 5 か所が同じ意味を持っていないため。⚠ `--pad-md` は
⚠ 導線・見出し・知らせ・入力欄が混ざっている）。⚠ **これは「値の段」。**

## 3. ⚠ 検査の言い方を変えた

⚠ **前は「まだ段に無い余白が N 件ある」と言っていた。**⚠ **これは未対応に読める。**

⚠ **いまは「段に無い padding が N 件ある。⚠ 決めた上でそうしている」と言う。**

⚠ **検査は「守るべきこと」を固定する**（`CLAUDE.md` §9）。
⚠ **決めたことと、⚠ 検査が言っていることを、⚠ 食い違わせない。**

## ⚠ まだ言えないこと

- ⚠ **`padding` を将来まとめないとは言っていない。**⚠ **いまの分布では根拠が無い**というだけ。
  ⚠ **触った範囲から寄せる**のは、⚠ いままでどおり（`.claude/rules/css.md`）
- ⚠ **余白は `px` のまま。**⚠ **文字は rem 化済み**（hidetzu/konjaku#91）なので、
  ⚠ **利用者が文字を大きくしても、⚠ 余白は追いてこない。**
  ⚠ 実測（2026-08-27・トップ 375・`html{font-size:20px}`）: ⚠ 全体の高さ 1689 → 1927px（+14%）、
  ⚠ **段は 3 / 7 / 9px のまま。**⚠ **横あふれ 0・重なり 0 で壊れてはいない。**
  ⚠ **rem にするかは、⚠ まだ決めていない。**
