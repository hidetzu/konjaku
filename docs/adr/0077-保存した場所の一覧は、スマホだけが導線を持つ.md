# 0077. 保存した場所の一覧は、スマホだけが導線を持つ

- 状態: 決めた
- 日付: 2026-09-01

## 何を決めたか

```text
狭い幅（スマホ）  下の帯（.tabs）      ⚠ 「保存した場所」への入口を持つ
広い幅（PC）      名乗り（.brand__nav） ⚠ 持たない
```

⚠ **一覧の画面（`/saved`）そのものは消していない。**⚠ **URL では開ける。**
⚠ **導線を出さないだけ。**

## なぜ

⚠ **Owner の言葉（2026-09-01）**:

> PC版は、保存した場所の一覧は見せなくてよい。
> スマホだと読みにくいので、他のデバイスに共有して読みやすくするのが目的だったので。

⚠ **保存は「あとで読む」ための道具**で、⚠ **PC はその「あと」の側。**
⚠ **PC で一覧を管理するのではなく、⚠ 受け取って深掘りする。**

## ⚠ 受け取りの道は切れていない

⚠ **これを確かめてから決めた。**⚠ **切れていたら、⚠ 目的そのものが成立しない。**

```text
スマホ  /saved で合言葉を出す。⚠ 住所は <host>/take
PC      その住所を開く  →  /take  →  合言葉を打つ
                              ↓ 受け取ると
                         location.replace("./saved?added=…")
```

⚠ **`/take` は、⚠ もともと名乗りにも帯にも入口が無い**（⚠ 合言葉が案内する住所で開く）。
⚠ **だから名乗りのリンクを外しても、⚠ 受け取りは前と同じに動く。**
⚠ **受け取ったあとは `/take` 自身が `./saved` へ進める**ので、⚠ PC も一覧に着ける。

## ⚠ 実測（2026-09-01・1280×800）

```text
/            ロゴ →/  ／ 名乗り [地図で調べる→/（現在地）]  ／ 保存への見える道 0 本
/about.html  ロゴ →/  ／ 名乗り [地図で調べる→/]            ／ 保存への見える道 0 本
/saved.html  ロゴ →/  ／ 名乗り [地図で調べる→/]            ／ 保存への見える道 0 本
/take.html   ロゴ →/  ／ 名乗り [地図で調べる→/]            ／ 保存への見える道 0 本
```

⚠ **狭い幅（393×830）は、⚠ 帯に 2 本のまま**（地図 ／ 保存した場所）。

## ⚠ 残したこと（この ADR では直さない）

⚠ **PC の名乗りに残った「地図で調べる」は、⚠ ロゴ（→ `/`）と同じ行き先。**
⚠ **トップでは自分自身を指す**（現在地）。⚠ **意味が重なっている。**

⚠ **今回の範囲は「保存一覧への導線を PC から外す」だけ**なので、⚠ ここには手を入れない
（`CLAUDE.md` §7-4）。⚠ **名乗りごと畳むかは、⚠ 別で決める。**

## これを守っているもの

⚠ **`test/check/next.mjs` ⑰。**⚠ **5 通りわざと壊して、⚠ 5 通りとも落ちることを確かめた。**

- 名乗り（`.brand__nav`）が保存一覧へのリンクを持たない（⚠ **全 HTML**）
- 狭い幅の帯（`.tabs`）は持つ（⚠ **両方消すと、⚠ 道が 1 本も無くなる**）
- 受け取り口（`take.html`）が在る
- ⚠ **住所を組み立てているところが全部 `/take`**（⚠ **2 か所ある**）
- 受け取ったら `./saved` へ進む

⚠ **`/take` の住所は、⚠ 本文に `/take` が在るか、では見ない。**
⚠ **実際に素通りした。**⚠ **2 か所あるので、⚠ 片方を壊しても、⚠ もう片方の字を拾って通る。**
⚠ **組み立てているところを全部取り出して、⚠ 1 つずつ見る。**

⚠ **実描画は「主な行き先が 1 か所にだけ出る」を、⚠ 幅ごとの行き先で見るようにした**
（⚠ 前は「どちらの幅でも同じ 2 つ」を主張していた。⚠ **その主張が、いま偽になった**）。
