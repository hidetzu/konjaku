# 中間を語らない。中間は見せる

- 状態: 採用
- 日付: 2026-08-13（旧 §3.30）

## 何が問題だったか

外部の助言を2つ受けた。どちらも「言葉の年表」を求めてきた。

```
明治期  低湿地だった
1960年代  造成開始        ← これが書けない
1980年代  住宅地化        ← これも書けない
現在    盛土地・埋立地
```

**両端はこちらが根拠つきで言える。真ん中の2行が言えない。**
これを書けば、konjaku は「自分が回避するために作られたものそのもの」になる（0006）。

## 何を測ったか

- 中間の主張が出せないことは、輝度・分散・彩度の実測と正規化相互相関の実測で確定済み（0006）
- 建設年は **OSM に 545件中8件しか無い**
- 写真を並べても**通信は増えない**: 写真タイルの要求 15件／実URL 8種。新しく取りに行くのは「現在」の1枚だけ
- 横スクロールで一度失敗した ―― **375px 幅で4枚目が切れ**、「現在」が画面外から始まっていた
- 折り返しにしたら **8枚が2行で全部見える**（実測: 現在が y=456・帯の高さ 185px）

## 決めたこと

- **言葉の年表ではなく、写真の年表にする。** 8コマ（1936–42 / 1945–50 / 1961–69 / 1974–78 / 1979–83 /
  1984–86 / 1987–90 / 現在）を並べる帯を置く
- **両端だけこちらが根拠つきで言い、間は写真がそのまま語らせる。こちらは一言も主張しない**
- **読めていないときは帯ごと出さない。** 「無い」と「読めない」を区別できないなら、どちらとも言わない
- 明治期のコマには**年を書かない**。低湿地データは年を持たない。無理に当てると持っていない精度を演出することになる
- 横スクロールをやめて折り返しにする

## そうしなかったこと

- **助言された言葉の年表の真ん中2行** … 実測で出せないと確定している
- **`ERAS` に「現在」を混ぜる** … `photos()` が答えるのは「**残っている**空中写真」＝過去の話。
  そこに現在を混ぜると「7年代を確認」の意味が変わる。現在は複製として別に持つ
- **明治期に年を当てる** … 持っていない精度の演出になる

## 派生した問題と、その直し（2026-08-14）

明治期のコマに年が無い ＝ `yearOf("明治期")` が年を返せない ＝ **年代付き事物は必ず0件**。
そして着いたときの帯の既定は最古＝明治期。結果、
**初めて来た人が最初に見る事物の枠は、必ず説明だけで、次の一歩が無い**状態になっていた。
どちらの判断も間違っていないのに、噛み合うと詰む。

直すのに2回失敗している。

1. ❌ 注記の横に別ボタンを足した → 実測 51px → 95px。折り返しの下へ出た
2. ❌ 「写真のある最初の年代」へ送った → **豊洲の 1936–42 は 0件**（埋立前なので当然）。押しても何も起きない一歩になった
3. ✅ 注記そのものを押せるようにして、**中身のある最初の年代**へ送る（実測 53px、豊洲で 明治期 → 1961–69、2件）

2回目の教訓として、差分の計算を `hitsAt(i, all)` に切り出し、
**描画と「行き先探し」が同じ判定を使う**形にした（0021）。
