# 0089. `/about` の節は、印と箱で読み進められるようにする

- 状態: 決めた
- 日付: 2026-09-03
- ⚠ **[`0087`](<0087-about は読み物の前に入口を持ち、帯の行き先は名乗り 1 本にする.md>) の続き**。
  ⚠ **`/deep` でやったこと（hidetzu/konjaku#465）と、⚠ 同じ方針を `/about` にも当てる。**

## 何を決めたか

⚠ **4 つの節を、⚠ 文章の連続から、⚠ 見て分かる形にする。**

```text
使い方              3 手のカード      印 ＝ ピン ／ 時計 ／ カメラ
何を読んでいるか     4 項目のカード    印 ＝ 稜線 ／ 方眼 ／ 雲と太陽 ／ 同心円
言えないこと         断りの箱          印 ＝ 丸に !（⚠ 4 つとも同じ）
送るものと、預けるもの 小さな図         この端末 → 預かる → 別の端末
```

## ⚠ 情報も根拠も削っていない

```text
字      1030 → 1041      ⚠ むしろ増えた（⚠ 項目名を段落から出したぶん）
ページ  3071 → 3002px    ⚠ 縦に伸びていない
```

⚠ **いちばん長かった「言えないこと」が、⚠ 961 → 791px。**⚠ **170px 短い。**

## ⚠ 1 列にした（2 列を落とした）

⚠ **「何を読んでいるか」を 2 列にすると 383px（1 列は 520px）。**⚠ **140px 短い。**
⚠ **しかし 375px では 1 枚 160px 幅になり、⚠ 説明が 5 行に折り返した。**
⚠ **短くはなるが、⚠ 読みにくくなる。**⚠ **1 列にした**（Owner 判断）。

## ⚠ 印の決めごと

```text
飾りではない        節の識別と、⚠ 視線の休憩のために置く
印だけで伝えない     字は必ず隣にある
読み上げから外す     aria-hidden="true"
フォントに頼らない   ⚠ 2026-09-02 に ☾ が豆腐になった
色は追いてくる       currentColor（⚠ --ink-3）
形は /deep と同じ    viewBox 0 0 16 16 ／ stroke-width 1.3
```

⚠ **画面の `⚠` は使わない。**⚠ **あれは災害リスク専用。**
⚠ **断りの箱は、⚠ 左の色の線（`--evidence`）と、⚠ 丸に `!` の印で示す。**
⚠ **`--evidence` は根拠の帯と同じ色。**⚠ **危険の色ではない。**

⚠ **枠は `--line`。**⚠ **押せるものではないので `--line-strong` を使わない。**
⚠ **検査が見ている。**

## 確かめたこと

```text
4 幅（375×667 / 344×882 / 320×640 / 1280×800）× 明るい・暗い
横あふれ 0 ／ 印 16 個が全部見える ／ 印の色が色みで変わる
```

⚠ **わざと壊して、⚠ 12 通りとも落ちることを確かめた。**

## 決めなかったこと

- ⚠ **`/privacy` の 4 節**（⚠ まだ文章の連続。⚠ `about__rows` を使っている）
- ⚠ **実在の利用者が印をどう読むか**
- ⚠ **読み上げでの通りやすさ**（⚠ `aria-hidden` にしたが、⚠ 実機で聞いていない）
