# 0107. 境目を出せたかを、深掘りで 1 回だけ数える

- 日付: 2026-09-30
- 状態: 採用

- ⚠ **hidetzu/konjaku#481。**⚠ **`docs/adr/0092` が「v0.3.0 公開後に測る」と残した宿題。**

## 何が測れていなかったか

⚠ **「この先で、土地が変わる」が、⚠ どれだけの土地で出せるかを知らなかった。**
⚠ **2 通り測ったが、⚠ どちらも利用者に対する出現率ではない**（`docs/adr/0092`）。

```text
24 地点   29% が「足元が無い」   ⚠ 手で選んだ地点。⚠ 都市に偏る
480 点    97% が「足元が無い」   ⚠ 矩形に無作為。⚠ 海と山が大半
```

⚠ **分母が 20 倍以上ぶれる数字しか持っていなかった。**
⚠ **その上に次の機能を積もうとしていた。**

## 決めたこと

⚠ **`/deep` で判定が出たとき、⚠ 5 通りのどれかを 1 回だけ送る。**

```text
ok          境目が上限内に在り、⚠ 向こう側の区分も読めた   ⚠ これだけが画面に出る
遠い        境目は在るが、⚠ 上限より遠い
見えない    ⚠ 読み込んだ範囲に別の区分が無い
足元が無い  ⚠ この点に地形分類が無い
読めなかった ⚠ 相手が返さなかった／対照表が読めなかった
```

### ⚠ なぜ 5 通りか（⚠ Issue は 3 通りと書いていた）

⚠ **`hidetzu/konjaku#481` の本文は「候補あり／足元なし／境目なし」の 3 通り。**
⚠ **実装は 4 通りに分かれており**（`public/border.js`）、⚠ **`verify.js` が 5 通り目を足す。**

⚠ **`遠い` と `読めなかった` を落とすと、⚠ 分母が縮んで「出せた割合」が高く見える。**
⚠ **取れなかったことを、⚠ 無かったことにしない**（`CLAUDE.md` §1）。

### ⚠ 判定は ok でも、⚠ 画面に出ないことがある

⚠ **対照表（`landform.json`）が読めないと、⚠ 区分の名前が引けない。**
⚠ **そのとき画面には何も出ない。**⚠ **だから `読めなかった` に数える。**
⚠ **測っているのは「判定が ok だったか」ではなく、⚠ 「利用者に出せたか」。**

## ⚠ 何を送らないか

```text
送る      5 通りのどれか、だけ
送らない  ⚠ 座標 ／ ⚠ 町名 ／ ⚠ 境目までの距離 ／ ⚠ 区分の名前 ／ ⚠ 方角
```

⚠ **判定そのものは、⚠ その場所の性質ではある。**
⚠ **ただし 5 通りしかないので、⚠ 場所は特定できない。**
⚠ **`/privacy` の「ここに書いていないことは、していません」に合わせて、⚠ 画面にも書いた。**

## ⚠ `page` と `border` は、⚠ 同時に入らない

⚠ **`metadata` はどちらか一方。**⚠ **画面側でも受け側でも弾く。**

⚠ **混ぜると、⚠ `npm run stats` の「どの画面が開かれたか」に判定が数え込まれる。**
⚠ **`docs/adr/0104` で踏んだのと同じ形**（⚠ `deep_accessed` と `page_load` が二重に見えた）。

⚠ **あわせて、⚠ 問い 5 を「画面の名を持つ行」だけに絞った**（⚠ 判定の行が `-` として並ばないように）。

## ⚠ 1 回だけ数える

⚠ **1 回の深掘りで 1 回。**⚠ **画面が描き直されても、⚠ 分母を水増ししない。**

## ⚠ `/` では数えない

⚠ **同じ判定を散歩中の画面（`/`）も使っている**（`docs/adr/0092` の追記）。
⚠ **今回は `/deep` だけ。**⚠ **`hidetzu/konjaku#481` が「`/deep` が開かれた地点を分母にする」と決めている。**
⚠ **両方数えると、⚠ 分母が混ざる。**

## いつまで測るか ── ⚠ 恒久にする（2026-09-30。Owner 判断）

⚠ **他の計測と同じ扱いにする。**⚠ **一度測って終わりにしない。**

⚠ **理由は、⚠ 出現率が動くから。**⚠ **地形分類は国土地理院の提供実験で、⚠ 整備が進む。**
⚠ **「足元が無い」土地は、⚠ 減りうる。**⚠ **一度の値を、⚠ ずっと正しいものとして持たない**
（`CLAUDE.md` §6。⚠ **測定日と条件が要る**）。

⚠ **何件たまったら読むかは、⚠ 決めていない。**
⚠ **`docs/adr/0010` は共有率について「100 件」と言うが、⚠ あれは共有率の話。**
⚠ **ここへ持ってこない**（⚠ 別の範囲の数字を持ち込むと、⚠ その数字自体が嘘になる）。

⚠ **止めるときは、⚠ 列挙から 1 行落とすだけで済む形にしてある。**
