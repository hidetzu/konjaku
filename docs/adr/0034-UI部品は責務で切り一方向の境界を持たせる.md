# 0034: UI 部品は、画面上の箱ではなく責務で切り、一方向の境界を持たせる

- 状態: 採用
- 日付: 2026-08-22
- 関連: hidetzu/konjaku#171 ／ PR hidetzu/konjaku#202 ／
  [`.claude/rules/components.md`](../../.claude/rules/components.md) ／
  [ADR 0021](0021-同じ問いに答える実装を2つ持たない.md) ／
  [ADR 0033](0033-HUDは年代の表示と操作だけを持つ.md)

## 決めたこと

⚠ **UI 部品は、⚠ 画面の上の箱ではなく、⚠ 責務で切る。**
⚠ **切ったものには一方向の境界を持たせる。**⚠ **必要なら DOM を所有してよい。**

```text
入力  update(state)     ⚠ 渡されたものだけを描く。取りに行かない
出力  callback          ⚠ 操作は返す。自分で状態を書き換えない
```

⚠ **満たす条件は 4 つ**（[`components.md`](../../.claude/rules/components.md) が正本。⚠ ここには書き写さない）。

⚠ **この ADR は「`EraControlPanel` を作った」という記録ではない。**
⚠ **それは Issue と PR で足りる。**⚠ 残すのは ⚠ **切り方の判断**。

## なぜ

### 1. ⚠ 箱で切ると、⚠ 責務が混ざったまま運ばれる

`/peel` の HUD には、⚠ **年代の表示と操作・補足・土地の答え**が同居していた。
⚠ **「HUD を部品にする」と決めていたら、⚠ 混ざったまま部品になっていた。**

hidetzu/konjaku#171 は ⚠ **「年代の表示と操作」に境界を置いた。**
補足は [ADR 0033](0033-HUDは年代の表示と操作だけを持つ.md) で HUD の外へ出し、
答えは [ADR 0030](0030-土地の答えは確実性の高い順に3層で出す.md) の情報パネルへ移してある。
⚠ **境界を責務で引いたので、⚠ どちらも一緒に運ばずに済んだ。**

### 2. ⚠ `DOM を持たない` を `MUST` にすると、⚠ この切り方ができない

[`javascript.md`](../../.claude/rules/javascript.md) は
「DOM も地図も持たない形に切り出す」を `SHOULD` にしている（⚠ **`MUST` ではない**）。
⚠ **7 つある既存**（`photos.js` / `words.js` / `prov.js` / `swale.js` / `ground.js` /
`land.js` / `verify.js`）は、⚠ **どれも Domain の変換**であって、⚠ **画面の部品ではない。**

⚠ **画面の部品は DOM を持つ。**⚠ **持たせないと、⚠ 呼ぶ側に DOM 操作が残り、
⚠ 切り出した意味が無くなる。**⚠ **だから認める。かわりに条件を強くした。**

### 3. ⚠ 切り出して初めて、⚠ 暗黙の依存が見つかった

⚠ **これが、この判断のいちばんの根拠。**⚠ **どれも実物のページでは動いてしまう。**

| 何に頼っていたか | ⚠ どうなったか |
|---|---|
| `peel3d.js` が最上位で宣言した `esc` | ⚠ classic script は最上位の `const` を共有する。⚠ **実物では動く。単体で開いて初めて落ちた** |
| `peel.html` の `*{box-sizing:border-box}` | ⚠ 単体だとノブが枠線ぶん **右へ 6px** ずれ、⚠ **真ん中を押しただけで値が 200 → 202 に動いた** |

⚠ **静的検査では捕まらない**（`esc` は禁止語ではない）。
⚠ **部品だけで開く検査を持って、初めて分かる。**

### 4. ⚠ 検査が速くなる（⚠ CI に効く）

⚠ **実測（2026-08-22・`main` = `ffe53ca`）**

| | |
|---|---|
| 地図を立ち上げるケース | ⚠ **1 件 10〜30 秒** |
| 部品だけで開くケース | ⚠ **95ms ／ 引いた URL 5 本 ／ 地図 0 本** |

⚠ **実描画 4 件を部品単体へ移した**（⚠ **主張は 1 つも落としていない**）。
⚠ **移せた理由は、⚠ どれも地図も建物も土地データも見ていなかったから。**
⚠ **段を渡せば足りるものは、⚠ 地図を立ち上げる必要が無い。**

## ⚠ 検査の的を、内部状態に置かない

⚠ **移す前の 4 ケースは、どれも `#t.value`（部品の内部）を見ていた。**
文字タップの処理は `slider.value` を自分で書いてから画面へ返すので、
⚠ **返す処理（`onChangeEra`）を丸ごと消しても、⚠ 4 件とも緑のままだった**（実測）。

⚠ **一方向にしたなら、⚠ 契約は「返す値」のほう。**⚠ **そちらを見る。**

## ⚠ やらないこと

- ⚠ **既存を一括で部品化しない。**⚠ **2 つ目が実際に現れてから共通化する**（`domain.md`）。
- ⚠ **この ADR は、⚠ 実装の形（Custom Elements にするか、`create<Name>()` にするか）を決めていない。**
  ⚠ **決めたのは境界の引き方だけ。**⚠ **形は hidetzu/konjaku#95 が扱う。**
  ⚠ `EraControlPanel` が `create<Name>()` なのは ⚠ **いまそれで足りているから**であって、
  ⚠ **将来もそうだという判断ではない。**⚠ **どちらにしても、上の 4 条件は変わらない。**
- ⚠ **見た目の統一を、⚠ 移設と同時にやらない。**⚠ `border-radius` は散らばっているが、
  ⚠ **hidetzu/konjaku#171 では 1 つも触っていない**（⚠ **尺度は hidetzu/konjaku#92 が扱う**）。

## 影響

- `public/components/<name>/` に `.js` と `.css` を置く。⚠ **両方 `public/sw.js` の SHELL へ。**
- ⚠ **部品ごとに、⚠ 地図もネットも無しで開く検査を持つ。**
- ⚠ **境界は静的検査でも見る**（禁じる語・触ってよい id）。
