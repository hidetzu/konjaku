## ⚠ 変更 1: ⚠ 「Magic Link」と「一時 URL」を、同じ段に置かない

⚠ **重さが違う。**

| | 要るもの | ⚠ 言えなくなること |
|---|---|---|
| ⚠ **URL / QR に載せる** | ⚠ **何も要らない** | ⚠ **1 つも無い** |
| ⚠ **一時 URL（サーバに置く）** | 置き場・失効・削除 | ⚠ 預けた場所が残る |
| ⚠ **Magic Link** | ⚠ **メールアドレス**・送信基盤・失効 | ⚠ 識別子・個人情報が要る |

⚠ **Magic Link は「アカウント無し」に見えて、⚠ メールアドレスを預かる。**
⚠ **正式なアカウントとほとんど同じ重さなので、⚠ 別の段にする意味が薄い。**

### ⚠ URL / QR で、⚠ 何件まで載るか（⚠ 実測 2026-08-28）

⚠ **数字は書き写さない。**⚠ **走らせて出す**（`CLAUDE.md` §6 と同じ考え方）。

```bash
node scripts/handoff-size.mjs
```

⚠ **記録の形は `public/top.js` の `setRec` と同じ**（star / memo / title / lon / lat / at）。
⚠ **地名 10 種・メモ 10 種・座標すべて別を混ぜて測っている**
（⚠ **同じ記録を並べると圧縮が効きすぎる。**⚠ 最初そう測って、⚠ 測り直した）。

⚠ **2026-08-28 に走らせて確かめたのは、⚠ 次の 2 点**
（⚠ **判断の分かれ目だけを書く。**⚠ 表そのものは走者が出す）:

```text
⚠ **50 件が、⚠ URL の実用上限 2000 文字に収まる**
⚠ **100 件は、⚠ URL には収まるが QR のバイナリ上限に近づく**
```

⚠ **URL は実用上 2000 文字まで通る。**
⚠ **QR はバイナリモードで最大 2953 バイト。**
⚠ **`base64url` は英数字モードに収まらない**（⚠ `-` `_` が入る）。

⚠ **つまり 50 件までは、⚠ サーバも識別子も無しで端末をまたげる。**
⚠ **「散歩を中断せずに → 家で再開」は、⚠ これだけで成立する。**

⚠ **上限をどこに引くかは決めていない。**
