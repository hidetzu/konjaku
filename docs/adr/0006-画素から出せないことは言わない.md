# 「いつ陸になったか」「いつ大きく変わったか」は、画素から出せないので言わない

- 状態: 採用
- 日付: 2026-08-11（旧 §3.20 実測1）／2026-08-13 に再測して確定

## 何が問題だったか

外部の助言が繰り返し「この土地が大きく変わったのは1960〜70年代です（⭐大きな変化）」や
「1961年に埋め立てられた」を求めてきた。**出せるなら物語ではなく事実になる**ので、出せるかどうかを測った。

助言者が何周しても同じ提案が来るのは、「場所×時間」で人が期待する文が、
**たまたま全部データの外側にある**からだった。

## 何を測ったか

### 実測1: 水陸すら分離しない（2026-08-11）

空中写真の輝度・分散・彩度で水陸を分けられるか、答えの分かる地点で検証した。

```
皇居（ずっと陸）  1974–78:  明 24.1  σ23.1   ← 最も暗い（森）
東京湾（いまも水）  現在:     明 85.7  σ 4.5   ← 皇居より明るい
豊洲   1961–69:  明 91.3  σ26.2
皇居   1961–69:  明 91.9  σ20.9   ← 豊洲とほぼ同じ
```

**撮影ごとに露出が違い、植生は水面より暗い。** 分離できない。

> 副産物: 「空白」は確実に判定できる（明>250 かつ σ<1）。皇居・夢の島の 1936–42 は、
> タイルは存在するが**その地点は写っていない**。年代の可用性チェックに入れた。

### 実測2: 変化点も分離しない（2026-08-13）

連続する2年代の、地点まわり 96×96 画素（z16 で約220m四方）の**正規化相互相関**。`1 - NCC` を変化量とした。
指標が「土地の変化」ではなく「フィルムの違い」を測ることを疑い、**変わっていないはずの土地を対照に入れた。**

```
変わった土地（豊洲・夢の島・亀戸・浦安）  変化量 0.31 〜 0.98（平均 0.69）
対照（皇居の森・明治神宮・上野公園）      変化量 0.18 〜 0.94（平均 0.47）
                                                        ↑ ここが重なる
```

- **対照の最大 0.94（皇居の森）が、変わった土地の大半の区間を上回る**
- 対照3つとも、最大変化が `1936–42 → 1945–50` に来る。測っているのは戦中戦後の写真の質（と戦災）
- `1987–90 → 現在` が系統的に持ち上がる（浦安 0.98 だけでなく上野公園 0.75、亀戸 0.86）。最新写真だけ解像度が違う
- ±12px の位置合わせを入れて測り直しても、値が下がるだけで**順位は変わらない**

## 決めたこと

- **⭐（大きな変化）は出さない。** 出せば「豊洲が大きく変わったのは 1945–50年です」という**自信ありげな誤り**になる
- 「1961年に埋め立てられた」「昔は海」も書かない。**埋立年は画素から出せない**
- 看板でも約束しない。「昔なんだったか」は地形分類の成因と明治期の低湿地から判定できる範囲の話に留める
- 代わりに **写真を並べる**（0012）。中間はこちらが一言も主張せず、見た人が読み取る

## そうしなかったこと

- **空中写真からの建物検出で変化点を出す** … 原理的には可能だが重い。いまは持たない
- **「推定」と断って出す** … 低湿地の二値判定を誤ったときや、通信断の豊洲に「整備対象外」と書いていたときと同じ形。
  権威ありげな見た目で誤ったことを言う
- **土地条件図で中間を埋める** … 0017 を参照。凡例が機械可読でない

## これを守っているもの

- `public/index.html` の看板コメントと、判定文を組む箇所（「書けるのは判定できることだけ」）
- `scripts/render.mjs` — 「1960年代：造成開始」のような中間の主張を出さないこと、
  「1964年。このころ、この周辺には……」を書かないこと
- `npm run render` の `判定から出た語が無いときは溶接しない`
