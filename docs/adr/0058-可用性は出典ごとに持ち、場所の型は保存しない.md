# 0058. 可用性は出典ごとに持ち、場所の型は保存しない

- 状態: 採用（⚠ **決めたのは Owner。**⚠ 2026-08-29。⚠ 原文は `tmp/tmp2.md`）
- 日付: 2026-08-29

⚠ **`docs/adr/0056`（低湿地の 3 状態）と `0057`（地形分類は粗くなるだけ）の続き。**
⚠ **`0057` は「まだ共通化しない」と決めた。**⚠ **何を共通化しないのかを、⚠ ここで正確にする。**

## 決めたこと

### ⚠ ① 場所を分類しない。⚠ **出典ごとに判定する**

```text
⚠ **「場所を分類する」のではなく、
⚠ 各データを独立して可用性判定し、⚠ その組み合わせで場所の状態を作る。**
```

⚠ **いちばん大事なのは、⚠ **明治期低湿地が無い ≠ 地形分類も無い**。**

### ⚠ ② 出典ごとの状態

⚠ **明治期の低湿地**（`docs/adr/0056` のまま）:

```text
A1  整備範囲内・区分あり    →  「明治期は水田でした」など
A2  整備範囲内・区分なし    →  「この場所はまだ分類されていません」
A3  ⚠ **整備範囲外**        →  「この地域ではこの資料は作られていません」
```

⚠ **地形分類**（⚠ 4 段階にする）:

```text
B1  詳細な地形分類あり              →  「氾濫平野」など詳細表示
B2  詳細版は無いが広域・地域分類あり  →  より粗い分類を表示
B3  分類情報を取得できない           →  「詳しい地形情報はありません」
B4  ⚠ **取得失敗**（通信・API）      →  ⚠ **データ不存在とは別**にエラー扱い
```

⚠ **B3 と B4 を分ける。**⚠ **これは掟 §1 そのもの。**

### ⚠ ③ 場所の型は、⚠ 保存しない

```text
⚠ **`location.type = A` のように固定しない。**
⚠ **出典ごとの状態を持ち、⚠ UI が結果から型を作る。**
```

⚠ **持つのはこの形**（`tmp/tmp2.md`）:

```text
明治期の低湿地   coverage: inside ／ classification: 水田
地形分類         detail: detailed ／ classification: 氾濫平野
```

⚠ **こうしておけば、⚠ 古地図・航空写真・PLATEAU・鉄道・地価・災害履歴・建物履歴を
⚠ 足しても、⚠ 同じ形で扱える。**

## ⚠ 組み合わせで、⚠ 何が言えるか

| | 低湿地 | 地形分類 | ⚠ 今昔で言えること |
|---|---|---|---|
| Type A | ○ | ○ | ⚠ 昔の姿 ＋ 土地の成り立ち |
| Type B | ○ | × | ⚠ 昔の姿だけ。⚠ **無理に土地の成り立ちを説明しない** |
| Type C | × | ○ | ⚠ **土地の成り立ちだけ。**⚠ **それでも使う値打ちがある** |
| Type D | × | × | ⚠ **この 2 つからは何も断定しない** |

⚠ **Type C が効く。**⚠ **「昔何だった？」に答えられなくても、
⚠ 「この場所はどういう土地なのか」には答えられる**（⚠ 那覇がこれ）。

⚠ **Type D では、⚠ 「昔は○○だった」のような推測を絶対にしない。**
⚠ **別のオープンデータが足されたとき、⚠ 情報が増える場所になる。**

## ⚠ 絶対にやらないこと

```text
⚠ **「データがない」という一つの言葉に潰さない。**
```

⚠ **`404` は「何もない」ではない。**
⚠ **「そのデータソースの整備対象外」という、⚠ ひとつの状態にすぎない。**

## ⚠ `docs/adr/0057` との関係（⚠ 言い直す）

⚠ **`0057` は「まだ共通化しない」と決めた。**⚠ **それは変えない。**⚠ **ただし対象を正確にする。**

## ⚠ β 版が、⚠ 既にこの 4 段階を持っていた（⚠ 2026-08-29 に確認）

⚠ **`worker.js` の計測イベントが、⚠ B1〜B4 と 1 対 1 で対応する:**

```text

B2  →  judged.coarse  広い区分でしか出せなかった
```

⚠ **つまり β 版は、⚠ 「取得できない」と「通信失敗」を既に分けていた。**
⚠ **こちらが `tmp/tmp2.md` で整理した形は、⚠ β 版の計測が持っていたものと同じだった。**

⚠ **足りないのは、⚠ 低湿地側**（⚠ A1/A2/A3 に当たる計測イベントは無い）。

## ⚠ 画面でも、⚠ 出典を分けて見せる（⚠ 2026-08-29 に足した）

⚠ **実装して、⚠ 利用者役 3 名に見せたら、⚠ 3/3 が同じ矛盾を指した。**

```text

A  ⚠ **上と下が喧嘩しているように読める。**⚠ じゃあ上の話はどこから出てきたのか
B  ⚠ **資料が無いのに、⚠ なぜ言い切れるのか分からない。**⚠ そこだけ信用が揺らいだ
```

### ⚠ 原因

```text
⚠ **可用性を出典ごとに持っていたが、⚠ 画面では出典が分かれて見えなかった。**
⚠ **上は地形分類、⚠ 下は明治期の低湿地。**⚠ **どちらがどの資料かを書いていなかった。**
```

⚠ **片方の「無い」が、⚠ もう片方に効いて見える。**

### ⚠ 直したこと

```text
⚠ **資料ごとに箱を分け、⚠ どの資料から言っているかを見出しにする。**

  いまの地形から
    ここは、かつて水面で、その後陸地にされた土地
    国土地理院の区分：旧水部

  明治期の地図から
    この地域では、この資料が作られていません
```

⚠ **`docs/adr/0058` の「出典ごとに持つ」を、⚠ 画面まで通す。**
⚠ **持ち方だけ分けても、⚠ 見せ方が混ざっていれば同じこと。**

### ⚠ 効いていたこと

⚠ **`docs/adr/0056` で決めた言葉は、⚠ 逆に信用を上げていた**（⚠ 2/3）:

```text
B  ⚠ **正直に書いてある。**⚠ 他の 3 枚も信用していいと思えた

   ⚠ **こういう区別をする作り手は信用できる**
```

⚠ **矛盾に見えていたのは言葉ではなく、⚠ **どの資料の話かが分からなかったこと**。**
