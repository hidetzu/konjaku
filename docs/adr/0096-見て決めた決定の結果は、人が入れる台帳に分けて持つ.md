# 0096. 見て決めた決定の結果は、人が入れる台帳に分けて持つ

- 状態: 決めた
- 日付: 2026-09-05
- ⚠ **[`0035`](<0035-開発の計測は配信の計測と分けてGitの外に置く.md>) と
  [`0036`](<0036-Evalは観測を比べるだけで良し悪しを決めない.md>) を変えない。**⚠ **採点しない。**
- ⚠ **[`0093`](<0093-Owner の手は、観測できたものだけを事実の名前で出す.md>) の台帳には混ぜない。**

## 何を決めたか

⚠ **`visual-decision` で Owner が絵を見て決めたあと、⚠ その決定がどうなったかを、
⚠ 1 つだけ記録できるようにする**（Owner 指示）。

```text
即決        ⚠ 出した案から、そのまま決まった（⚠ 聞き直しが無かった）
迷った      ⚠ 聞き直した ／ 案を出し直した ／ 条件を足して撮り直した
後で戻した  ⚠ 一度そう決めたが、あとで元へ戻した
```

- ⚠ **値は 3 つだけ。**⚠ **増やさない**（Owner 指示）。
- ⚠ **キーは PR 番号。**⚠ **`hidetzu/konjaku#487` の形で持つ**
  （⚠ 裸の番号は移行すると別のものを指す。`CLAUDE.md` §9）。
- ⚠ **`visual-decision` の出し方（いま／案／推す案／落とした案）は変えない。**⚠ **記録だけ。**

## ⚠ なぜ既存の台帳に混ぜないか

⚠ **既存の計測は、⚠ 全部フックが自動で書いた事実**（`.claude/hooks/telemetry.mjs`）。
⚠ **人が入力した値は 1 つも入っていない**（⚠ 2026-09-05 に実測。⚠ 記録の全欄を数えた）。

⚠ **とくに「Owner の手が入らなかった」は、⚠ 次の 3 つが 0 だった Task、という機械の判定**
（`0093`）。

```text
OwnerAsk が無い ／ 道具が止まっていない ／ 本文で聞いていない
```

⚠ **ここへ人の入力が 1 行でも混ざると、⚠ あの数が何の数か言えなくなる。**
⚠ **だから、⚠ ファイルごと分ける。**

```text
.claude/telemetry/events.jsonl     ⚠ フックが書いた事実
.claude/telemetry/tasks.jsonl      ⚠ 同上
.claude/telemetry/decisions.jsonl  ⚠ **人が入れた値**（⚠ これ）
```

⚠ **読む側（`.claude/tools/telemetry-eval.mjs`）は、⚠ 別の節に、
⚠ 「人が入れた値」と名乗って出す。**⚠ **上の表には 1 つも混ぜない。**

## ⚠ あとから書き戻せる形にする

⚠ **「後で戻した」は、⚠ 決めた時点では分からない。**⚠ **あとで分かる。**

⚠ **だから、⚠ 同じ PR にもう 1 行足す**（⚠ `tasks.jsonl` と同じ契約）。

```text
書く    ⚠ 追記だけ。⚠ 前の行は消さない
読む    ⚠ その PR の最後の行を採る
```

⚠ **書き換えて 1 行にしない。**⚠ **いつ何を入れたかが、⚠ ファイルに残る。**

## ⚠ 良し悪しではない

⚠ **「即決が多いほど良い」ではない**（`0036`）。
⚠ **迷ったほうが良い決定だったことも、⚠ 戻したのが正解だったこともある。**
⚠ **出力にもそう書く**（⚠ 検査が、⚠ その 1 文が在ることを見ている）。

## ⚠ 置き場を、⚠ 道具が作らない

⚠ **実測（2026-09-05）**: ⚠ **本物の記録は本体のチェックアウトにあり、
⚠ `worktree` の下からは見えない**（⚠ `.claude/telemetry/` が無い）。

⚠ **黙って作ると、⚠ 台帳が 2 つになって、⚠ どちらも全部を持っていない状態になる。**
⚠ **だから、⚠ 無ければ見に行った場所を言って止まる**（⚠ `ask-slack.mjs` と同じ流儀）。
⚠ **これはフックではないので、⚠ 止まってよい**（⚠ 間違った値を黙って書くほうが悪い）。
