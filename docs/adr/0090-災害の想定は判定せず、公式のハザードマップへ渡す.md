# 0090. 災害の想定は判定せず、公式のハザードマップへ渡す

- 状態: 決めた
- 日付: 2026-09-03
- ⚠ **hidetzu/konjaku#446**（⚠ `docs/v0.1.1-土地ごとの地盤・地震情報.md` の Issue 6）

## 何を決めたか

⚠ **洪水・津波・高潮・土砂災害は、⚠ 今昔では判定しない。**
⚠ **`/deep` の「この土地の地盤と揺れ」の末尾に、⚠ 道を 1 本だけ置く**（Owner 判断）。

```text
洪水・津波・高潮・土砂災害を、公式のハザードマップで見る
国土交通省の「重ねるハザードマップ」が、この場所で開きます。
どの想定があるかは、開いた先で確かめてください
```

⚠ **渡すのは、いま見ている場所の座標だけ**（`?ll=<緯度>,<経度>&z=15`）。
⚠ **β 版が渡していた形と同じ。**⚠ **v0.1.0 へ運んでいなかったものを戻した。**

## なぜ判定しないか

- ⚠ **今昔の主役は「土地の過去」。**⚠ **防災サービスにしない**
- ⚠ **公式のほうが、⚠ 凡例も断りも整っている**
- ⚠ **同じ問いに答える実装を 2 つ持たない**（⚠ 掟 6）

## ⚠ タイルの 200/404 で出し分けない

⚠ **実測（2026-09-01・z14。hidetzu/konjaku#446 の本文）**

```text
地点      洪水（想定最大）  津波   高潮   土砂（土石流）
豊洲      200          404   200   404
浦安      200          200   200   404
春日部     200          404   404   404
渋谷      200          404   404   404
軽井沢     200          404   404   200
```

⚠ **取れる／取れないは分かる。**⚠ **それでも出し分けない**（Owner 判断）。

⚠ **理由**: ⚠ **出し分けると「404 だった＝その災害の想定が無い」に読まれる。**
⚠ **取れなかったことと、⚠ 想定が無いことは別**（掟 §1）。
⚠ **こちらは、⚠ その地点に何の想定があるかを言わない。**⚠ **開いた先で読んでもらう。**

## ⚠ 副作用（決めたうえで残す）

⚠ **地盤の資料が両方とも無い地点では、⚠ 節ごと出ないので、⚠ この道も出ない**
（⚠ 海の上など）。⚠ **節の末尾に置くと決めたので、⚠ 節と一緒に消える。**
