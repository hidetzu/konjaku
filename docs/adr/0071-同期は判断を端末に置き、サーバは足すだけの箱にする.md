# 0071: 同期は、判断を端末に置き、サーバは足すだけの箱にする

- 状態: 採用
- 日付: 2026-08-29
- 関連: [0069](0069-端末をまたぐ手渡しは、サーバに置かず URL で渡す.md)、
  [0048](0048-散歩と家を分け、端末をまたぐのは URL で始める.md)、
  [0065](0065-保存は端末の中だけに置き、町名で見分ける.md)、
  [0008](0008-地名も座標も送らない.md)
- ⚠ **根拠の種別**: ⚠ **一般的な判断**（⚠ 実測ではない）。⚠ **利用者に見せて確かめてはいない。**

## 決めたこと

⚠ **同期を足すとき、⚠ 「同じ場所か」「どう混ぜるか」を、⚠ サーバに書かない。**
⚠ **サーバは、⚠ 行を預かって返すだけにする。**

```text
端末   同じ場所か（50m）／どう混ぜるか／いつ混ぜるか    ⚠ saved.js が持つ（既にある）
サーバ 誰のものか／預かる／返す                        ⚠ 判断しない
```

## なぜ

⚠ **`saved.js` は、⚠ すでに「同じ場所か」と「どう混ぜるか」を持っている**
（⚠ `findAt` は 50m、⚠ `merge` は足すだけ。⚠ [0069](0069-端末をまたぐ手渡しは、サーバに置かず URL で渡す.md) で入れた）。
⚠ **サーバにも書くと、⚠ 同じ問いに答える実装が 2 つになる**（`CLAUDE.md` §3）。

⚠ **2 つ持つと、⚠ 必ずずれる。**⚠ **しかも、⚠ ずれ方が見えにくい。**
⚠ **端末では「同じ場所」なのに、⚠ サーバでは別の行、⚠ という状態が普通に起きる**
（⚠ 50m は座標の丸めでは表せない。⚠ 30m 離れた 2 点は、⚠ どんな桁で丸めても
⚠ 同じにも別にもなりうる）。⚠ **そのとき利用者に見えるのは「同じ場所が 2 つ並ぶ」で、
⚠ どちらが正しいかは画面からは分からない。**

⚠ **この分け方には、⚠ もう 1 つ効き目がある。**⚠ **作業を 2 人で分けられる。**
⚠ **サーバ側は「50m とは何か」を一度も考えずに作れる**（⚠ 行を預かるだけ）。
⚠ **端末側は、⚠ 相手の実装を待たずに作れる**（⚠ 契約に合う偽のサーバで進む）。

## どう作るか

- MUST: ⚠ **記録に、⚠ 端末が作る id を持たせる**（⚠ 保存した瞬間に決まる。⚠ 二度と変わらない）。
  ⚠ **サーバはこれを、⚠ 中身を読まない印として扱う。**⚠ **座標から作らない。**
- MUST: ⚠ **サーバは、⚠ `(利用者, id)` が同じ行を 2 つ持たない。**⚠ **それ以上は判断しない。**
- MUST: ⚠ **混ぜるのは端末**（⚠ 受け取った行を `KonjakuSaved.merge` に通す）。
- MUST NOT: ⚠ **消したことを同期しない**（⚠ [0069](0069-端末をまたぐ手渡しは、サーバに置かず URL で渡す.md) と同じ）。
  ⚠ **片方で消したものが、⚠ 両方から消えるのを避ける。**
- MUST: ⚠ **失敗しても、⚠ 端末の控えを 1 件も減らさない。**
  ⚠ **同期は「増やす道」であって、⚠ 「置き換える道」ではない。**

## 何を失うか

- ⚠ **同じ場所が 2 行、⚠ サーバに残ることがある**（⚠ 別の端末で 30m ずれて保存したとき）。
  ⚠ **画面では 1 件に見える**（⚠ 端末が混ぜるので）。⚠ **サーバの中だけ増える。**
- ⚠ **消しても相手には残る。**
- ⚠ **端末が古いと、⚠ 古い混ぜ方のままになる**（⚠ サーバが直しても効かない）。

⚠ **どれも「利用者に嘘を見せる」side ではない。**⚠ **だからこちらを採る。**

## 決まっていないこと

⚠ **ここは Owner の判断が要る**（⚠ 実測では決まらない）。

- ⚠ **画面に出す言葉**（⚠ なぜログインが要るのかを、⚠ どう言うか）
- ⚠ **同期の頻度**（⚠ 押したときだけか、⚠ 保存のたびか）
- ⚠ **やめたい人が、⚠ 預けたものを消す道をいつ作るか**
