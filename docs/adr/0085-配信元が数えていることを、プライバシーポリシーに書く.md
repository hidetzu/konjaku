# 0085. 配信元が数えていることを、プライバシーポリシーに書く

- 状態: 決めた
- 日付: 2026-09-02

## ⚠ 何が起きていたか

⚠ **本番のプライバシーポリシーが、⚠ 嘘をついていた。**

```text
書いてあったこと   誰がどこを見たかは、数えていません
                   閲覧の記録も、広告のための記録も取っていません。

実際               ⚠ Cloudflare Web Analytics の beacon が、⚠ 全画面に差し込まれていた
```

⚠ **実測（2026-09-02・本番）**:

```text
⚠ ブラウザの名乗りで取ると、⚠ / ／ /about ／ /privacy の 3 画面とも beacon が 1 個入る
⚠ curl の既定の名乗りでは 0 個（⚠ だから、⚠ 手元の検査では出なかった）
⚠ <script src="static.cloudflareinsights.com/beacon.min.js" data-cf-beacon='{"token":"…"}'>
   ⚠ token が入っている＝有効
```

⚠ **これは repo に無い。**⚠ **配信側（zone）が差し込んでいる。**
⚠ **だから静的検査も実描画も見つけられなかった**（⚠ 実描画は手元のサーバに向けて走る）。

## ⚠ どうやって見つけたか

⚠ **`/about` に絵を入れたあと、⚠ 本番で「外へ 0 本」を確かめたら 1 本出ていた**
（`docs/adr/0084`）。⚠ **手元と実描画は 0 本だった。**⚠ **その 1 本が beacon だった。**

⚠ **本番で確かめていなければ、⚠ 見つかっていない。**
⚠ **「CI が緑でも仕様が正しいではない」の実例**（`CLAUDE.md` §2）。

## 決めたこと

⚠ **集計は止めない**（Owner 判断）。⚠ **プライバシーポリシーのほうを実態に合わせる。**

⚠ **書き方の条件**（Owner 指示）:

```text
⚠ 過剰に安心させる表現を避ける
⚠ Cookie / 保存領域による個人追跡と、⚠ 広告目的の追跡をしていないことは書く
⚠ ページ閲覧・表示性能を集計していることを、⚠ 正確に書く
⚠ Cloudflare 公式ドキュメントを根拠にする
```

## 根拠にした記述

⚠ **`developers.cloudflare.com/web-analytics/` の原文**（2026-09-02 に読んだ）:

> All you need to enable Cloudflare Web Analytics is a Cloudflare account and
> a JavaScript snippet on your page to start getting information on **page views and visitors**.

> The RUM beacon script **does not store any data in the browser or access any storage data**,
> such as cookies, localStorage, sessionStorage, IP address, or IndexedDB.

> Although the RUM service receives the client/source IP address …
> it **discards the IP address at the nearest Cloudflare data center** and does not store it
> in core databases or logs.

> Since RUM data does not use location services,
> it **may be processed in a different country or region from where it originated**.

⚠ **集計の項目**（Dimensions）: Country / Host / **Path** / Referer / Device type / Browser /
Operating system / Navigation type。

## ⚠ 「Cloudflare がそう書いている」と書く

⚠ **こちらで確かめたことにしない**（掟 §1）。⚠ **画面にもそう書く。**

```text
Cloudflare は「…」と書いています。⚠ こちらでは確かめられません。
ここに書いたのは、Cloudflare が公開している資料の記述です。
⚠ こちらで中身を確かめたわけではありません。
```

## ⚠ 検査のほうを直した

⚠ **静的検査 ⑲ は「数えていません」を要求していた。**⚠ **その主張が間違っていた。**

⚠ **検査は「守るべきこと」を固定するので、⚠ 間違った主張は間違ったまま固定される**
（`CLAUDE.md` §9）。⚠ **だから、⚠ 検査の側を直した。**

```text
前  "行動を追跡しないこと":       /数えていません|取っていません/
後  "誰が数えているかを名乗ること": /数えています/
    ＋ 集めているものの一覧 ／ Cookie ／ 接続元 ／ 国外処理 ／ 確かめていない断り
```

⚠ **7 通りにわざと壊して、⚠ 全部落ちることを確かめた。**

## ⚠ まだ無いもの

⚠ **本番に beacon が在ることを、⚠ 見張る検査は無い。**
⚠ **手元にも実描画にも現れないので、⚠ 本番へ向けないと測れない。**
⚠ **外の答えに依存する検査は置かないと決めている**（`CLAUDE.md` §9）ので、
⚠ **いまは置いていない。**⚠ **止めるときは、⚠ この文書を先に直す。**
