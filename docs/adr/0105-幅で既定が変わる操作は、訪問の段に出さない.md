# 0105. 幅で既定が変わる操作は、訪問の段に出さない

- 日付: 2026-09-11
- 状態: 採用
- 決めた人: Owner

## 何が起きていたか

`npm run stats` の「3. どこまで進んだか」は、訪問を分母に段を並べていた。

```text
訪問 → 調べた → くわしく → 深掘り → 保存 → 共有
```

**この「くわしく」だけ、画面の幅で意味が変わる。**

```text
public/top.css:82   .fold::before{content:"fold"; display:none}
public/top.css:83   @media (min-width:700px){ .fold::before{content:"open"} }
public/top.js:440   畳み直す() が、この印を読んで fold.open を決める
public/top.js:449   fold__sum を押したときだけ detail_view を送る
```

**700px 以上では「くわしく」が最初から開いている。**押す行為が存在しないので、
`detail_view` は **1 本も飛ばない**。

つまり `detail_view` は「くわしくを読んだ人」ではなく、
**「狭い幅で来た人が押した数」**だった。それを訪問（幅を問わない）で割っていた。

## なぜ痛いか

**「押されなかった」と「押す必要がなかった」が、同じ 0 になる。**
`CLAUDE.md` §1（観測されていない ≠ 存在しなかった）に当たる。

実測（2026-09-11・本番 `events_simple`・2026-09-06〜09-10 の 5 日・訪問 42）:

```text
訪問 42  →  調べた 30  →  くわしく 11  →  深掘り 7
```

**この 11 を「訪問の 26%」と読むと嘘になる。**
同じ実測の中に、痕跡も出ていた。

```text
調べた 3 回の 5 訪問   くわしく 0   深掘り 2
```

**くわしくを飛ばして深掘りへ行ったように見えるが、開いていただけかもしれない。**
どちらかは、いま持っている記録では**分けられない**。

## 決めたこと

**集計側で、「くわしく」を訪問の段から降ろす。**

```text
訪問 → 調べた → 深掘り → 保存 → 共有
```

- **記録の側は変えない。**`detail_view` はこれまでどおり送る
- **本数は「1. 日ごとの本数」に出る。**消してはいない。**段として使わないだけ**
- **「出していないもの」に、理由と一緒に載せる**（書き忘れと区別がつくように）

残った段は、すべて幅に依らない。`map_opened` は判定が出れば飛び、
深掘りは `page_load`（`page: deep`）で、どちらも押す操作を前提にしていない。

## 選ばなかった案

**① 画面の幅を記録する。**
`public/measure.js` は user-agent も端末の見分けも**採らないと決めている**（2026-09-06）。
幅を足すと、その約束と `/privacy` の字が動く。**段 1 つのために動かす話ではない。**

**② `detail_view` を、幅に依らず「読める状態になった」に変える。**
広い画面では常に 1 本飛ぶので、**段としては 100% になり、何も言わなくなる。**
しかも `docs/adr/0103` と同じ形で、**同じ列に 2 つの意味が混ざる期間ができる**。

**③ 広い画面でも最初から閉じておく。**
これは計測の都合で画面を変える話。**順序が逆**（`CLAUDE.md` §1）。
畳むかどうかは、読みやすさで決めるべきもの。

## 根拠が消えたら、落ちる

**この判断は `public/top.css` が幅で既定を変えていることに依っている。**
CSS がそれをやめたら、`detail_view` は段として使える指標に戻る。
**規則だけで持つと、片方だけ古くなる**（`CLAUDE.md` §3）。

`test/check/safety.mjs` が、両方を実際に見て結びつけている。

```text
CSS が幅で既定を変えている  かつ  段に「くわしく」がある   → 落ちる
CSS が幅で既定を変えていない                              → 落ちる（根拠ごと見直す合図）
```

**見るのは、実際に返った列**（字面ではない。コメントに書いた語を拾わないため）。
**わざと壊して、両方が落ちることを確かめた**（2026-09-11）。
