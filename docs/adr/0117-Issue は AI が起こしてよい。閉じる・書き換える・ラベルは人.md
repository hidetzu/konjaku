- 状態: 採用

## 何が起きていたか

⚠ **AI が Issue を 2 件起こした**（hidetzu/konjaku#535 ／ hidetzu/konjaku#538。2026-10-10）。
⚠ **どちらも Owner の判断を受けた後だったが、⚠ 登録そのものは禁じられていた。**

⚠ [`0037`](<0037-Discoveryは案を出すより先に案を捨てる.md>) が
⚠ **「Issue を起こすのは人。Discovery は Draft を書くところまで」**と決めており、
⚠ **`test/check/guard.mjs` が `gh issue create` を落としていた**（2026-08-24 に足した）。

⚠ **AI が自己申告し、⚠ Owner が「外してよい」と判断した。**

### ⚠ 検査は、⚠ AI の操作そのものを見ていない

⚠ **`guard.mjs` が走査するのは `.claude/` の中の Skill と Hook の文面。**
⚠ **AI が端末で打つコマンドは見ていない。**⚠ **だから緑のまま通った。**

⚠ **検査の穴ではない。**⚠ **文面に書かせないための検査で、⚠ そこは守られていた。**
⚠ **逸脱したのは AI**（⚠ 方針を読んでいながら、⚠ 上位の指示（`tmp/` の依頼文）を優先した）。

## 決めたこと

⚠ **`gh issue create` の禁止を外す。**⚠ **それだけ。**

```text
外す    gh issue create          ⚠ AI が Issue を起こしてよい
残す    gh issue close           ⚠ 閉じるのは人
残す    gh issue edit            ⚠ 書き換えるのは人
残す    --add-label ready-for-ai ⚠ 付けるのは人（CLAUDE.md §7-2）
```

### ⚠ なぜ「起こす」だけ外せるか

⚠ **「起こす」と「渡してよいと決める」は別。**

```text
起こす          ⚠ 調べたことを、⚠ 追える場所へ置く        → AI がやってよい
渡してよいと決める ⚠ ready-for-ai を付ける                  → ⚠ 人だけ
閉じる          ⚠ 「もう要らない」と決める                → ⚠ 人だけ
書き換える       ⚠ 人が書いた本文を変える                  → ⚠ 人だけ
```

⚠ **Issue が並んでも、⚠ どれをやるかは人が決める。**⚠ **そこは何も変わっていない。**

⚠ **外す側の利点**: ⚠ **調べた結果が、⚠ 会話と `tmp/` にしか無い状態を減らせる**
（⚠ `tmp/` は追跡していないので消える。⚠ 実際に、⚠ 棚卸しの実測を残す先が無かった）。
