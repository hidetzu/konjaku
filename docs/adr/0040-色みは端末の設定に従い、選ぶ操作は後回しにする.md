# 色みは端末の設定に従い、選ぶ操作は後回しにする

- 状態: 採用
- 日付: 2026-08-26
- 関連: [0039](0039-色を1か所に集め、色みを定義だけ置く.md) の続き。hidetzu/konjaku#96

## 決めたこと

| # | 決めたこと |
|---|---|
| 1 | ⚠ **`@media (prefers-color-scheme: light)` に従う。**⚠ **画面に操作を足さない** |
| 2 | ⚠ **明るい色みの値は、⚠ その `@media` の中の 1 か所にしか書かない** |
| 3 | ⚠ **色を全部トークンへ通し終えてから、⚠ 最後にこの節を開けた**（⚠ 順を逆にしない） |
| 4 | ⚠ **実描画は、⚠ 既定を「暗い」に固定する。**⚠ 明るいは、⚠ 指定したケースだけが見る |

## 1. ⚠ なぜ操作を足さなかったか

⚠ hidetzu/konjaku#96 は「端末の設定に従う／明るい／暗い の 3 つを選べる」を求めており、
⚠ **切り替えをどこに置くかを Human Decision として残していた。**

⚠ **2026-08-26 に Owner が判断**: ⚠ **まず端末の設定に従うところまでを入れ、
⚠ 選ぶ操作は別の Issue にする。**

⚠ **画面に新しい操作を足さずに、⚠ 明るい端末の人へ先に届く。**
⚠ **`/peel` は「別の場所を探す導線を足さない」**という決めごとがある（`.claude/rules/domain.md`）ので、
⚠ **どこに置くかは、⚠ それ自体で 1 つ考える価値がある。**⚠ **届けるのを、⚠ そこまで待たない。**

## 2. ⚠ 順を逆にしない

⚠ **色がトークンを通っていないうちに `@media` を開けると、⚠ 明るい設定の人だけが壊れる。**

```text
地は暗いまま ／ 帯と文字と操作だけ明るい
```

⚠ **落ちない。**⚠ **暗い設定の人には何も起きない**ので、⚠ 気づくのは明るい設定の人だけ。
⚠ **端末の設定は、⚠ 明るいほうが既定の人が多い。**

⚠ だから hidetzu/konjaku#96 は ⚠ **5 回に分けて、⚠ 先に色を全部通した**（`0039` の表）。
⚠ **この ADR は、⚠ その最後の 1 回。**

## 3. ⚠ 値を 2 か所に持たない

⚠ **`[data-theme="light"]` を併記しない。**⚠ **併記すると、⚠ 同じ値が 2 か所になる。**

```css
:root { …暗い色み… }
@media (prefers-color-scheme: light) { :root { …明るい色み… } }
```

⚠ **選ぶ操作を足す回に、⚠ 組み立て方ごと決め直す**（⚠ そのときは `[data-theme="dark"]` も要る）。
⚠ **いま先回りして両方書くと、⚠ 使われない側が古くなる。**

## 4. ⚠ 実描画の既定を「暗い」に固定した

⚠ **`prefers-color-scheme` を見るようにすると、⚠ ブラウザの既定（明るい）で全部が走る。**
⚠ **いまあるケースは、⚠ 暗い色みの画面に対して書かれている。**

⚠ **だから走者が `colorScheme: "dark"` を明示する**（`test/render.mjs`）。
⚠ **明るい色みは、⚠ `colorScheme: "light"` を指定したケースだけが見る。**⚠ **混ぜない。**

⚠ **混ぜると、⚠ 落ちたときに「色みの問題」と「その画面の問題」が分けられなくなる。**

## 5. ⚠ 何を検査に残したか

⚠ **静的検査だけでは足りない**（`CLAUDE.md` §2）。

```text
静的  明るい色みの定義がある／名前が揃う／コントラスト／枠の色が --bg と一致
実描画 ⚠ 端末の設定が明るいとき、⚠ **画面が実際に明るい色みになる**
```

⚠ **`@media` の条件を書き間違えても、⚠ 静的検査は「定義がある」としか言えない。**
⚠ **わざと 6 通り壊して、⚠ 落ちることを確かめた**（⚠ うち 3 通りは実描画でしか落ちない）。

⚠ **「明るい色みの値と一致する」だけでは足りない。**
⚠ **暗い色みと違うことまで見る**（⚠ 両方が同じ値なら、⚠ 何も切り替わらなくても通る）。

## ⚠ まだ言えないこと

- ⚠ **人が選べるとは言っていない。**⚠ **端末の設定に従うだけ**（⚠ 3 つのうち 1 つ）
- ⚠ **枠（`--line`）と `--ink-faint` は、⚠ 下限に届いていない**（⚠ この Issue の前から）
- ⚠ **地図と空中写真は、⚠ 色みで変えていない**（⚠ 資料の見え方）
