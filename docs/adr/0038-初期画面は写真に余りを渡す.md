# 判定が出たら道具を引っ込め、写真には「余り」を渡す

- 状態: 採用
- 日付: 2026-08-26
- 関連: [0031](0031-答えの区分名には意味を1行そえる.md)「何を犠牲にしたか」を置き換える

## 決めたこと

| # | 決めたこと |
|---|---|
| 1 | ⚠ **足りない縦は、⚠ 写真からではなく「答えを出すための道具」から出す** |
| 2 | ⚠ **写真の高さは定数で決めない。**⚠ **上に積んだものを実測した「余り」** |
| 3 | ⚠ **写真には下限がある。**⚠ 好みではなく、⚠ **出典と操作の足し算で決まる** |
| 4 | ⚠ **入らない条件は、⚠ 潰して入れない。**⚠ 入らないと認めて、⚠ 何を諦めたか書く |

## 1. 引っ込めるのは「道具」であって「答え」ではない

⚠ **判定が出たあとも、⚠ 答えを出すための道具が画面を占めていた。**
⚠ **文字を大きくするほど、⚠ 道具のほうが速く育つ**（375×667・16px → 24px）。

| | 既定 | 150% |
|---|---|---|
| 見出し（この土地は、昔なんだったのか？） | 31px | ⚠ **94px** |
| 1 つ目の問いの見出し（ここはどんな土地？） | 17px | 25px |
| ▶ と 🔊 の字 | 44px | 59px |

- ⚠ **見出しは読み上げに残す。**⚠ `display:none` にすると、⚠ 見出しの無い文書になる
- ⚠ **▶ と 🔊 はボタン（44×44）を残し、⚠ 字だけ畳む。**⚠ 同じことを `aria-label` が言っている

### ⚠ 検索欄は畳まない

⚠ **一度畳んで、⚠ 戻した。**⚠ **機能を消していた。**

```
未選択  「地名・住所を入力」                            ＝ 場所を決める
選択後  「豊洲 で調べる（例: ごはん、公園、歯医者、昔）」  ＝ ⚠ その場所で探す
```

⚠ **高さだけを見て、⚠ 何をする欄かを読んでいなかった。**⚠ 実描画が 3 件で捕まえた。

## 2. 写真は「余り」を取る

⚠ **以前は、⚠ 上に積んだものの合計を CSS へ手で写していた。**

```css
max-height: calc(100dvh - 31.5rem)
```

⚠ **ビューポート単位と `rem` の引き算。**⚠ **`100dvh` は文字サイズで動かないのに、
`31.5rem` だけが比例して増える。**⚠ 拡大するほど引く量だけが増え、⚠ **写真が 2px になった。**

⚠ **上に積むものが変わるたびに測り直すことになる。**⚠ **しかも安全側に大きめ**なので、
⚠ **写真から余計に取っていた。**

⚠ **実測して渡す**（`--big-above`）。

```
--big-above = 写真の上端（文書の上端から） ＋ すき間 ＋ 「重ねる」の高さ
```

- ⚠ **どちらも写真の高さでは変わらない。**⚠ **だから 1 回で決まる**（⚠ 環にならない）
- ⚠ **JS が動かなくても壊れない。**⚠ CSS 側に既定値を残す
- ⚠ **検査は値ではなく仕組みを見る**（⚠ 上へ足したら、⚠ 写真が同じだけ縮むか）

## 3. 下限は足し算で決まる

```
帰属表示（国土地理院）  44px   ⚠ 出典は隠さない（0001 の系）
＋−（PC は縦積み）      68px   ⚠ 32 + 4 + 32
──────────────────────────────
                       112px
```

⚠ **これを割ると、⚠ ＋− は出典を隠さずに置けない。**
⚠ **切れた ＋− は「押しても何も起きない導線」**（[0026](0026-押しても何も起きない導線を置かない.md)）。
⚠ **computed style は切られても 44×44 のまま。**⚠ **座標を押さないと気づけない。**

## 4. 入らない条件は、潰して入れない

⚠ **横向き（高さ 360〜390px）では、⚠ 「重ねる」が初期画面に入らない。**
⚠ **写真を 2px まで潰しても、⚠ まだ 58〜90px 足りない**（実測）。⚠ **潰す意味が無い。**

⚠ **そこでは「重ねるが初期画面に入る」を諦め、⚠ 見える写真のほうを取る。**
⚠ **「重ねる」はスクロールで届く。**⚠ **2px の写真は、⚠ どこへも届かない。**

## 0031「何を犠牲にしたか」の、どこを置き換えるか

⚠ 0031 は「⚠ **足したぶんは写真の上限から出した。⚠ 他に出どころが無かった**」と書いた。

| | 0031（2026-08-22） | ⚠ ここ（2026-08-26） |
|---|---|---|
| 補助説明 | ⚠ **足す**（⚠ 変えない） | ⚠ **変えない** |
| 足したぶんの出どころ | ⚠ **写真の上限** | ⚠ **答えを出すための道具** |
| 写真の上限 | ⚠ 定数（`31.5rem`） | ⚠ **実測した余り** |

⚠ **「他に出どころが無かった」は、⚠ 道具を見ていなかったから。**
⚠ **補助説明を消すという結論には戻らない**（0031 は採用のまま）。

⚠ **検査へ字を書き写さない。**⚠ **持ち主から借りる**（⚠ 書き写していたら、⚠ 言い直したときに
製品ではなく検査が落ちた）。

## 何を犠牲にしたか

- ⚠ **狭い幅では、⚠ 上の余白が詰まる**（34+20+9 → 12+6+6px）。⚠ **広い幅では戻す**
- ⚠ **指の端末では ＋− が横並びになる**（⚠ 縦だと 92px 要り、⚠ 短い写真に入らない）
- ⚠ **横向きでは「重ねる」が初期画面の外**（⚠ 上の 4）
