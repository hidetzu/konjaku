# 0069: 端末をまたぐ手渡しは、サーバに置かず URL で渡す

- 状態: 採用
- 日付: 2026-08-29
- 関連: [0048](0048-散歩と家を分け、端末をまたぐのは URL で始める.md)、
  [0065](0065-保存は端末の中だけに置き、町名で見分ける.md)、
  [0067](0067-いまの場所は URL で渡し、年代は渡さない.md)、
  [0008](0008-地名も座標も送らない.md)

## 決めたこと

⚠ **保存した場所を別の端末へ移す口を、⚠ URL 1 本で作る。**
⚠ **サーバに何も置かない。**⚠ **アカウントも作らない。**

```text
スマホ   保存の一覧 →「PC やタブレットでも見る」→ リンクができる
PC       そのリンクを開く → 何が来たかを見せる → 押すと足す
```

## なぜ

⚠ **散歩中に保存し、⚠ 帰宅後に PC で深掘りする**、が v0.1.0 の筋
（[0048](0048-散歩と家を分け、端末をまたぐのは URL で始める.md)）。
⚠ **その筋は、⚠ 端末をまたげないと通らない。**

⚠ **同期は保留にしてある**（Owner 判断。2026-08-28。⚠ **却下ではない**）。
⚠ **保留のあいだ、⚠ 筋が通らないままにはしない。**⚠ **サーバを持たない形なら、
⚠ 同期を入れるかどうかの判断より先に置ける。**

⚠ **サーバに置かない理由は、⚠ 置くと「どこに置いたか」を守る話が始まるから**
（[0008](0008-地名も座標も送らない.md) が「地名も座標も送らない」と決めている）。
⚠ **URL に載せるなら、⚠ 送り先は利用者が選ぶ。**⚠ **こちらは受け取らない。**

## どう作ったか

- ⚠ **`public-next/saved.js` が持つ。**⚠ **DOM も圧縮も持たない**
  （⚠ 圧縮は呼ぶ側が渡す。⚠ ブラウザは `CompressionStream`、⚠ 検査は `node:zlib`）。
  ⚠ **持たせると、⚠ 検査がブラウザ抜きで回せなくなる。**
- ⚠ **先頭 1 文字で版を名乗る**（`1` = 生、`2` = 圧縮）。
  ⚠ **知らない版は `null` を返す。**⚠ **空配列を返さない**
  （⚠ 「0 件だった」と読める。[0001](0001-取れなかったを無いと言わない.md)）。
- ⚠ **混ぜるのは足すだけ。**⚠ **消さない。**⚠ 同じ場所（50m）でぶつかったら、
  ⚠ **先に見つけたほう（`at` が古いほう）を残し、⚠ 名前は在るほうを採る。**
- ⚠ **開いただけでは混ぜない。**⚠ **何が来たかを見せて、⚠ 押してもらう。**

## 何を失うか

- ⚠ **一方向。**⚠ **PC で保存したものは、⚠ 同じ手順を踏まないとスマホへ戻らない。**
- ⚠ **消したことは伝わらない。**⚠ 足すだけなので、⚠ 片方で消しても相手には残る。
- ⚠ **件数に上限がある**（⚠ URL 2000 文字。⚠ 超えたら渡さないと言う）。
  ⚠ **実測（2026-08-29）: 50 件で 生 5521 文字 → 圧縮 941 文字。⚠ 3 件で 288 文字。**

⚠ **これらは同期を入れれば消える。**⚠ **だから保留にしてある**（[0048](0048-散歩と家を分け、端末をまたぐのは URL で始める.md)）。
