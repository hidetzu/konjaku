# 0084. `/about` の絵は、今昔の実画面から作った作り置きにする

- 状態: 決めた
- 日付: 2026-09-02

## 何を決めたか

⚠ **`/about` の冒頭に、⚠ 今昔の実画面から撮った 2 枚だけを置く。**
⚠ **装飾のために描いた絵は 1 枚も置かない。**

```text
左   1936–42 の空中写真   一面が水面
右   いまの画面           台場の街
```

⚠ **実行時にタイルを読み込む形は採らない。**⚠ **作り置きの静的画像にする**（Owner 判断）。

## なぜ作り置きか

⚠ **`/about` は、⚠ いま外へ 1 本も出していない**（⚠ 実測 2026-09-02）。
⚠ **実行時にタイルを読むと、⚠ 読み物を開いただけで、⚠ 読者の接続元が配信元へ届く。**
⚠ **`docs/adr/0003` の「静的配信できるものは静的にする」とも向きが同じ。**

⚠ **実描画が「外へ 0 本」を主張している**（⚠ 3 幅）。⚠ **崩したら落ちる。**

## ⚠ 規約について、⚠ 読めたことと読めなかったこと

⚠ **これは「確認した」ではない。**⚠ **どこまで読めたかをそのまま書く。**

⚠ **地理院タイル一覧（`maps.gsi.go.jp/development/ichiran.html`）の原文**:

> 地理院タイルをウェブサイトやソフトウェア、アプリケーション上で**リアルタイムに読み込んで利用する場合**、
> 地理院タイルは出典の明示のみで申請不要でご利用いただけます。

⚠ **「リアルタイムに読み込んで」に条件が付いている。**⚠ **作り置きは、⚠ これに当たらない。**

| 使うもの | 一覧での区分 |
|---|---|
| 淡色地図 | ⚠ **1. 基本測量成果**（⚠ 備考「利用にあたっては『国土地理院の地図の利用手続』をご覧ください」） |
| 年代別の空中写真 | 2. 出典の記載のみで利用可能 |
| 明治期の低湿地 | 2. 出典の記載のみで利用可能 |
| 地形分類（提供実験） | ⚠ **一覧に見つけられなかった** |

⚠ **`www.gsi.go.jp`（利用手続の本文）へ到達できなかった**（⚠ `http=000`）。
⚠ **だから「申請が要る」とも「要らない」とも書かない。**
⚠ **言えるのは「静的な複製の要否を、⚠ こちらは確認していない」まで。**

⚠ **そのうえで Owner が、⚠ 出典と加工の明示を条件に、⚠ 作り置きで進めると判断した**（2026-09-02）。

## 画面に必ず添えるもの

```text
出典        国土地理院（⚠ 「出典」と「国土地理院」が同じ文にあること）
加工        今昔の画面で表示し、切り取ったこと
断り        原図そのままではないこと
リンク      地理院タイル一覧へ
```

⚠ **静的検査が 4 つとも見ている。**⚠ **「国土地理院」という語があるだけでは通さない**
（⚠ 実際に素通りした。⚠ **「国土地理院が公開している地理院タイル…」という別の文を拾っていた**）。

## ⚠ 場所は、お台場でなければならない

⚠ **豊洲では並べられない**（⚠ 実測 2026-09-02）。

```text
豊洲    1936–42 の写真   ⚠ 既に陸（飛行場）。⚠ 水は写っていない
お台場  1936–42 の写真   ⚠ 一面が水面
```

⚠ **「河川・湖沼・海面」は明治期の資料が言っていること**で、⚠ **1936 の写真が言っていることではない。**
⚠ **豊洲で並べると、⚠ 写真が言っていないことを言ったことになる**（`CLAUDE.md` §1）。

## 1 組だけにする

⚠ **増やすと、⚠ 下の「言えないこと」まで届く人が減る。**

```text
             375px      1280px
いま         2511px     1723px
1 組（採用）  2819px     2048px
3 か所        4469px     4929px   ⚠ 採らなかった
```

⚠ **静的検査が「2 枚」を見ている。**⚠ **増やすと落ちる。**

## 作り方

```bash
npm run about-hero            # 撮り直して manifest を書く（⚠ Playwright と通信が要る）
npm run about-hero -- --check # 撮らずに、manifest と実ファイルを突き合わせる
```

⚠ **`--check` は通信もブラウザも要らない。**⚠ **だから CI の静的検査から呼べる**
（⚠ `--count` がブラウザを読み込んで CI で落ちた件と同じ轍を踏まない。`CLAUDE.md` §9）。

⚠ **いつ・どこで・どうやって撮ったかは `assets/about/hero.json` にある**（`CLAUDE.md` §6）。
