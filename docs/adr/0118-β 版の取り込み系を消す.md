# 0118. β 版の取り込み系を消す

- 日付: 2026-10-10
- 状態: 採用
- 決めた人: Owner（⚠ **理由: 「今後のコンテキストに影響する」**）
- hidetzu/konjaku#538

## 何が起きていたか

⚠ **棚卸し（2026-10-10）で、⚠ 出力も読み手も無いスクリプトが 10 本あった。**

```text
ingest-wikidata  export-tiles   ingest-buildings  export-buildings  pack-buildings
build-water      export-assets  export-places     fetch-buildings   bl-format
```

⚠ **実測**:

```text
public/data/ の中身   area-record / landform / landuse-code / monument/ / muni / swale-legend
                      ⚠ data/bl も data/ev も *-water.geojson も *-buildings.geojson も無い
画面が読むか          git grep "data/bl\|data/ev" -- public/  → ⚠ 0 件
                      git grep "建物" -- public/              → ⚠ コードに 0 件
CI が呼ぶか           .github/workflows/ → ⚠ 0 件
検査が呼ぶか          test/ → ⚠ 0 件
```

⚠ **β 版（`/peel`）の 3D・建物・Wikidata 用で、⚠ ADR 0080 で降ろしたときに `scripts/` だけ残った。**

⚠ **`docs/data-rebuild.md` は既にこう書いていた**: ⚠ **「消すかどうかは、まだ決めていない
（決めたら、ここも直す）」。**⚠ **今日決めたので、⚠ そこも直した。**

## 決めたこと

⚠ **消す。**⚠ **理由は Owner の言葉で「今後のコンテキストに影響する」。**
⚠ **次に調べる人（⚠ AI を含む）が、⚠ 同じ調査を繰り返す。**

### ⚠ 残したもの（⚠ 消す対象と見分けがつきにくい）

```text
db.mjs            ⚠ survey.mjs が使う
check-tiles.mjs   ⚠ 調査の道具（⚠ 江東区の年代タイルの穴を実測する）
swale-sample.mjs  ⚠ 調査の道具（⚠ 参照は 0 になったが、survey-* と同じ性質）
survey-*.mjs 6 本 ⚠ 人が手で走らせる道具（⚠ npm script に無いのは意図的）
seeds/            ⚠ survey.mjs が読む
build-landform    ⚠ public/data/landform.json が実在する
```

### ⚠ 連鎖の対応

```text
scripts/survey-when.mjs  ④「Wikidata の点」が ingest-wikidata.mjs を readFileSync で読み、
                         プロパティ番号を抜いて報告していた → ⚠ 節を外した
                         ⚠ 番号をこちらへ写さない（⚠ 配っていないものの仕様を 2 か所に持つことになる）
docs/data-rebuild.md     ⚠ 「β 版の道具について」を「消した」に書き直した
public/swale.js          ⚠ コメントの build-water.js 参照に「消した」を添えた
public/verify.js         ⚠ 同上
scripts/swale-probe.mjs  ⚠ 同上
package.json             ⚠ npm script 9 個を外した（26 → 17）
```

## ⚠ また要るときに何を見るか

⚠ **git 履歴**（⚠ `aee67c2` より前には出力もあった）。
⚠ **建物・3D をやるときは書き直しになる。**⚠ **`CLAUDE.md` §3 は
「Overpass の実行時依存拡大」「Wikidata の実行時クエリ拡大」を理由なく導入しないと書いている。**
⚠ **だから、⚠ 戻すなら ADR が先。**

⚠ **`public/data/` を 0 から作り直す手順は失われていない**（`docs/data-rebuild.md` §1〜§4 は別の口）。

⚠ **実測（2026-10-10）: 消したあとも緑。**⚠ **コメントの参照には「消した」を添えた**
