# `/peel` の HUD は、年代の表示と操作だけを持つ

- 状態: 採用
- 日付: 2026-08-22
- 関連: [0026](0026-押しても何も起きない導線を置かない.md) ／
  [0030](0030-土地の答えは確実性の高い順に3層で出す.md)（⚠ **層の順は変えない。⚠ 置き場所だけ決める**）

## 決めたこと

| # | 決めたこと |
|---|---|
| 1 | ⚠ **HUD が持つのは、⚠ いまの年代と、⚠ 年代を動かす道具だけ** |
| 2 | ⚠ **土地の答えと分母は HUD に置かない。**⚠ 情報パネルの 1 か所が持つ |
| 3 | ⚠ **注意・精度・操作のヒントは、⚠ HUD の外の独立した層**（`#notice`）が持つ |
| 4 | ⚠ **年代の器は 1 つ。**⚠ **中身の無い箱と、⚠ それを開閉するボタンを作らない**（0026） |
| 5 | ⚠ **消すのは器であって、字ではない。**⚠ 年・撮影種別・接続の名乗りは残す |

## なぜ

⚠ **`/peel` は地図が主役**（`.claude/rules/domain.md`）。⚠ **HUD は地図の上に乗る。**
⚠ **HUD に別の責務を足すと、⚠ 足すたびに地図が減る。**⚠ 減った場所は戻らない。

⚠ **実際に 2 つ起きた。**

1. ⚠ **同じことを 2 か所で言っていた。**土地の答えと分母が、⚠ **HUD と情報パネルの両方**にあった
   （hidetzu/konjaku#152）。⚠ **どちらが正か、画面からは決まらない。**
2. ⚠ **押しても何も起きない導線ができた。**補足を外へ出したあと、
   ⚠ **`#era` に残ったのは、⚠ 中身が空の箱を開閉するボタンだけ**になっていた
   （hidetzu/konjaku#194）。⚠ **0026 に真正面から反する。**

⚠ **どちらも「HUD が何を持つか」を決めていなかったから起きた。**

## 持ち主

| | 誰が持つか |
|---|---|
| 年代の字（共有された年代の 1 行 ほか） | `public/words.js` の **1 か所**（hidetzu/konjaku#180） |
| いまの年代と、年代を動かす道具 | HUD（`#timePanel`） |
| 注意・精度・操作のヒント | ⚠ **HUD の外の層**（`#notice`） |
| 土地の答えと分母 | 情報パネル（`#panel` → `#result`）の **1 か所** |

## 何を犠牲にしたか

⚠ **年代を動かしながら、⚠ 分母を同時に読むことはできなくなった。**
⚠ **同じ画面に両方を出すと、⚠ 地図が主役でなくなる**ので、⚠ **こちらを取った。**

⚠ **答えを消したのではない**（掟 §1）。⚠ **場所を 1 つに決めただけ。**
⚠ **情報パネルは、押さなくても見えている**（上の実測）。

## この決めごとを、どう守るか

⚠ **文書だけでは守れない。**⚠ **画面の姿は検査が持つ**（`docs/SPEC.md` に寸法を書かない）。
⚠ 実描画が、⚠ **HUD に答えが戻っていないこと**と、⚠ **補足が HUD の外に居ること**を見る。
