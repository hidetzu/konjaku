## ⚠ 検査を 1 つ直した

⚠ **例外を認めたら、⚠ 検査が「引き込んでいない」と言い続けるのは嘘になる。**

```text
一覧に無いものを引き込んだ   ✗  ⚠ 落ちる
一覧にあるものだけ           ✓  ⚠ **「一覧に書いたものだけ」と名乗る**
何も引き込んでいない         ✓  ⚠ 「引き込んでいない」と名乗る
```

⚠ **数えた字が、⚠ 実際に見たものと食い違ってはいけない**（`CLAUDE.md` §1）。

⚠ **両方向で確かめた**（2026-08-29）:

```text
許した words.js を引き込む      →  ✓（⚠ 「一覧に書いたものだけ」と出る）
許していない photos.js を引き込む →  ✗ 1 件の問題
```
