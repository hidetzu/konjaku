# 生物（GBIF）と出来事（Wikidata の時点）は、自動取り込みでは載せない

- 状態: 採用（自動取り込みの道は閉じる。seed でキュレートしたものだけ検討可）
- 日付: 2026-08-14

## 何が問題だったか

オーナーの案:

> 海のような場合は、どんな魚がいるか、どんな動物・植物があるかは、建物とは違う入れものとして
> 基盤はあるから、それを上手く使うと色々のせることできる。
> あと以前に言っていた、特定の年代のニュースなんかもこれに含めてもいい。

**スキーマは乗る。** `feature` の `kind` は CHECK 制約なしの TEXT で、増やすだけで入る。
`source_url` も `precision` もある。足りないのは `importance` ではなく「**位置の確からしさ**」だった。

## 何を測ったか

### 生物（GBIF API を実際に叩いた）

```
日本・座標あり 全12,038,498件   1936–1990: 2,853,672
ライセンス  CC-BY 73% / CC-BY-NC 25% / CC0 1.4%
```

**しかし z14（≒1.6km四方）の粒度に落とすと:**

```
豊洲 bbox  全340件   1936–1990:  5件   2011年以降: 333件（97%）
渋谷 bbox  全871件   1936–1990:  7件   1800–1935: 104件
```

**古い記録は「点」ではない。** 渋谷の 1800–1935 の104件は全部が標本で、`locality` は「Shibuya」＝**区名**。
座標の誤差記載は **2/100**。豊洲のサンプルには `coordinateUncertaintyInMeters = 28,649m`（**28.6km**）の記録が18件。

この製品は「明治期の資料は位置誤差を含む。街区単位の判断に留めてください」を常時表示している。
**28.6km の点を、街区の写真の上に置くことはできない。**
低湿地の誤差は凡例に明記されているぶんまだマシで、GBIF の誤差は **98%が未記載**。
「誤差がある」ではなく「**誤差が分からない**」。

加えて presence-only（在るという記録しか無い）なので、**「観察されていない ≠ いなかった」を出し方で解けない。**
5件を出せば「1961年の豊洲にはこの5種がいた」と読まれ、出さなければ意味が無い。

### 出来事（Wikidata の `P585` 時点 ＋ `P625` 座標）

```
渋谷 10項目 ／ 豊洲 2項目 ／ 上野 1項目 ／ 広島 2項目 ／ 長崎 1項目
```

**広島で決定的なものが出た。**

```
広島 bbox:  「日本への原子爆弾投下」  1945-08-09   ← 長崎の日付
           「広島市への原子爆弾投下」 1945-08-06
長崎 bbox:  「日本への原子爆弾投下」  1945-08-09
```

**国全体の項目が、広島にも長崎にも座標を持って落ちてくる。しかも日付は長崎の8月9日。**
実装すれば、広島の 1945–50 の空中写真の上に「1945年8月9日」と出る。
**座標も年も出典も「揃っている」ので、画面は何も警告しない。**

そのほか: 豊洲で返ってきたのは既に名指しで否定した「東京空襲」そのもの（しかも `precision 8` ＝年代）／
「2020年東京オリンピックのハンドボール競技」に `P585` が 2020 と 2021 の2つ（延期）／
二・二六事件（1936）が渋谷の枠に落ちる（実際は永田町・三宅坂一帯）。

## 決めたこと

- **生物は載せない。** 誤差が分からないものは、街区の写真の上に置けない
- **出来事の自動取り込みの道は閉じる。** 点ではないものを点に置く問題から逃げようがない
- やるなら **seed でキュレートしたものだけ**（`source='seed'`, `verified=1`）、
  かつ**印を打たず、範囲についての注記としてテキストだけ**。
  上野戦争・淀橋浄水場・出島のような**場所と一体の出来事**に限る
- `coverage.layer` は**層ごとに分ける**。`ev` の0件は「年つきの事物が無い」、
  生物の0件は「**誰も観察していない**」で、意味がまったく違う

## 代わりにやること

**追加通信ゼロで効くものが、既に配っているデータの中にある。**

`ev` の 2,367件は `station` / `school` / `park` という `kind` を持っているのに、
画面が `あった` / `できた` / `無くなった` で上書きして捨てている。
**新しいデータを探す前に、既に配っているものの種類を画面に出すほうが先。**
追加通信ゼロ、新しい出典ゼロ、リスクゼロ。

⚠ この上書きは読み上げ・並べ替え・描画の3箇所が同じ値を見ているので、**対で直す**（0021）。
