# 既知の未解決事項は、内容が分かる名前で残す

- 状態: 採用
- 日付: 2026-08-15

## 決めたこと

未解決事項をコードに残すときは、コメント単体で問題が分かるように書く。
リポジトリの移動で意味が変わるため、Issue 番号だけを根拠にしない。

この ADR は公開リポジトリの Issue へ移すまでの台帳である。
Issue を作成した項目は受け入れ条件を Issue へ移し、ここから削除する。

## 現在の未解決事項

### Service Worker が地形分類タイルを保存しない

判定の根拠となる地形分類タイルは `maps.gsi.go.jp/xyz` にあるが、
`public/sw.js` の `isTile` は `cyberjapandata.gsi.go.jp` だけを対象にしている。
同じ対象漏れが `scripts/cost.mjs` にもある。

### 建物タイルが Service Worker の版ごとに捨てられる

`public/sw.js` は `/data/ev/` と `.geojson` をキャッシュ対象から外す一方、
`/data/bl/` は版付きキャッシュへ入れる。版が変わると建物タイルを取得し直す。

### ブラウザの文字サイズ設定が効かない

画面の `font-size` は px 固定で、利用者がブラウザの既定文字サイズを変えても追従しない。
CSS 変数を rem ベースへ移す必要がある。

- `public/index.html` — 文字サイズの項目をコメントから参照する
