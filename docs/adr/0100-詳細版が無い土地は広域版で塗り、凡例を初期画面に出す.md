# 0100. 詳細版が無い土地は広域版で塗り、凡例を初期画面に出す

- 日付: 2026-09-06
- 状態: 採用
- 決めた人: Owner（絵を並べて決めた）
- hidetzu/konjaku#494

## 何が起きていたか（実測 2026-09-06・`87a35cc`）

地形分類には 2 種類ある。

```text
詳細版      z14〜16   主要平野部だけ
広域版・地域版 z5〜13  全国
```

**判定は詳細版が無ければ広域版へ落ちていた。地図だけが落ちていなかった。**

```text
        z16                    z13
豊洲    5 面                   5 面
軽井沢  404（詳細版が無い）     5 面
白馬    404                    2 面
高野山  404                    2 面
屋久島  404                    1 面
```

その結果、同じ地点で文章と地図が違うことを言っていた。

```text
軽井沢  文章  区分の名前を答える
        地図  塗り 0 画素・凡例 0 行
豊洲    文章・地図とも同じ（244,628 画素）
```

## 利用者役に見せた（実在の利用者ではない）

3 名に、色を塗った画面と塗らない画面だけを見せた（どちらが新しいかは伏せた）。

```text
どちらが分かりやすいか   塗る 2 名 ／ 塗らない 1 名
緑を「森・公園・緑地」と読んだ   3 名（全員）
塗らない側を「読み込み中かと思った」   2 名
```

**塗らない側を選んだ 1 名は、条件つきだった。**

> 色が何なのか画面のどこにも書いていないので、結局自分で勘で決めるしかなかった。
> 間違って覚えるくらいなら色がないほうがまし。
> 逆に言えば、色の意味を書いた小さな凡例が 1 行あれば、塗るほうが断然分かりやすい。

**1 名は、文章のほうを疑った。**

> 地図に無いのに、どこから低地だと言っているんだろう。

## 決めたこと

### 1. 詳細版が 1 面も取れなければ、広域版で塗る

判定はもともとそうしていた。**地図をそちらへ合わせる。**

粗いことは画面が別に言う（hidetzu/konjaku#495）。**ここで決めたのは、塗るかどうかだけ。**

### 2. 凡例を初期画面に出す

**色を塗るなら、意味も同じ画面に要る。**3 名全員が緑を「森」と読んだ。

畳んだのは 2026-09-03 の実測が理由だった（`docs/adr/0091`）。

```text
畳まない（丸ごと開く）  板が画面の 57%・見える地図 130px
畳む                    32% / 292px
凡例だけ出す            44% / 201px   ← いま
```

**あの数字は畳みを丸ごと開けたときのもの。凡例だけなら 44% で収まる。**
写真の年代と根拠は、畳んだままにする。

### 3. いちばん狭い幅では 2 種まで

3 種だと凡例が 2 段になる。

```text
320×640・軽井沢   3 種 → 板 47%・地図 177px（2 段）
                  2 種 → 板 44%・地図 201px（1 段）
```

**3 つ目は消えない。「ほか n 種を見る」に回る。**
**「ここ」の区分は必ず 1 つ目に入るので、自分の足元は必ず見える。**

**幅の数は CSS の 1 か所が持つ**（`#legend::before`）。`.fold::before` と同じやり方。
一度 `innerWidth < 344` と JavaScript に書いて、幅の数が 2 か所になった。

## 何を失うか

**板が高くなる。**

```text
320×640   38% → 44%   見える地図 235 → 201px
375×667   37% → 42%   262 → 228px
```

**地図が主役という向き（`docs/adr/0064`）からは、一段近づく。**
半分は超えていない。

## 何を見張るか

**静的検査**:

```text
凡例が畳む器の外にある（畳まない側）
凡例に出す数を CSS が決めている（#legend::before）
JavaScript がその数を読んでいる（自分で決めていない）
```

**実描画**:

```text
詳細版が無い土地で、地図が塗られる／凡例が初期画面に出る／足元が凡例の 1 つ目
詳細版が在る土地で、変わっていない
いちばん狭い幅で、凡例が 1 段・板が画面の半分を超えない
```

**4 本とも、わざと壊して、狙った理由で落ちることを確かめた。**

## 既存の検査を 2 つ書き換えた

**「凡例は畳む側」と主張していた検査が、静的・実描画に 1 つずつあった。**
どちらも正しく決定を記録していたが、その決定が変わった。
**書き換えた理由を、検査のコメントに残してある。**
