## ⚠ Owner Intervention は、⚠ この版では取れない

⚠ **実測（2026-09-05。Claude Code 2.1.261）。**
⚠ **拒否させたのに、⚠ 次の 3 つは 1 度も呼ばれなかった。**

```text
PermissionDenied ／ PermissionRequest ／ PostToolUseFailure
```

⚠ **設定 schema には名前が在る。**⚠ **呼ばれない。**
⚠ **だから「人が止めた瞬間」は観測できない。**⚠ **取れないものを、⚠ 取れることにしない。**

### ⚠ 代わりに取るもの

```text
通ったとき     PreToolUse:X → PostToolUse:X
止まったとき   PreToolUse:X            ⚠ PostToolUse が来ない
```

- ⚠ **名前は `tool_stopped`。**⚠ **「拒否」とは書かない**（Owner 指示）。
- ⚠ **止まった理由は分けていない**（⚠ 規則による拒否・中断・落ちた・時間切れが同じ形）。
- ⚠ **人がその場で押した拒否も同じ形になるかは、⚠ 確かめていない。**

## ⚠ 取れないものを、⚠ 記録自身が名乗る

```text
missing: ["intervention", "rework", "near_miss", "active_time", "completed"]
```

⚠ **欄が無いだけだと、⚠ 「0 件」と読まれる。**⚠ **0 件と、⚠ 観測していないは別。**

⚠ **精度優先。**⚠ **曖昧なら数えない**（Owner 指示）。⚠ **測って決めた**（⚠ 手元の返答 3631 本）。
