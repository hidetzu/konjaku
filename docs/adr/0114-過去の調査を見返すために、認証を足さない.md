# 0114. 過去の調査を見返すために、認証を足さない

- 日付: 2026-10-10
- 状態: 採用
- 決めた人: Owner（⚠ **探索の指示を出し、⚠ AI の調査結果を見て落とす判断をした**）

## 何を頼まれたか

⚠ **Owner の指示**（2026-10-10。⚠ **原文は `tmp/` にあり、⚠ 追跡していない。**
⚠ **だから要点をここへ引き写す**）:

```text
A. Personal
  kagima の Google アカウント認証の実装を参考に、
  「自分が過去に散歩・調査した場所を後から見返せる」体験を検討する。
  単に認証機能を移植するのではなく、
    なぜログインが必要なのか / 何を保存すると利用者価値になるのか /
    匿名利用との境界 / プライバシー / 今昔の既存体験を壊さないか
  から考えること。kagima のコードは実物を調査すること。
```

## 調べたこと（⚠ **実測・現物**）

### ⚠ 同じ問いに、⚠ 既に 2 つが答えている

```text
/saved           保存した場所の一覧（⚠ 端末の中。`public/saved.js`）
/api/handoff*    合言葉で、⚠ 別の端末へ渡す（`docs/sync-api.md`）
```

### ⚠ その既存機能が、⚠ ほとんど使われていない

⚠ **実測（2026-10-09・`npm run gate`。⚠ 分母は「読める」と出ている）**:

```text
保存率   3/96   3.1%    ⚠ 訪問 96 ／ 最小 50
深掘り率 16/96 16.7%
調べた率 73/96 76.0%
```

⚠ **保存は、⚠ 96 訪問のうち 3 件。**⚠ **その上に認証を載せても、⚠ 載せる先が無い。**

### ⚠ 効いたかどうかを、⚠ 測れない

⚠ **認証が効くとすれば「また来た人」に効く。**
⚠ **ところが「また来た人」は数えられないと決めてある**（[`0102`](0102-計測は日ごとに数え、位置は送らない.md)）。

```text
訪問の印は 1 日で消える  →  「昨日も来た人」は別の印になる
```

⚠ **測るには印を残し続ける必要があり、⚠ それは実質 Cookie を持つことになる。**
⚠ **`0102` は、⚠ それを持たないと決めた。**⚠ **だから、⚠ 認証の効果を読む道が無い。**

### ⚠ いまは「流入を増やす手」しか採らないと決めている

⚠ [`0112`](0112-成長は流入で測り、健康は率で測る.md) が、⚠ **採る手の決め方を持っている。**

```text
健康が安定・成長が止まる  ⚠ 流入を増やす手だけを採る
```

⚠ **実測（2026-10-09）**: ⚠ **健康は全部読める。**⚠ **流入は線（14 日で 7 件）に届かず 2 件。**
⚠ **認証は、⚠ 来た人の体験に効く手で、⚠ 流入を増やさない。**

### ⚠ kagima の認証を、⚠ そのまま持ってこられない

⚠ **実物を読んだ**（`~/work/private/kagima/src/auth/google.ts`。⚠ 2026-10-10）。

```text
Google OAuth（Authorization Code）   ⚠ confidential client。⚠ secret はサーバ
要求するのは openid と email だけ     ⚠ profile・picture・name は取らない
ID token の署名は検証しない           ⚠ Google から直接受け取り、⚠ 他へ渡さないから
現れるのはログインの 1 点だけ          ⚠ Google が落ちても、⚠ 既存の room は止まらない
```

⚠ **kagima はこれを ADR で明示的に許している**（⚠ `CLAUDE.md` §3 が runtime 依存を禁じており、
⚠ **その例外として ADR を立てている**）。

⚠ **今昔の側の約束**:

```text
docs/SPEC.md §1   サーバは 2 つの口しか持たない
CLAUDE.md §3      Runtime 依存を増やさない
```

⚠ **認証を足すと、⚠ 口が増え、⚠ runtime の依存先が増える。**
⚠ **kagima と同じ作りにできるかどうかではなく、⚠ 今昔がそれを引き受けるかどうかの話。**

## 決めたこと

⚠ **足さない。**

⚠ **「永久にやらない」ではない。**⚠ **次の 3 つが揃うまで、⚠ 検討に戻さない。**

```text
1  保存が使われている        ⚠ 保存率が、⚠ いまの 3.1% から上がっている
2  また来た人を数えられる     ⚠ `0102` の「印は 1 日で消える」を見直す判断が先に要る
3  流入が線に届いている       ⚠ `0112`。⚠ 届くまでは、⚠ 来た人の体験へ足さない
```

⚠ **1 つでも欠けていると、⚠ 作っても効いたかどうかが言えない**（`CLAUDE.md` §1）。

## ⚠ 代わりに言えること

⚠ **「過去に調べた場所を見返したい」が利用者の問いなら、⚠ 答える先は既にある。**
⚠ **足すより先に、⚠ `/saved` が使われていない理由を分ける**（⚠ **要らない** のか、
⚠ **気づかれていない** のか）。⚠ **これは別の判断で、⚠ `0112` の「健康側は磨かない」に当たる。**

⚠ **落とした理由と、⚠ 戻す条件を、⚠ 両方書いた。**
