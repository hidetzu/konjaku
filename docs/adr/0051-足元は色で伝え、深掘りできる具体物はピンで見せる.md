# 0051. 足元は色で伝え、深掘りできる具体物はピンで見せる

- 状態: 採用（⚠ **決めたのは Owner。**⚠ 2026-08-29）
- 日付: 2026-08-29

⚠ **`docs/adr/0049` が開いたままにしていた「A ピン主役 / B 面主役 / C 両方」の答え。**

## 決めたこと

```text
⚠ **自分がいまどんな土地の上にいるかは、⚠ 色で伝える。**
⚠ **そのうえで、⚠ 周辺にある「深掘りできる具体物」を、⚠ ピンで見せる。**
```

⚠ **順番に意味がある。**⚠ **色が先、⚠ ピンが後。**

- ⚠ **色は、⚠ どこに立っていても出る**（⚠ 面はほぼ全国で答えが出る）。
- ⚠ **ピンは、⚠ 在れば出る。**⚠ **無くても画面は成立する。**

⚠ **`docs/adr/0049` の 3 案でいうと C。**⚠ **ただし下の 1 点を含む。**

## ⚠ 保存の的は 1 つ（⚠ 2026-08-29 に絵で見つけた）

⚠ **絵に描いたら、⚠ `♡ あとで見る` が 2 か所に出た。**
⚠ **飾りではなく、⚠ **保存の対象が 2 種類あった**から**（⚠ 足元の「地点」と、⚠ ピンの「もの」）。

⚠ **1 つに絞る形**:

```text
⚠ **カードは 1 枚。**⚠ **中身が入れ替わる。**

  既定        📍 いまいる場所  →  ここは 旧水部       ♡ あとで見る
  ピンを押す   📌 この場所      →  豊洲橋（造船所）     ♡ あとで見る
```

⚠ **画面に ♡ は常に 1 つ。**⚠ **何を保存するかは、⚠ カードの見出しが名乗る。**

⚠ **Owner の見立て**（2026-08-29）: ⚠ **「足元レベルで覚えるより、
⚠ このエリアにある情報を PC で深掘りさせる」と捉えるほうがよい。**
⚠ **保存の単位を「地点」から「エリア」へ寄せる方向。**⚠ **ただし確定していない**（下の「決めていないこと」）。

## ⚠ なぜこの順番か（⚠ 測った）

⚠ **「へえ」は情報が出ることではなく、⚠ いまの見た目とのギャップから出る。**
⚠ **5 秒に入るのは「地図が出る → 読むものが出る → 読む → ギャップに気づく」まで。**

```text
A  ピン主役   地図 → ⚠ **ピンを見つける** → ⚠ **どれを押すか決める** → 押す → 読む
B  面主役     地図 → ⚠ **もう答えが出ている** → 読む
C  両方       ⚠ 既定は B と同じ。⚠ ピンは押した人だけの上積み
```

⚠ **A はタップが 1 回入るうえ、⚠ 「どれを押すか」の判断も入る。**⚠ **5 秒では届かない。**

⚠ **面のうち「へえ」が出る割合**（⚠ 実測 2026-08-29・市街地 18 か所の周辺・z16・27 タイル・
取得失敗 0 回。⚠ **分母は「その 18 か所の周辺」であって全国ではない**）:

```text
ギャップ大（いまと違う）        38.4%   盛土地･埋立地 22.6% ／ 旧水部 12.2%
ギャップ小（いまも見たとおり）  46.7%   台地･段丘 17.5% ／ 扇状地 12.1%
どちらとも言えない              14.9%   氾濫平野・海岸平野
```

⚠ **「ギャップ大／小」の振り分けは解釈。**⚠ **測ったのは面積の割合だけ。**

## ⚠ 「深掘りできる具体物」が何かは、⚠ 決めていない

⚠ **これは条件であって、⚠ 出典の名前ではない。**

⚠ **いま β 版が出しているものは、⚠ この条件を満たしていない**（⚠ 実測 2026-08-29・半径 1km）:

```text
豊洲   豊洲駅(1988) ／ 豊洲小学校(1947) ／ 豊洲北小学校(2007)
渋谷   渋谷スクランブルスクエア(2019) ／ SHIBUYA SKY(2019)
本郷   国道254号(1963) ／ 本郷三丁目駅(1954) ／ 本郷小学校(1998)
```

⚠ **どれも「いま目の前にあるもの」。**⚠ **「深掘りできる具体物」ではない。**

⚠ **原因は取り込み条件**（`scripts/ingest-wikidata.mjs` の `KINDS` 13 分類）。
⚠ **どれも現存する施設の分類で、⚠ 城跡・遺跡・寺社・古墳・廃駅・記念碑・伝承碑が 1 つも入っていない。**

⚠ **分類を広げて聞き直したら、⚠ 数字が変わった**（⚠ 詳細は `docs/adr/0049`）。
⚠ **ただし重複があり、⚠ 数として使うには数え直しが要る。**
