# 0049. スマホは街で見つける場所、PC は深掘りする場所

- 状態: 採用（⚠ **決めたのは Owner。**⚠ 2026-08-28。⚠ 原文は `tmp/tmp.md`）
- 日付: 2026-08-28

⚠ **`docs/adr/0048` の「散歩と家を分ける」を、⚠ 画面の役割まで下ろしたもの。**
⚠ **`docs/adr/0046` §② で「画面をいくつに分けるか決めない」としていたが、
⚠ **数ではなく端末で分ける**という答えが出た。**

## 決めたこと

```text
スマホ   ⚠ **街で見つける場所**   （⚠ 調べる場所ではない）
PC       ⚠ **保存した興味を深掘りする場所**
```

⚠ **スマホ版は、⚠ PC 版の縮小版にしない。**⚠ **散歩中に拾うための専用 UI として割り切る。**

### ⚠ スマホの役割は 2 つだけ

```text
1  場所を探す
2  気になった場所を残す
```

⚠ **スマホで深掘りさせない。**
⚠ **「もっと読む」「関連情報」「資料一覧」「年代別地図」を大量に置くと、
⚠ またスマホが PC 版に近づく。**

⚠ **スマホで足りるのは、ここまで**:

```text
へえ、そうだったんだ  →  気になる  →  保存
```

### ⚠ 画面の形（⚠ Owner の原案）

```text
スマホトップ
  ⚠ **大きな地図が主役**
  検索は、⚠ **別画面ではなく地図がその場所へ移動する**
  情報がある場所にピン（⚠ MVP は「情報あり」の 1 種類でよい）
  ⚠ **♡ あとで見る n** を主要導線として常に置く

ピンを押したとき
  ⚠ **地図を隠さずに、⚠ 下から軽いカード**
  地名 ／ 短い説明 ／ ♡ 後で見る ／ PC で詳しく見る →

あとで見る 一覧
  貯めた場所が並ぶ
  ⚠ **一覧の最後に「PC で続きを見る」**
  → メールでリンクを送る ／ QR コードで開く ／ 共有リンクをコピー
```

### ⚠ 「あとで見る」と「この場所を PC で見る」は役割が違う

```text
この場所を PC で見る   ⚠ いま見ている 1 地点を、⚠ すぐ PC へ渡す
あとで見る             ⚠ 散歩中に複数地点を貯める
```

⚠ **両方いっぺんに作ると複雑になる。**⚠ **MVP は「あとで見る」を中心にする**（Owner 判断）。

```text
散歩   場所A → ♡   場所B → ♡   場所C → ♡
         ↓
       あとで見る 3 件
         ↓
       PC で続きを見る
```

| ⚠ いつ位置情報を求めるか | ⚠ **決まっていない** |

⚠ **`docs/adr/0047` の「保存できることを明示する」は、⚠ この形なら別の解き方になる。**
⚠ **`♡ あとで見る n` が常に出ているなら、⚠ 明示は位置と字で済む**
（⚠ β 版に足す話ではなく、⚠ 作り直す側の話）。

## ⚠ 次に詰めるところ（⚠ Owner が指名した）

```text
⚠ 「検索結果を表示する画面」ではなく、
⚠ **「散歩中に地図を見た瞬間、⚠ 何が見えていれば 5 秒で興味を持てるか」**
```

⚠ **ここがスマホ版今昔のコアになる**（Owner）。

## ⚠ この形が前提にしていること ── ⚠ **測った**

⚠ **「情報がある場所にピンを出す」は、⚠ 点の情報を持っていることを前提にしている。**
⚠ **測ったら、⚠ そこに穴があった**（⚠ 2026-08-28）。

```bash
node scripts/pin-density.mjs
```

⚠ **数字は書き写さない**（`CLAUDE.md` §6）。⚠ **判断の分かれ目だけを書く。**

```text
⚠ **点（Wikidata の `ev/`）を配っているのは、⚠ 日本のごく一部の区画だけ。**
⚠ **配っている土地でも、⚠ 画面の短辺（≒900m）に見えるピンの数は 5 倍ひらく。**
⚠ **配っていない土地では 0 本。**⚠ **メモが例に挙げた浦安も、⚠ 0 本だった。**

⚠ **一方、⚠ 面（土地条件・低湿地・標高）は、⚠ ほぼ全国で答えが出る**
   （⚠ β 版の `judged.ok` がこれ）。
```

⚠ **つまり**:

```text
点（ピン）        ⚠ ごく一部の土地にしか無い   ⚠ 「見つける」の材料
面（足元の答え）  ⚠ ほぼ全国で出る             ⚠ 「知る」の材料
```

⚠ **メモの案は「ピンを見つける」を入口にしているが、
⚠ 今昔が全国で持っているのは「足元の答え」のほう。**

### ⚠ ここは実測では決まらない

```text
A  ⚠ ピンを主役にする        ⚠ 対応した土地でだけ成立する。⚠ 広げる作業が要る
B  ⚠ 足元の色を主役にする     ⚠ 全国で成立する。⚠ 地図が土地の色で塗られていて、
                             ⚠ そこを歩いている自分が見える（⚠ ピンは在れば出す）
C  ⚠ 両方                    ⚠ 面で塗り、⚠ 点が在る所にはピン
```

⚠ **決めていない。**⚠ **`docs/adr/0042` のとおり、⚠ 見え方は絵で決める。**

⚠ **走者が壊れたら静的検査が落ちる**（⚠ 点の範囲が 5% を超えたら、⚠ この ADR を見直す合図）。
