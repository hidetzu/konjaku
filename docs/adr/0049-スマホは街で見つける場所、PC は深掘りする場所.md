# 0049. スマホは街で見つける場所、PC は深掘りする場所

- 状態: 採用（⚠ **決めたのは Owner。**⚠ 2026-08-28。⚠ 原文は `tmp/tmp.md`）
- 日付: 2026-08-28

⚠ **`docs/adr/0048` の「散歩と家を分ける」を、⚠ 画面の役割まで下ろしたもの。**
⚠ **`docs/adr/0046` §② で「画面をいくつに分けるか決めない」としていたが、
⚠ **数ではなく端末で分ける**という答えが出た。**

## 決めたこと

```text
スマホ   ⚠ **街で見つける場所**   （⚠ 調べる場所ではない）
PC       ⚠ **保存した興味を深掘りする場所**
```

⚠ **スマホ版は、⚠ PC 版の縮小版にしない。**⚠ **散歩中に拾うための専用 UI として割り切る。**

### ⚠ スマホの役割は 2 つだけ

```text
1  場所を探す
2  気になった場所を残す
```

⚠ **スマホで深掘りさせない。**
⚠ **「もっと読む」「関連情報」「資料一覧」「年代別地図」を大量に置くと、
⚠ またスマホが PC 版に近づく。**

⚠ **スマホで足りるのは、ここまで**:

```text
へえ、そうだったんだ  →  気になる  →  保存
```

### ⚠ 画面の形（⚠ Owner の原案）

```text
スマホトップ
  ⚠ **大きな地図が主役**
  検索は、⚠ **別画面ではなく地図がその場所へ移動する**
  情報がある場所にピン（⚠ MVP は「情報あり」の 1 種類でよい）
  ⚠ **♡ あとで見る n** を主要導線として常に置く

ピンを押したとき
  ⚠ **地図を隠さずに、⚠ 下から軽いカード**
  地名 ／ 短い説明 ／ ♡ 後で見る ／ PC で詳しく見る →

あとで見る 一覧
  貯めた場所が並ぶ
  ⚠ **一覧の最後に「PC で続きを見る」**
  → メールでリンクを送る ／ QR コードで開く ／ 共有リンクをコピー
```

### ⚠ 「あとで見る」と「この場所を PC で見る」は役割が違う

```text
この場所を PC で見る   ⚠ いま見ている 1 地点を、⚠ すぐ PC へ渡す
あとで見る             ⚠ 散歩中に複数地点を貯める
```

⚠ **両方いっぺんに作ると複雑になる。**⚠ **MVP は「あとで見る」を中心にする**（Owner 判断）。

```text
散歩   場所A → ♡   場所B → ♡   場所C → ♡
         ↓
       あとで見る 3 件
         ↓
       PC で続きを見る
```

## ⚠ この形が前提にしていること ── ⚠ **測ったが、⚠ 測る対象を間違えた**

⚠ **「情報がある場所にピンを出す」は、⚠ 点の情報を持っていることを前提にしている。**

### ⚠ 2026-08-28 に測ったこと（⚠ **そのままでは使えない**）

```bash
node scripts/pin-density.mjs
```

⚠ **この走者が測っているのは、⚠ **β 版が配信しているタイルの範囲**。**
⚠ **「世の中にどれだけ点データがあるか」ではない。**

⚠ **2026-08-29 に、⚠ Owner の指摘で気づいた**（⚠ 「今の β 版で見えているデータに依存していない？」）。

### ⚠ 何を取り違えていたか

⚠ **β 版の取り込み条件は、⚠ `scripts/ingest-wikidata.mjs` の `KINDS` 13 分類**:

```text
building / structure / station / house / school / hospital / bridge
park / road / railway / port / airport
```

⚠ **どれも「現存する施設」の分類。**
⚠ **城跡・遺跡・寺社・古墳・廃駅・記念碑・伝承碑は、⚠ 1 つも入っていない。**

⚠ **つまり「Wikidata に昔のものが無い」のではなく、⚠ 「昔のものを取りに行っていない」。**

⚠ **分類を広げて聞き直したら、⚠ 数字が変わった**（⚠ 実測 2026-08-29・半径 1km 相当）:

```text
                β の取り込み（13 分類）   ⚠ 聞き直し（寺社・遺跡・城跡ほか）
大阪梅田         ⚠ **0 件**              ⚠ **上限 200 件に当たった**
名古屋栄         ⚠ **0 件**              ⚠ **上限 200 件に当たった**
浦安               5 件                    8 件（⚠ 大蓮寺 1544 / 正福寺 1593）
```

⚠ **ただし、⚠ この聞き直しにも重複がある**（⚠ 同じものが 3 回返る。⚠ `DISTINCT` を入れていない）。
⚠ **数として使うには、⚠ 数え直しが要る。**

### ⚠ 何が言えて、何が言えないか

```text

           ⚠ **面（土地条件・低湿地）は、⚠ ほぼ全国で答えが出る**

言えない   ⚠ **世の中にある点データが少ない**  ← ⚠ **これは測っていない**
```

⚠ **測り直す先**（⚠ どれも未測定）:
