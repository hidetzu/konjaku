# 0056. データの状態を 3 つに分けて言い分ける

- 状態: 採用（⚠ **決めたのは Owner。**⚠ 2026-08-29。⚠ 原文は `tmp/tmp2.md`）
- 日付: 2026-08-29

⚠ **`docs/adr/0055` は「分類情報とデータ可用性を、⚠ 同じ凡例に混ぜない」と決めた。**
⚠ **では、⚠ 可用性のほうを何と言うのか。**⚠ **その答え。**

## 背景

⚠ **国土地理院の「明治期の低湿地」は 2023 年に「整備完了」とされているが、
⚠ **全国を隙間なく整備したという意味ではない**（`tmp/tmp2.md`）。**

⚠ **つまり、⚠ 少なくとも 3 つの状態がある。**

## 決めたこと ── ⚠ **3 つを別のこととして扱う**

```text
① ⚠ 整備範囲内で、⚠ 区分あり      → ⚠ 「水田」「河川」「湿地」などを表示する
② ⚠ 整備範囲内だが、⚠ 区分が無い  → ⚠ **明治期の地図はあるが、⚠ 該当分類が無い**
③ ⚠ **そもそも整備範囲外**        → ⚠ **この地域には、⚠ 明治期の低湿地データが作られていない**
```

⚠ **② と ③ を、⚠ 同じ言葉で言わない。**

```text
②  「⚠ まだ調べられていません」          ⚠ ← 調べる対象ではあった
③  「⚠ この地域では作られていません」     ⚠ ← 調べる対象に入っていない
```

⚠ **どちらも「無い」ではない**（掟 §1）。⚠ **「取れなかった」でもない。**⚠ **別のこと。**

## ⚠ 機械で分けられる（⚠ 実測 2026-08-29・13 地点）

```bash
node scripts/survey-swale.mjs
```

⚠ **数字は書き写さない。**⚠ **判断が変わったところだけ書く。**

```text
⚠ **③ は、⚠ タイルが 404 で返る。**⚠ **那覇・稚内・高知・石垣。**
⚠ **①② は、⚠ タイルが 200 で返る。**
⚠ **200 が返る地点では、⚠ 透明画素がどこも 0%。**
```

⚠ **`HTTP 200` を「データがある」と読まない**のは変わらないが、
⚠ **`404` が「整備範囲外」の合図になる**ことが分かった。

## ⚠ 踏んだこと ── ⚠ **下地を「整備の穴」と読み違えた**

⚠ **前の測定で「凡例に当たらない画素が 9〜33% ある」と報告し、
⚠ それを「整備されていない土地」と読んでいた。**⚠ **違った。**

```text
⚠ **あれは地図の下地**（⚠ 道路・注記・背景）。
⚠ **透明画素が 0% であることが、⚠ その証拠。**
```

⚠ **`public/swale.js` は、⚠ 透明と凡例外を別々に数え、⚠ どちらも分母から外している。**
⚠ **こちらはそれを混同していた。**⚠ **走者を、⚠ 3 状態が分かる形に直した。**

## ⚠ 公開範囲図と、⚠ 配信されているタイルが一致していない

⚠ **公開範囲図では対象外に見える地点でも、⚠ 凡例色が取れる**（⚠ 網走・釧路・札幌・盛岡・長野）。

⚠ **これは測れた事実。**⚠ **どちらが正しいかは、⚠ こちらでは分からない。**
⚠ **だから「公開範囲図に載っているか」で判定しない。**⚠ **実際に取れるかで判定する。**

## ⚠ 画面がどうなるか

```text
①  豊洲    ⚠ 断り書き無し
②  網走    ⚠ 「斜線の部分は、⚠ まだ調べられていません」   ⚠ **凡例の外**（`docs/adr/0055`）
③  那覇    ⚠ 「明治期の低湿地は、⚠ この地域では作られていません」
```

⚠ **③ でも、⚠ 足元と凡例はいつもどおり出る。**
⚠ **地形分類は別のデータで、⚠ 那覇でも取れることを確かめた**（⚠ 標高も取れた）。
⚠ **無いのは明治期の低湿地だけ。**

⚠ **「何も出せません」にしない。**⚠ **出せるものは出す**（`CLAUDE.md` §4-1）。

## ⚠ 決めていないこと

```text
⚠ 断り書きの字（⚠ 上の 2 つは案。⚠ **画面に出る言葉は Owner が決める**）
⚠ ③ のとき、⚠ 断り書きを常に出すか（⚠ 出すと、⚠ 那覇では毎回出る）
⚠ 地形分類（別データ）にも同じ 3 状態があるか（⚠ **測っていない**）
⚠ ほかの出典（⚠ 空中写真・建物）の状態を、⚠ 同じ枠で扱うか
```

⚠ **3 つ目は、⚠ 網走で「区分が無い」が 18% 出ていたので、⚠ 地形分類にも ② が在ることは分かる。**
⚠ **③ が在るかは測っていない。**
