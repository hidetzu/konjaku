# 主題は「その土地はどうやってできたか」。明治期の低湿地は手法のひとつ

- 状態: 採用
- 日付: 2026-08-11（旧 §3.25）

## 何が問題だったか

見出しに「明治期に何だったか」と書いていた。**手法の名前が主題の名前を乗っ取っていた。**

主題はずっと「その土地はどうやってできたか」だった。明治期の低湿地を使っていたのは、
それが手に入る手法だったからであって、「明治期」そのものが主題だったからではない。

そして手法の当たり率が低いことを、主題の限界として受け取っていた。
0001 で「狙いの客を首都圏の埋立地・低地住民に絞る」と決めたのも、
**「判定が出る範囲と一致するから」**という、この取り違えの上に乗った理由だった。

## 何を測ったか

```
                 明治期の低湿地      地形分類
全国24地点        7 / 24 (29%)      24 / 24 (100%)（都市部の詳細版）
```

両方取れる土地では、**同じことを別の手法が独立に言う**:

```
豊洲   地形分類: 旧水部 ＋ 盛土地･埋立地
       明治期:   水面
```

地形分類は 36区分あり、**成因と災害リスクの文が国土地理院自身の記述として付いている**
（`public/data/landform.json`。図式コード 100 → 36区分）。

## 決めたこと

- 主題を「その土地は、どうやってできたか」と言い直す。**方針転換ではなく取り違えの訂正**として記録する
- **地形分類を判定の先頭にする**（z16 詳細版 → z13 広域版の二段構え、粒度を画面に明示）
- **明治期の低湿地は捨てない。** もうひとつの手法として残し、両方あるときは両方見せる
- 成因・災害リスクの文は**国土地理院の記述をそのまま使う**。こちらで書かない
- 判定文「この場所は 旧水部 で、いまは 盛土地･埋立地 です」は変えない
- 「首都圏の埋立地・低地住民」への絞り込みは**前提が消えたので保留**。誰に向けるかは共有率を観測してから決め直す

## そうしなかったこと

- **明治期の軸を手放して地形分類だけにする** … 時間の主張が消える。両方取れる土地で答えが厚くなる利点を捨てることになる
- **二本立てを「並列の2機能」として見せる** … 手法が2つあることは利用者の関心ではない。主題は1つ
- **z16 が無いときに z13 の答えを黙って出す** … 「詳細版が無い」と「分類が無い」は別のこと。「（広い区分）」と書く

## これを守っているもの

- `public/verify.js` — 地形分類が先頭。1文目は「どうやってできたか」。成因の文は地理院の記述をそのまま
- `public/index.html` — 色（青＝水由来）は地形分類が主。明治期はもうひとつの手法
- `npm run render` の `明治期が無くても、地形分類から語が出る` / `詳細版が無い土地では、粗いと言う` /
  `ランチャー（水域だが高台）` / `粗いカードに、粗いと書く`
