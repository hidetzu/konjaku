# 取り込むのは、商用利用できるデータだけ

- 状態: 採用
- 日付: 2026-08-22

## 決めたこと

⚠ **`public/data/` に置いて配るのは、商用利用が許されているデータだけ**にする。

⚠ **迷ったら入れない。**⚠ 入れたいときは、**先に配布元へ問い合わせてから**決める。

## なぜ

⚠ **「いつか稼ぐかもしれないから」ではない。**⚠ **いまの形と噛み合わないから。**

### 1. ⚠ 非商用のデータは、無料で運営していても引っかかりうる

⚠ 国土数値情報の旧約款（原文）:

> （ｂ）「非商用」＝出典・加工者等表示のうえ、原著作者等の許諾上、
> **非商用目的のみでの利用（ただし複製物の再配布を除く）**が可能なもの

⚠ **konjaku は事前に取り込んで `public/data/` から配っている。**
⚠ **これは複製物の再配布にあたる。**⚠ 無料で運営し続けても、そこは変わらない。

⚠ 同じ約款は、こうも書いている。

> 「非商用」の「国土数値情報」であっても、GISによって空間演算した結果
> （データベースでないもの）等については、出典及び加工者名を明示することによって
> 利用可能です。ただし、利用する国土数値情報がGIS形式やエクセル形式等の
> **データベースの場合は**、原著作者等が有するデータベースの著作権の侵害のおそれが
> ありますので、**国土情報ダウンロードサービス事務局にお問い合わせください。**

⚠ **konjaku のタイルは点や属性の集合＝データベース側**に見える。
⚠ **つまり「使えない」ではなく「訊かないと分からない」。**⚠ 訊く前に入れない。

### 2. ⚠ あとから外すのが高い

⚠ 外に出たものは戻せない。⚠ **共有カード・OGP・README まで届く**（CLAUDE.md §6）。
⚠ タイルに混ぜてしまうと、外すのに全タイルの作り直しが要る。

### 3. ⚠ いまは 1 件も無い

⚠ 実測（2026-08-22）: 配っているデータの出どころは
Wikidata（CC0）／OpenStreetMap（ODbL）／国土地理院／こちらで作ったもの。
⚠ **商用利用を妨げるものは 1 つも入っていない。**⚠ この状態を保つ。

## どう見張るか

⚠ **人の記憶では保たない。**⚠ 実際に、`LICENSES.md` の表は両方向にずれていた
（2026-08-22 に実測。載せ忘れ 3 件／実体の無い行 2 件）。

`scripts/check.mjs` が次の 3 つを見る。

```
a  public/data/ の中身が、全部 LICENSES.md の表に載っている
b  表に載っていて、実体が無い行が無い（消したデータの行が残らない）
c  条件の欄に、禁じる語（非商用 など）が入っていない
```

## やってよいこと

⚠ **実行時に読むだけなら、この規則の外**（配っていないので再配布にならない）。
⚠ ただし、⚠ **Runtime 依存を増やさない**という別の掟がかかる（CLAUDE.md §3）。

⚠ **非商用のデータを見て、こちらで別の主張を組み立てること**も、この規則の外ではない。
⚠ **迷う形になった時点で、配布元に訊く。**

## 例

⚠ 実測（2026-08-22・国土数値情報の各データページの「このデータの使用許諾条件」欄）。

| データ | 条件 | 入れてよいか |
|---|---|---|
| 行政区域 / 土地利用細分メッシュ / 都市計画決定情報 / 大規模盛土造成地 / 内水浸水想定区域 | CC BY 4.0 | ⚠ **よい** |
| 高速道路時系列 / 土砂災害警戒区域 / 津波浸水想定 | CC BY 4.0（一部制限） | ⚠ **一部制限の中身を読んでから** |
| 洪水浸水想定区域 | 旧約款準拠 | ⚠ **読んでから** |
| **鉄道時系列 / 交通流動量 駅別乗降数 / ニュータウン** | ⚠ **非商用** | ⚠ **入れない** |

⚠ 鉄道時系列が欲しかったもの（駅の開業年）は、**Wikidata（CC0）から取れる**。
⚠ 実測（2026-08-22・豊洲まわり）: 10 駅のうち 9 駅に開業日があった。
⚠ **つまり、この規則を守っても失うものは少ない。**
