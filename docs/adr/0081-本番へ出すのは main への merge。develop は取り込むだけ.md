# 0081. 本番へ出すのは main への merge。develop は取り込むだけ

- 状態: ⚠ **置き換えた**（2026-09-01。[0082](<0082-枝は main の 1 本。develop は消し、要るときだけ切り直す.md>)）
- 日付: 2026-09-01

⚠ **同じ日に置き換えた。**⚠ **前提が 2 つ崩れたため**（⚠ 0082 に実測つきで書いた）:
⚠ **`main` は ruleset で守られており squash しか通らない** ／
⚠ **squash は長命な枝どうしを恒久的に分岐させ、⚠ 取り込みでは直らない。**
⚠ **版の印の扱い（出たことを確かめた後に打つ・about.html の 1 か所・打ち直さない）は 0082 が引き継ぐ。**

## 何を決めたか

```text
feature → develop   ⚠ 取り込むだけ。⚠ **出さない**
develop → main      ⚠ **これが本番**。⚠ 出たあと、⚠ 版の印を打つ
```

⚠ **[ADR 0070](<0070-v0.1.0 は検査が全部緑の develop からだけ自動で出す.md>) の「develop から出す」を変える。**
⚠ **「検査が全部緑のときだけ出す」は変えない。**⚠ **変えたのは、⚠ どの枝か だけ。**

## なぜ

⚠ **[0080](<0080-v0.1.0 を本番へ上げ、器と Worker を 1 つにする.md>) で v0.1.0 を本番へ上げたとき、
⚠ 3 つ困った。**⚠ **どれも実測。**

### 1. ⚠ 取り込む操作と、⚠ 出す操作が同じだった

⚠ **`develop` への merge が、⚠ そのまま本番の入れ替えだった。**
⚠ **「取り込んで様子を見る」という選択肢が無い。**

⚠ **実際に困った**: ⚠ 0080 は 386 ファイル・30,850 行削除の変更で、
⚠ **merge した瞬間に本番が切り替わった。**⚠ **確かめてから出す、ができなかった。**

### 2. ⚠ 戻す先を言えなかった

```text
実測（2026-09-01・切り替え前）
  main    68 本遅れ。⚠ 最終更新 2026-08-28。⚠ **何も出していない**
  タグ    v0.1.0 が 2026-08-23 の f5353d5 を指したまま。⚠ **中身と一致していない**
```

⚠ **何か壊れても、⚠ 「どこへ戻すか」を言える基準が repo に無かった。**

### 3. ⚠ 保護が無い

⚠ **`develop` も `main` もブランチ保護なし**（⚠ 実測: `gh api` が両方 404）。
⚠ **`git push origin develop` が直接通る。**⚠ **事故が 1 回で本番に届く。**

## 決めたこと

### 出す枝

```yaml
if: github.event_name == 'push' && github.ref == 'refs/heads/main'
```

⚠ **`main` は「いま本番にあるもの」を指す。**⚠ **戻す先が言える。**

### ⚠ 版の印は、⚠ 出たことを確かめた後に打つ

```text
出す（konjaku）
  ↓
出たものが、手元と同じか（全ファイル）   ⚠ scripts/check-deploy.mjs
  ↓
出たものに、版の印を残す                 ⚠ ここで初めてタグ
```

⚠ **順を変えない。**⚠ **先に打つと、⚠ 出ていないものに「出た」の印が付く。**

- ⚠ **版は `public/about.html` の 1 か所から読む**（⚠ 静的検査 ⑱ が 1 か所を守っている）。
  ⚠ **ワークフローに数字を書かない。**⚠ **書くと 2 か所になる**（`CLAUDE.md` §3）。
- ⚠ **同じ版の印が既に在ったら、⚠ 打ち直さない。**⚠ **黙って動かさない**
  （⚠ 動かすと、⚠ 前にその印で見た人と、⚠ いま見る人で中身が変わる）。
  ⚠ **版を上げ忘れたことは、⚠ ここで分かる**（⚠ 出力に出る）。
- ⚠ **`git push` は使わない。**⚠ **`persist-credentials: false` のまま、⚠ API で作る**
  （⚠ 認証情報を `.git/config` に残さない）。
- ⚠ **書き込みの権限は、⚠ この段だけ**（⚠ 全体の既定は `contents: read`）。

## ⚠ 失うもの

⚠ **良いことだけ並べない。**

- ⚠ **手数が 1 回増える**（⚠ `develop → main` の PR が要る）。
- ⚠ **`develop` は merge しても出ない。**⚠ **確かめる場所が別に要る。**
  ⚠ **`dev.konjaku.hidetzu.work` が空いた**（⚠ `konjaku-next` はもう出していない）。
  ⚠ **そこを確かめる先にするかは、⚠ ここでは決めない。**

## ⚠ 人が確かめること

⚠ **Cloudflare の Workers Builds は、⚠ 2026-09-01 に Owner が GitHub 連携を切った。**
⚠ **切っていないと、⚠ 検査を待たずに出る経路が残る。**⚠ **これは repo からは見えない。**

⚠ **ブランチ保護は、⚠ まだ無い**（⚠ 実測 2026-09-01）。
⚠ **`main` への直接 push が通る。**⚠ **この ADR では入れない**（⚠ 範囲を広げない）。

## これを守っているもの

⚠ **`test/check/deliver.mjs`。**⚠ **6 通りわざと壊して、⚠ 6 通りとも落ちることを確かめた。**

```text
develop に戻す                      → 落ちた
develop も足す（||）                 → 落ちた
印の段を消す                        → 落ちた
版を読む先を別のファイルにする        → 落ちた
既に在る印を打ち直す                 → 落ちた
印を、出たことを確かめる前に打つ      → 落ちた
```

⚠ **「版を読む先」は、⚠ 最初 素通りした。**
⚠ **コメントと `::error::` に `public/about.html` の字が残っていたため。**
⚠ **落としてから、⚠ 実際に取り出している行だけを見るようにした**（`CLAUDE.md` §5）。
