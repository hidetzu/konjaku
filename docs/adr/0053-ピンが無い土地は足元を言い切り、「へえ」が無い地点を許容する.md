# 0053. ピンが無い土地は足元を言い切り、「へえ」が無い地点を許容する

- 状態: 採用（⚠ **決めたのは Owner。**⚠ 2026-08-29）
- 日付: 2026-08-29

⚠ **`docs/adr/0052` が残していた「ピンが 0 件のとき、⚠ 面だけで何を出すか」の答え。**

## 背景

⚠ **`docs/adr/0052` で、⚠ **1km 以内に候補が 1 件も無い地域がある**ことが実測で分かった**
（⚠ 浦安・春日部）。⚠ **そこで「面だけで基本体験が成立する設計とする」と決めた。**
⚠ **ただし「何を出すか」は決めていなかった。**

⚠ **その 2 か所の面を測った**（⚠ 実測 2026-08-29・地理院）:

```bash
node scripts/survey-face.mjs
```

⚠ **数字は書き写さない。**⚠ **走らせて出す**（`CLAUDE.md` §6）。
⚠ **判断が変わったところだけ書く。**

```text
⚠ **浦安は、⚠ 半径を広げても足元の区分が 9 割を占めたまま**（⚠ 300m でも 1km でも変わらない）
⚠ **春日部は、⚠ 半径を広げると顔が変わる**（⚠ 300m はほぼ一色、⚠ 1km で 2 つが半々）
⚠ **どちらも、⚠ 別の区分の境目が 100m 前後にある**
```

⚠ **面の性格が正反対だった。**⚠ **面の半径を 1 つに決めると、⚠ どちらかが損をする。**

## 決めたこと

### ⚠ 案 1（足元を言い切る）を、⚠ v0.1.0 の基本形にする

```text
📍 いまいる場所
ここは 旧水部
かつて水面で、その後陸地にされた土地／標高 2.9m
  ♡ あとで見る    PC で詳しく →
```

⚠ **出すのは、⚠ 足元の区分 1 つと標高。**⚠ **情報量は最小。**

### ⚠ 案 2（境目を言う）は、⚠ 採用しない

⚠ **理由は、⚠ 意味の誤読リスク。**

```text
「50m 先から、⚠ いまも水域です」
  → ⚠ **事実だが、⚠ 「危ないですよ」と読まれうる。**
```

⚠ **`CLAUDE.md` §4-1 が「`⚠` を災害以外に使わない」と決めているのと同じ筋。**
⚠ **危険の話でないものを、⚠ 危険の話に読ませない。**

### ⚠ 案 3（このあたりの割合を帯で出す）は、⚠ スマホトップに採用しない

⚠ **将来の深掘り情報の候補として残す**（⚠ PC 側なら成立しうる）。

⚠ **スマホトップで採らない理由**:

```text
⚠ **情報量が最多**（⚠ 5 秒に合わない）
⚠ **足元が一色の土地では、⚠ 帯が情報にならない**（⚠ 浦安で 9 割一色）
```

## ⚠ 「へえ」が無い地点が存在することを許容する

⚠ **これがこの ADR のいちばん大事なところ。**

```text
⚠ **どこでも「へえ」が出る画面を目指さない。**
⚠ **足元が「今も見たとおり」の土地では、⚠ 「へえ」は出ない。**⚠ **それでよい。**
```

⚠ **`docs/adr/0051` は「ピンは無くても画面は成立する」と決めたが、
⚠ 「どこでも『へえ』が出る」とは決めていない。**⚠ **ここで明示する。**

⚠ **無理に「へえ」を作らない。**⚠ **作ろうとすると、⚠ 次のどれかになる**:

```text
⚠ 事実を盛る            → 掟 §1 に反する
⚠ 危険の話にすり替える   → ⚠ 案 2 を落とした理由
⚠ 情報量を増やす         → ⚠ 5 秒に合わない（案 3）
```

⚠ **「この土地は台地です」で終わってよい。**⚠ **嘘をつくよりよい。**

## ⚠ 決めていないこと

```text
⚠ 面（色）の半径（⚠ 浦安と春日部で性格が正反対。⚠ 1 つに決めると片方が損をする）
⚠ 区分の言い換え（⚠ 「氾濫平野・海岸平野」をそのまま出すか。⚠ `CLAUDE.md` §4）
⚠ 標高を常に出すか（⚠ 「標高 5.7m」が何を意味するかは、⚠ 土地によって違う）
⚠ 案 3 を PC 側でどう使うか
```
