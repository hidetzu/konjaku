# 0053. ピンが無い土地は足元を言い切り、「へえ」が無い地点を許容する

- 状態: 採用（⚠ **決めたのは Owner。**⚠ 2026-08-29）
- 日付: 2026-08-29

⚠ **`docs/adr/0052` が残していた「ピンが 0 件のとき、⚠ 面だけで何を出すか」の答え。**

## 背景

⚠ **`docs/adr/0052` で、⚠ **1km 以内に候補が 1 件も無い地域がある**ことが実測で分かった**
（⚠ 浦安・春日部）。⚠ **そこで「面だけで基本体験が成立する設計とする」と決めた。**
⚠ **ただし「何を出すか」は決めていなかった。**

⚠ **その 2 か所の面を測った**（⚠ 実測 2026-08-29・地理院）:

```bash
node scripts/survey-face.mjs
```

⚠ **数字は書き写さない。**⚠ **走らせて出す**（`CLAUDE.md` §6）。
⚠ **判断が変わったところだけ書く。**

```text
⚠ **浦安は、⚠ 半径を広げても足元の区分が 9 割を占めたまま**（⚠ 300m でも 1km でも変わらない）
⚠ **春日部は、⚠ 半径を広げると顔が変わる**（⚠ 300m はほぼ一色、⚠ 1km で 2 つが半々）
⚠ **どちらも、⚠ 別の区分の境目が 100m 前後にある**
```

⚠ **面の性格が正反対だった。**⚠ **面の半径を 1 つに決めると、⚠ どちらかが損をする。**

## 決めたこと

### ⚠ 案 1（足元を言い切る）を、⚠ v0.1.0 の基本形にする

```text
📍 いまいる場所
ここは 旧水部
かつて水面で、その後陸地にされた土地
  ♡ あとで見る    PC で詳しく →
```

⚠ **出すのは、⚠ 足元の区分 1 つとその説明。**⚠ **情報量は最小。**
⚠ **当初は標高も添えていたが、⚠ 2026-08-29 に落とした**（⚠ 下）。

### ⚠ 案 2（境目を言う）は、⚠ 採用しない

⚠ **理由は、⚠ 意味の誤読リスク。**

```text
「50m 先から、⚠ いまも水域です」
  → ⚠ **事実だが、⚠ 「危ないですよ」と読まれうる。**
```

⚠ **`CLAUDE.md` §4-1 が「`⚠` を災害以外に使わない」と決めているのと同じ筋。**
⚠ **危険の話でないものを、⚠ 危険の話に読ませない。**

### ⚠ 案 3（このあたりの割合を帯で出す）は、⚠ スマホトップに採用しない

⚠ **将来の深掘り情報の候補として残す**（⚠ PC 側なら成立しうる）。

⚠ **スマホトップで採らない理由**:

```text
⚠ **情報量が最多**（⚠ 5 秒に合わない）
⚠ **足元が一色の土地では、⚠ 帯が情報にならない**（⚠ 浦安で 9 割一色）
```

## ⚠ 「へえ」が無い地点が存在することを許容する

⚠ **これがこの ADR のいちばん大事なところ。**

```text
⚠ **どこでも「へえ」が出る画面を目指さない。**
⚠ **足元が「今も見たとおり」の土地では、⚠ 「へえ」は出ない。**⚠ **それでよい。**
```

⚠ **`docs/adr/0051` は「ピンは無くても画面は成立する」と決めたが、
⚠ 「どこでも『へえ』が出る」とは決めていない。**⚠ **ここで明示する。**

⚠ **無理に「へえ」を作らない。**⚠ **作ろうとすると、⚠ 次のどれかになる**:

```text
⚠ 事実を盛る            → 掟 §1 に反する
⚠ 危険の話にすり替える   → ⚠ 案 2 を落とした理由
⚠ 情報量を増やす         → ⚠ 5 秒に合わない（案 3）
```

⚠ **「この土地は台地です」で終わってよい。**⚠ **嘘をつくよりよい。**

## ⚠ 観測事実 ── ⚠ **面の半径は一律にできない**（⚠ 2026-08-29 に測り足した）

⚠ **これは Decision ではない。**⚠ **観測しただけ。**⚠ **面の半径はまだ決めていない。**

```bash
node scripts/survey-face.mjs 0 7
node scripts/survey-face.mjs 7 13
```

⚠ **数字は書き写さない。**⚠ **走らせて出す**（`CLAUDE.md` §6）。
⚠ **`scripts/survey-pins.mjs` と同じ 13 か所で測っている**（⚠ 突き合わせられるように揃えた）。

### ⚠ ① 半径を広げたときの「顔の変わり方」が、⚠ 土地でばらける

⚠ **「落差」＝ 足元の区分が占める割合の、⚠ 300m と 1000m の差。**

```text
⚠ **落差は 0 から 45 までばらけた。**
⚠ **どの半径を選んでも、⚠ 半数近くが損をする。**

落差が大きい（⚠ 広げると顔が変わる）   春日部・弘前・鞆の浦・梅田・渋谷
落差がほぼ無い（⚠ 広げても同じ）       松本・浦安・佐賀
⚠ **落差が負**（⚠ 狭いほうが混ざる）   高知・関宿
```

### ⚠ ② 境目は、⚠ ほとんどの土地ですぐ近くにある

```text
⚠ **13 か所中 11 か所で、⚠ いちばん近い別の区分が 160m 以内にあった。**
⚠ **面をどんな半径で見せても、⚠ 画面には必ず境目が入る。**
```

⚠ **これは案 2（境目を言う）を落とした判断とは別の話。**
⚠ **言葉にしないだけで、⚠ **色としては見えている**。**

### ⚠ ③ 足元が少数派の土地がある

```text
⚠ **松江は、⚠ 足元の「旧水部」が 300m で 4 分の 1、⚠ 1km で 1 割を切る。**
⚠ 鞆の浦・渋谷・関宿も、⚠ 足元が半分に満たない。
```

⚠ **「ここは旧水部」と言い切ったとき、⚠ 周りの大半が別の土地、⚠ という状況が起きる。**
⚠ **嘘ではないが、⚠ 地図の色と食い違って見える。**

⚠ **上で決めた基本形（⚠ 足元を言い切る）は、⚠ この状況でも成り立つかを確かめる必要がある。**

## ⚠ 標高は出さない（⚠ 2026-08-29。Owner）

⚠ **上の基本形には「／標高 2.9m」と書いていたが、⚠ 落とす。**

```text
📍 いまいる場所
ここは 旧水部
かつて水面で、その後陸地にされた土地
  ♡ あとで見る    PC で詳しく →
```

### ⚠ なぜ落とすか

⚠ **豊洲（⚠ 標高 −1.9m）と松本（⚠ 標高 592m）の実データを、⚠ 同じ画面で比べた**
（⚠ 実測 2026-08-29・375×667・z16。⚠ **条件付き表示案は作っていない**）。

```text
豊洲   「かつて水面」＋「−1.9m」
       → ⚠ **区分の説明を裏づけている。**⚠ いまも海より低いことが分かる

松本   「扇状地」＋「592m」
       → ⚠ **592m は扇状地であることを裏づけていない。**
       → ⚠ 山の中なら当たり前で、⚠ **「だから何」になる**
```

⚠ **判断の基準は「5 秒体験を助けるか、⚠ 別の意味を持ち込むか」**（Owner）。

### ⚠ 別の意味を持ち込む

```text
⚠ **数字が並ぶと「高い／低い」の話に見える。**
⚠ **今昔の問いは「昔どんな土地だったか」で、⚠ 高さの話ではない。**
```

⚠ **豊洲で効いて見えるのは、⚠ 標高が「高さ」ではなく「海面との関係」として読めるから。**
⚠ **−1.9m は「水だった土地が、⚠ いまも水面より低い」という**昔の話**に繋がる。**
⚠ **592m には、⚠ その繋がりが無い。**

### ⚠ 効くのは一部の土地だけ

⚠ **測った 15 地点で、⚠ 標高が区分を裏づけるのは海面付近の土地だけだった**
（⚠ 豊洲・浦安・松江）。⚠ **所沢・弘前・松本には効かない。**

⚠ **`docs/adr/0053` は「へえ」が無い地点を許容すると決めた。**
⚠ **標高で無理に情報量を増やすのは、⚠ そのとき落とした「情報量を増やす」に当たる。**

### ⚠ 失うもの

```text
⚠ **豊洲の「−1.9m」が消える。**
⚠ **「かつて水面」だけでは、⚠ いまも海より低いことは伝わらない。**
```

⚠ **承知の上で落とす。**⚠ **条件付きで出す案は作らない**（Owner）。
⚠ **「説明がある土地」と「無い土地」の差が意味を持ってしまう**
（⚠ `public/words.js` の GROUND_GLOSS が「例外を作らない」と決めているのと同じ筋）。
