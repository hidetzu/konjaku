# 0079. 配信物から語を消すときは、配るもの全部を見る

- 状態: 決めた
- 日付: 2026-09-01

## 何が起きたか

⚠ **[0078 の前の作業](<0078-プライバシーは先に4点を渡し、くわしくは下に置く.md>)（hidetzu/konjaku#432）で
「作りかけ」を消したつもりが、⚠ 消せていなかった。**⚠ **Owner の指摘で分かった。**

> 作りかけ `<title>` と OGP / meta title あたりも含めて「作りかけ」が残っていないかだけ grep した?

⚠ **していなかった。**⚠ **`public-next/*.html` しか見ていない。**

## ⚠ 残っていたもの

| 場所 | ⚠ 配信されるか | なぜ漏れたか |
|---|---|---|
| `public-next/robots.txt` | ⚠ **される**（⚠ 誰でも取得できる） | ⚠ **`*.html` しか見ていなかった** |
| `public-next/about.html` の HTML コメント | ⚠ **される**（⚠ コメントも配信物） | ⚠ **検査がコメントを落としてから見ていた** |
| `public-next/_headers` | されない（Cloudflare の設定） | ⚠ **`*.html` しか見ていなかった** |

⚠ **3 つ目が、⚠ いちばん質が悪い。**
⚠ **「作りかけ」を消したこと自体を説明するコメントを、⚠ 自分で `about.html` に書いた。**
⚠ **そのコメントが、⚠ 消したはずの語を配っていた。**
⚠ **検査はコメントを落としてから見るので、⚠ 緑のままだった。**

## 決めたこと

```text
配信物から語を消すとき   ⚠ 配るもの全部を見る（拡張子で絞らない）
                        ⚠ コメントも落とさずに見る（HTML コメントは配信物）
経緯・理由              ⚠ 配信物に書かない。docs/adr か README に置く
```

⚠ **`CLAUDE.md` §5 は「検査が文書やコメントを読むとき、⚠ コメントを先に落とす」と言う。**
⚠ **これは正しいが、⚠ 主語が違う。**

```text
自分の字を拾わないため    ⚠ コメントを落とす   ← §5 が言っているのはこちら
配信物から語を消すため    ⚠ コメントも見る     ← ⚠ 今回はこちらだった
```

⚠ **どちらを見ているかで、⚠ 落とすかどうかが変わる。**⚠ **一律に落とさない。**

⚠ **今回の検査（⑱）は、⚠ 両方を使い分けている。**

```text
「作りかけ」を探す    配るもの全部 ／ ⚠ コメントを落とさない
版の数を数える        *.html      ／ ⚠ コメントを落とす（⚠ 説明の中の v0.1.0 を拾うため）
```

⚠ **だから、⚠ この決めごとの経緯を配信物に書くと、⚠ 検査自身が落ちる。**
⚠ **書く場所はここ（ADR）。**

## ⚠ ついでに分かったこと

⚠ **v0.1.0 には OGP も meta description も 1 つも無い**（⚠ `og:` `twitter:` `description` とも 0 件）。
⚠ **だから「OGP に作りかけが残っている」ことは無かった。**⚠ **ただし、⚠ 無いこと自体は別の話。**
⚠ **いまは `robots: noindex` なので困らないが、⚠ 公開するときに要る。**
⚠ **この ADR では決めない。**
