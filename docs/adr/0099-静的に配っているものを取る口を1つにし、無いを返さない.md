# 0099. 静的に配っているものを取る口を 1 つにし、「無い」を返さない

- 日付: 2026-09-05
- 状態: 採用
- hidetzu/konjaku#99

## 何が起きていたか（実測 2026-09-05・`172a680`）

**静的に配っているものを、7 か所 / 4 ファイルで取っていた。**

```text
top.js:314    landform.json      時間切れ 無し   失敗 → null（覚えない）
top.js:616    area-record.json   時間切れ 無し   失敗 → {ok:false,data:null}
top.js:762    muni.json          時間切れ 在り   失敗 → null
verify.js:365 landform.json      時間切れ 在り   失敗 → 例外
deep.js:187   monument の 2 本   時間切れ 無し   失敗 → 拒む
deep.js:473   area-record.json   時間切れ 無し   失敗 → null
```

**時間切れを持っていたのは 2 本だけ。**
**失敗したときの返し方は `null` / 例外 / `{ok:false}` の 3 通りあった。**

ばらばらだと、「取れなかった」を「無い」に化けさせる経路が口の数だけ増える（掟 §1）。
**実際に踏んでいる**（2026-08-29。周辺の資料そのものを読めなくしても、
画面は資料が無い場所とまったく同じだった）。

## 何を決めたか

### 1. 口は `public/static-json.js` の 1 つ

DOM も地図も持たない。`fetch` は呼ぶ側が渡せるので、検査がブラウザ抜きで回せる
（`.claude/rules/javascript.md` の「7 つの形」に倣う）。

### 2. 返す形は 2 つだけ。「無い」を返さない

```text
{ state: "ok", data }                  読めた
{ state: "unreachable", why, status }  読めなかった
```

**`absent` を返せるようにしない。**
配っていないものを取りに行くのは、こちらの不具合であって、
利用者に「無い」と言ってよいことではない。

何が無いかは、呼ぶ側の Domain が表を見て決める
（`monument.js` は `tiles.json` を見て `absent` と `unreachable` を分けている）。

### 3. 時間切れは 8 秒。外への口と同じにする

**別の値にする根拠が、こちらで測れていない。**

実測（2026-09-05・本番・10 回ずつ・回線 1 本）:

```text
landform.json        0.36〜0.44 秒
area-record.json     0.33〜0.44 秒
muni.json            0.35〜0.58 秒
monument/tiles.json  0.31〜0.43 秒
```

**これは速い回線 1 本の話で、遅い回線でどこまで伸びるかは測っていない。**
測っていない値で短く切ると、読めるはずのものを「読めなかった」にする。

## 変えたこと

`top.js` の `area-record.json` は、失敗しても覚えなかったのが `{ok:false}` のときだけだった。
**いまはどの失敗でも覚えない**（次に開いたら、もう一度取りに行く）。
**画面に出る字は変えていない。**

## 何を見張るか

**静的検査**（`test/check/next.mjs` ㉖）:

```text
配り物へ fetch( を直に向けている場所が無い
口を、使う相手より先に読み込んでいる
口が ok / unreachable だけを返す（absent を返さない）
口が時間切れを持っている
```

**実描画**（`test/render/next.mjs`）: 配り物を 1 つずつ落として、画面が「無い」と言わないこと。

```text
monument         いま読み込めませんでした。この近くに碑が在るかどうかは分かっていません
area-record      いま読み込めませんでした。この周辺の記録が在るかどうかは分かっていません
landform.json    いま、この場所を調べられません（「まだ分類できていません」とは言わない）
muni.json        保存は止まらない
```

**8 本とも、わざと壊して、狙った理由で落ちることを確かめた。**
