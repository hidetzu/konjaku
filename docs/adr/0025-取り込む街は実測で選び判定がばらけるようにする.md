# 取り込む街は実測で選ぶ。ただし数字の上位ではなく、判定がばらけるように選ぶ

- 状態: 採用
- 日付: 2026-08-14

## 何が問題だったか

ピンは6件、取り込みは7エリアで、**両者が一致していなかった**（渋谷は取り込んであるのにピンに無い）。
そして「どの街を入れるか」を「面白そう」で決めていた。

**人が「面白そう」を決めると、その判断を後から検証できない。**

## 何を測ったか

候補25件を挙げ、`scripts/survey.mjs` で3つ測った ―― 判定／写真の年代数／年代を送ったときに一覧が動く段数。

⚠ **3つを1つの点数にまとめていない。重みに根拠が無いから。** 数字は並べ、選ぶ理由は言葉で書いた。

主な結果（動く段数 / 写真年代 / 年のあるもの / 判定）:

```
上野     8/7/180  台地･段丘（そのまま）      札幌   8/4/ 88  扇状地
西新宿   8/7/157  台地･段丘 → 盛土地        広島   8/5/128  自然堤防
渋谷     8/7/107  氾濫平野 → 盛土地         難波   8/6/ 89  砂州・砂丘
汐留     8/7/314  氾濫平野 → 盛土地         出島   7/2/ 89  水部
お台場   4/7/ 67  旧水部 → 埋立地           仙台   7/4/ 68  台地･段丘
豊洲     7/7/ 27  旧水部 → 埋立地           浦安   3/7/ 13  旧水部 → 埋立地
```

**汐留と日比谷が同じ 314件** ＝ 同じ z14 タイル。並べると利用者から見れば同じ場所を2回ピン留めしていることになる。
**数字が先に教えてくれた。**

取り込み後: **769件 → 2,367件**（35タイル → 87タイル、20束）。再開が効いて、既存7エリアは**1リクエストも出さずに**飛ばした。

ピンを6→10に増やしたときの実測（375×667）:

```
ピン    10個・2行 308→402px（折り返しの上）
全高    657px → 687px（20px の縦スクロールが出た）
タップ高  29px → 44px
```

29px のまま10個を2行に詰めると、行の間隔が6pxしかない。
押し間違いが「隣の街が開く」という、**間違えたこと自体に気づけない**形で出る。

## 決めたこと

- **候補は測って並べる。人が「面白そう」で決めない**
- ただし**数字の上位そのままでは選ばない。判定がばらけるように選ぶ**。
  全部「昔は水でした」だと、どこを押しても同じ話になり、**判定が当たっているのか疑えない**
  - **上野**は動く段数も件数も最上位だが、選んだ本当の理由は判定が「台地･段丘」＝**改変されていない**こと。
    埋立でない土地を1つ持っていないと、この製品は「なんでも埋立と言う機械」に見える
  - **お台場**は数字が弱いが、写真の最古と現在で**別の土地に見える**
  - **長崎 出島**は写真2年代しかないが、判定が全候補で唯一の「この場所は**水部**です」
- 選んだ10件: 東京5（豊洲・渋谷・西新宿・上野・お台場）／地方5（札幌・仙台・大阪 難波・広島・長崎 出島）
- 外れた街も `seeds/areas.jsonl` に残す。**外すと取り込みが回らなくなり、調べた日が古いまま固定される**
- 指で押すものは 44px 以上（`@media (hover:none)` の中だけ）

## そうしなかったこと

- **3つの指標を合成して1つの点数にする** … 重みに根拠が無い
- **画面から候補の年分布を測る** … 同じ実行の中で候補の数だけ Wikidata を叩くことになり、**相手に断られた**。
  そこで0件と記録していたら、**西新宿（157件）と汐留（314件）を「何も無い街」として候補から外していた**（0001）
- **`::after` で見えない当たり判定だけを広げる** … 行の間隔（35px）より判定（44px）が大きくなり、
  上下の行の判定が重なって、**下の行を押したのに上の行が開く**という、もっと分かりにくい壊れ方になる。
  **見た目と当たり判定は一致させる**

## 副作用として直したもの

「未整備の土地では、取り込み済みのふりをしない」検査が**札幌を使っていた**。
札幌を取り込むと、この検査は外へ出なくなり、**何も確かめずに必ず通る**。
→ 帯広へ移し、「その土地が索引に載っていないこと」を見る検査を足した。**取り込んだ日に CI が落ちる。**

⚠ 同じ札幌を使う別の3件（「明治期のデータが無い土地」）は国土地理院の整備範囲に寄りかかっているだけで、
こちらの取り込みとは無関係。混ぜないよう定数を分けた。
