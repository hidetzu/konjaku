# 0102. 計測は日ごとに数え、位置は送らない

- 日付: 2026-09-06
- 状態: 採用
- 決めた人: Owner

## 何を解くか

どこから来た人が、どこまで進み、どこでやめたかが分からない。
**分からないと、画面を直しても効いたかどうかが言えない。**

## いままで（実測 2026-09-06）

**受け口だけが在って、送る側が 1 つも無かった。**

```text
/t              在る（worker.js）。Origin 検査・長さ上限・列挙で弾く
tick / health   在る（migrations/0001_tick.sql）。日ごとに畳む
送る側          ⚠ 0 か所（public/*.js から /t を叩いているところは無い）
```

`/t` の一覧は β 版の操作だった（`open.peel` / `share.tap` など）。
v0.1.0 は 1 件も計測していなかった。

## 決めたこと

**`/t` は畳み、`/api/events` を作り直す**（`CLAUDE.md` §3。同じ問いに答える口を 2 つ持たない）。
`tick` / `health` の表は消さない（β のデータが入っている）。書く側が無いだけ。

### 記録するもの

```text
created_at   UTC の日（⚠ 時刻は持たない）
referrer     app-village / tsukutta.app / konjaku / other / direct（⚠ 列挙のみ）
session_id   端末の中で作った印。⚠ 日が変わると別の印になる
event_type   page_load / map_opened / detail_view / deep_accessed / save_place / shared
entry_point  default / link / map / search / here
metadata     { "page": … } だけ
```

### 記録しないもの

```text
座標・町名     1 件も残さない（⚠ どこを調べたかは分からない）
user-agent     残さない（⚠ 端末の見分けはしない）
検索した語     残さない（⚠ 回数だけ）
時刻           日までしか持たない
```

**画面は座標を持っている。持っているものを送らない、というのは検査でしか守れない。**

## 端末をまたぐことは、結ばない

Owner の仮説（2026-09-06）:

> スマホで使って、URL を共有して PC で深堀りする想定なので、
> セッション ID は異なるものになる可能性が高い

**だから、セッション ID で端末をまたいで結ぶことはしない。**
かわりに、PC 側の入口を `entry_point` が名乗る（`link` ＝ 共有リンクで開かれた）。
これは画面が既に判定しているものを借りているだけで、新しく何も知らない。

## 測れないもの

**リピーター率は測れない。**
訪問の印は 1 日で消えるので、「昨日も来た人」は別の印になる。

測るには印を残し続ける必要があり、それは実質 Cookie と同じものを持つことになる。
**測れないものを測れると書かない**（`CLAUDE.md` §1）。

## 流入元は、こちらが貼った印を先に見る

```text
1  ?from=app-village があれば、それ
2  無ければ、来た相手のホスト名を列挙の名前へ畳む
3  どちらも無ければ direct
```

**生の URL は残さない。**列挙の外は `other` に畳む（どこから来たかは残らない）。

## プライバシーポリシー

要約を 1 点足した（Owner の字。2026-09-06）。

```text
ご利用時に、流入元・行動パターン・セッション情報を記録します。
位置情報は送信されません。
```

**「押さなければ、何も送りません」は、そのままでは嘘になる**ので直した。
保存した場所については、いままでどおり「押したときだけ」。

## 何を見張るか

**静的検査**（`test/check/safety.mjs` 1.7。⚠ 本物の Worker を実際に呼ぶ）:

```text
画面（measure.js）と受け側（events.js）の一覧が同じ
列挙にあるイベントを全部数える
座標・都道府県・user-agent を送りつけても表に入らない
生の流入元は数えない
大きい本文を、読まずに落とす
上限が、実際に送る本文より短くない（⚠ 短いと静かに数えなくなる）
Content-Length 無し・よそのオリジン・POST 以外・列挙外
```

**実描画**:

```text
/about と /deep を開くと、計測が 1 本だけ飛ぶ
送った本文に、座標も町名も user-agent も入らない／鍵は決めた 5 つだけ
同じ訪問なら、印は同じ
計測が落ちても、画面は動く
```

**7 本とも、わざと壊して、狙った理由で落ちることを確かめた。**

## Owner に残っている作業

**AppVillage と tsukutta.app の登録 URL に `?from=` を付けると、流入元が確実になる。**
付けなくても Referer から畳むが、付けたほうが取りこぼさない。

```text
https://konjaku.hidetzu.work/about?from=app-village
https://konjaku.hidetzu.work/about?from=tsukutta
```
