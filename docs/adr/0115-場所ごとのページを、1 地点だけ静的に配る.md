# 0115. 場所ごとのページを、1 地点だけ静的に配る

- 日付: 2026-10-10
- 状態: 採用
- 決めた人: Owner（⚠ **「まず 1 地点だけ試す」を選んだ**）
- hidetzu/konjaku#535

## 何が起きていたか

⚠ **検索から誰も来ていなかった。**

⚠ **実測（2026-10-10）**:

```text
Search Console   検索での表示回数 0                        ⚠ Owner が確認
索引の下地       robots.txt 200 ／ sitemap.xml 200         ⚠ 本番へ curl
                 X-Robots-Tag 無し                        ⚠ 塞いでいない
トップの HTML    title・description・canonical・h1 あり    ⚠ 本文 7472B（タグ除去後）
                                                          ⚠ SEO の最低条件は満たしている
索引にある画面   / ・/about ・/privacy ・/terms            ⚠ 地名が 1 つも入っていない
成長             直近 14 日 2 件 ／ 線 14 日で 7 件        ⚠ npm run gate（2026-10-09）
```

⚠ **塞がっていたのではない。**⚠ **出す中身が無かった。**
⚠ **人が検索するのは地名を含む語**（「東京駅 昔」など）。⚠ **その語を持つページが 1 枚も無い。**

## ⚠ 0106 は、⚠ そうしない理由を持っていた

[`0106`](<0106-索引に出す画面を絞り、robots.txt は置かない.md>) はこう書いている。

```text
/ と /deep はクエリで場所が変わる。
場所ごとのページを静的に配ってはいないので、変種を索引へ増やしても中身が無い。
```

⚠ **正しい。**⚠ **クローラは画素を読まない。**⚠ **空の器を索引へ増やしても意味がない。**

## 決めたこと

⚠ **1 地点だけ、⚠ 答えを事前に作って静的に配る**（`/place/tokyo-station`）。
⚠ **0106 の判断を、⚠ 1 地点に限って覆す。**

### ⚠ 判定を 2 つ持たない

⚠ **作る口は判定を書かない**（`scripts/build-place.mjs`）。
⚠ **本番の画面をそのまま開き、⚠ 出た答えの字を写すだけ。**

```text
1  ローカルで public/ を配る（scripts/serve.mjs）
2  /?ll=<緯度>,<経度> を開く
3  答えの字が出るまで待つ（⚠ 器ではなく結果の字。CLAUDE.md §9）
4  #gloss / #sub / #glossSrc を写す
5  静的 HTML を書く
```

⚠ **字は `public/words.js` / `public/answer.js` が持つ**（`.claude/rules/domain.md`）。
⚠ **だから「作った答え」と「ブラウザで開いた答え」は、⚠ 同じコードから出る。**

⚠ **`CLAUDE.md` §3 を踏まないための形**（⚠ **precision で一度踏んでいる**:
⚠ 取り込み側とブラウザ側に同じ判断を書き、⚠ 取り込み済みの土地と実行時に問い合わせる土地で答えが変わった）。

### ⚠ 取れなかったら、⚠ 作らない

⚠ **古い答えを配らない。**⚠ **「無い」とも書かない。**⚠ **黙って出さない**（`CLAUDE.md` §1）。

### ⚠ いつの答えかを書く

⚠ **資料が変われば答えも変わる。**⚠ **ページに測った日を書く**（`CLAUDE.md` §6）。
⚠ **人が読む日付なので JST**（⚠ 計測の日は UTC。`docs/adr/0102`。⚠ 混ぜない）。

### ⚠ 生成物は git に入れる

⚠ **入れる理由は 1 つ**: ⚠ **答えが変わったら差分で気づける。**
⚠ **入れないと、⚠ デプロイのたびに地理院を叩くことになる**
（⚠ **CI が相手先の答えに依存する**。`CLAUDE.md` §9 が禁じている形）。

## ⚠ 効いたかどうかは、⚠ すぐには言えない

⚠ **[`0112`](<0112-成長は流入で測り、健康は率で測る.md>) の線は 14 日で 7 件。**
⚠ **いま直近 14 日で 2 件。**⚠ **届くまでは「効いた」とも「効かなかった」とも言わない。**

⚠ **索引に入るかどうかは相手（Google）が決める。**⚠ **こちらの正しさとして主張しない**（`CLAUDE.md` §9）。

## ⚠ 増やす条件

⚠ **2 地点以上・一覧・検索は、⚠ `.claude/rules/domain.md` の MUST が禁じている。**
⚠ **増やすのは、⚠ 次が揃ってから。**

```text
1  この 1 枚が索引に入った        ⚠ Search Console で見る（⚠ 人の作業）
2  検索での表示回数が 0 でなくなった
3  流入が線に届いた              ⚠ 0112。⚠ 届くまでは効いたかを言えない
```

## 何を見張るか

**静的**（`test/check/next.mjs`「場所ごとのページ」）:

```text
生成物の印がある（⚠ 手で直されても気づけない形にしない）
測った日がある
題に地名が入っている（⚠ これが無いと、⚠ 検索される語を持たない）
作る口が「答えが揃っているか」を、⚠ 出すところで呼んでいる
作る口が判定を持っていない（classify / SWALE / GROUND_GLOSS / inRing）
索引の正本と sitemap の顔ぶれが一致（⚠ 既存の節が見ている）
```

**実描画**（`test/render/next.mjs`）:

```text
場所のページの答えが、地図で同じ座標を開いた答えと一致する   ⚠ これが条件
日本語だと名乗る ／ 索引の正本が自分を指す ／ 地図と深掘りへの導線がある
画面に ⚠ を出していない（⚠ あれは災害リスクの印。CLAUDE.md §4-1）
```

⚠ **5 通りのわざと壊しで、⚠ 狙った理由で落ちることを確かめた**（2026-10-10）。

```text
答えを古くする            → ✗ 実描画「答えが食い違う」
日本語だと名乗らない       → ✗ 実描画
画面に ⚠ を出す           → ✗ 実描画
取れなくても作る形にする   → ✗ 静的（⚠ 1 度目は素通りした。下を見る）
生成物の印を消す          → ✗ 静的
```

⚠ **1 度、⚠ 静的検査を素通りさせた。**⚠ **「`答えが揃っている` という字があるか」だけを見ていたため、
⚠ `if (false)` に変えても関数の定義が残っていて通った。**
⚠ **出すところで呼んでいるかを見る形に直した**（⚠ hidetzu/konjaku#505 と同じ型の見落とし）。
