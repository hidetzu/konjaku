# 0086. 色みは 1 つの token が両方を持ち、人が選べるようにする

- 状態: 決めた
- 日付: 2026-09-02
- ⚠ **[`0040`](<0040-色みは端末の設定に従い、選ぶ操作は後回しにする.md>) の「後回し」を解いた**（⚠ 置き換えではない）

## 何を決めたか

⚠ **端末の設定に従う／明るい／暗い の 3 つを、⚠ 人が選べる。**⚠ **次に開いても残る。**

```text
既定           :root{ color-scheme: light dark }        ⚠ 端末の設定に従う（0040 のまま）
人が選んだとき  :root[data-theme="light"|"dark"]        ⚠ color-scheme を固定するだけ
```

## ⚠ いちばん大事なところ — ⚠ 値を 2 か所に持たない

⚠ **`.claude/rules/css.md` は「`[data-theme]` を併記しない」を MUST にしていた。**
⚠ **理由は、⚠ 同じ値が 2 か所になり、⚠ 色みを足したとき片方だけ切り替わるから。**

⚠ **素直に `[data-theme="dark"]` を足すと、⚠ その MUST に反する。**

⚠ **`light-dark()` なら、⚠ 1 つの token が両方を持つ。**

```css
:root{
  --bg:light-dark(#f2f5f7, #0b0f14);   /* ⚠ 明るいと暗いが 1 行に */
}
:root[data-theme="dark"]{ color-scheme: dark }   /* ⚠ 色の値を 1 つも書かない */
```

⚠ **`[data-theme]` に入るのは `color-scheme` だけ。**⚠ **MUST の狙いはそのまま守れる。**
⚠ **検査が、⚠ `[data-theme]` に色の値が入っていないことを見ている。**

## ⚠ 1 画素も変えていない

⚠ **実測（2026-09-02）**: ⚠ **`/`・`/about`・`/deep` を、⚠ 明るいと暗いの両方で、
⚠ 変換の前後で撮って突き合わせた。**

```text
要素 952 個 × 5 つの色（文字・背景・枠の上下・輪郭）   ⚠ 違い 0
コントラスト                                        ⚠ 前後で同じ数字
絵                                                  ⚠ /・/about は同一
                                                    ⚠ /deep だけ違うが、
                                                      ⚠ 同じ版で 2 回撮っても違う（外のタイル待ち）
```

## ⚠ 検査の主張を、⚠ 2 つ書き換えた

⚠ **形が変わると、⚠ 前の主張は「間違ったまま固定される」**（`CLAUDE.md` §9）。

```text
前  暗い色みの節に、⚠ 同じ名前が宣言されているか
後  ⚠ 色は light-dark() で書かれているか。
    ⚠ 色みで変えないものは、⚠ 理由と一緒に一覧へ書く（⚠ 書き忘れと区別するため）
```

⚠ **もう 1 つは、⚠ 黙って何も見なくなる形だった。**
⚠ **コントラストの検査は `parseColor()` で色を拾う。**⚠ **`light-dark(...)` は読めないので、
⚠ そのままだと 13 個の色が表から落ち、⚠ 何も測らずに緑になる。**
⚠ **だから `light-dark()` を読める形にし、⚠ 「8 個未満しか読めなければ落とす」を足した。**

## 選ぶ口

```text
置き場所   名乗りの帯の、⚠ ☰ の手前
形         ⚠ 押すたびに回る（◐ → ☀ → ☾ → ◐）
字         ⚠ 印だけでなく、⚠ 読み上げも「色み：明るい」と、⚠ いまの状態を名乗る
```

- ⚠ **44×44 を割らない**（⚠ 実測で 320px のとき 37×44 になり、⚠ `flex:0 0 auto` で直した）
- ⚠ **JavaScript が動くまで出さない**（⚠ 押しても何も起きない導線を置かない。`docs/adr/0026`）
- ⚠ **最初の描画より前に当てる**（⚠ `<head>` で読む。⚠ でないと一瞬だけ前の色みで描かれる）
- ⚠ **保存領域を触れない端末でも落ちない**（⚠ その画面のあいだは効く）

## ⚠ 増えた前提

⚠ **`light-dark()` に対応していないブラウザでは、⚠ 色が出ない。**
⚠ **Chrome 123 ／ Safari 17.5 ／ Firefox 120 以降。**⚠ **どれだけの人が外れるかは測っていない。**

## 決めなかったこと

- ⚠ **色みを 3 つより増やすこと**（⚠ 高コントラストなど）
- ⚠ **端末ごとに違う色みを覚えること**（⚠ この端末の中だけ）
