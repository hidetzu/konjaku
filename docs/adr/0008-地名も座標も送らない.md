# 地名も座標も送らない。記録するのは「何が起きたか」だけ

- 状態: 採用
- 日付: 2026-08-11（旧 §3.13「評価は自分専用」）

## 何が問題だったか

このサービスは「自分の★とメモは自前だが非公開」「評価は自分専用」を設計にしている。
一方で共有率を測るために計測が要る。**測ることが、この設計を壊しうる。**

そして実際に壊れていた。URL に地名と座標が載っている（`?q=豊洲&ll=35.65,139.79`）ため、
**既定のままだと計測の POST にも外部リンクにも Referer としてそれが付いて出ていく。**
「地名も座標も送らない」と画面に書いている以上、ここを塞がないとその記述が嘘になる。

## 何を測ったか

- **実測で `/t` への referer に `?q=` と `?ll=` が乗っていた**（2026-08-11、公開前レビュー）
- `/t` は Origin が**無い**ものが素通りしていた（`origin &&` の書き方）。
  curl のループで 10万行/日を焼き切れるし、`shared` を好きなだけ増やせる。**唯一の指標を外から汚せる状態**だった
- Worker 側の `EVENTS` で弾いていても「送ってはいる」ことになるので、送る側でも列挙を守る必要がある

## 決めたこと

- **利用状況の計測には、地名も座標も送らない。Cookie も識別子も使わない**
  - ⚠ **主語は「計測」**（2026-08-15 に追記）。この ADR の題は「地名も座標も送らない」だが、
    **どこへ送らないのかを書いていなかった**ため、画面に主語なしで写され
    「こちらのサーバーには送りません」という**事実でない説明**になっていた。
    ⚠ **調べた場所は URL に載る**（`?q=<地名>&ll=<座標>`。戻る・共有するために必要で、外さない）。
    その URL を開けば、アドレスの一部として**配信元（Cloudflare）には届く**。
    実測（2026-08-15）: 判定後にリロードすると、自分のサーバーへ出た 11 件のうち
    **1 件が `/?q=豊洲&ll=35.65480,139.79750`**。一方 `/t` は 2 件出たが、どちらにも載っていない。
    ⚠ **題は変えない。** これは当時の判断の記録で、決めたこと自体は正しい。
  - ⚠ IP は保存せず、利用者の識別にも使わない（基盤（Cloudflare）が接続元 IP を扱うことは避けられない）。
    ⚠ 「IP も使わない」と書いていたが、**言い過ぎだった**（2026-08-15 のレビューで指摘）。
    こちらが保存も識別もしないのは本当だが、通信は基盤を通る。
- Referer を止める。`index.html` / `peel.html` の `meta referrer` と `public/_headers` の
  `Referrer-Policy: no-referrer` の**両方**
- 送るのは `worker.js` の `EVENTS` / `TARGETS` / `SOURCES` に列挙した**固定文字列だけ**。それ以外は受け側で捨てる
- **黙って集めない。** 送るかどうかは本人が決める（不具合報告など、本人の操作を起点にする）
- 年代を動かしたことは「触られたか」だけ知りたいので、**1つの場所につき1回**。回数は送らない
- Origin が自分のオリジンでないものは落とす。**Origin が無いものも落とす**。204 を返し、理由は教えない

## そうしなかったこと

- **Referer で流入元を測る** … 自分で止めておいて受け側で読むことはできないし、
  読めたとしても**他人の閲覧元を集める形**になる。`?from=` クエリにした
- **任意の文字列をラベルとして通す** … 外から好きなラベルを増やせる＝この表が信用できなくなる
- **現在地を検索の並べ替えに使う** … 同じURLが人によって違う場所を指し、共有ループが壊れる（0010）

## これを守っているもの

- `worker.js` の冒頭の約束、`EVENTS` / `TARGETS` / `SOURCES`、Origin チェック
- `public/index.html` / `public/peel.html` の `meta referrer`、`public/_headers`
- `npm run check` の `_headers に Referrer-Policy: no-referrer` / `index.html に meta referrer` / `peel.html に meta referrer`
- `npm run render` — 送っているものが列挙の外に出ていないこと、地名も座標も送っていないこと
