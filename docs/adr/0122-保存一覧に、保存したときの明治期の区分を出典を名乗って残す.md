# 0122. 保存一覧に、保存したときの明治期の区分を出典を名乗って残す

- 日付: 2026-11-21
- 状態: 採用
- 決めた人: Owner（文言は 3 案から選んだ）

## 何が起きていたか

地図の見出しは、明治期の区分が読めた場所では「ここは 河川・湖沼・海面 でした」と答える。
保存したくなるのは、この見出しを読んだときになる。

一方、控え（`konjaku-next-saved-v1`）に入っていたのは**いまの地形**の区分（`value`）だけだった。
一覧の行は「町名 ／ 保存日　いまの地形の区分」で、**保存したときに読んだ見出しが残っていなかった。**

## 実測（2026-11-21・手元・幅 375px・main = `03ce092`）

10 か所を開いて保存し、見出しと控えを読んだ。

```text
明治期の区分が見出しに出た   7 / 10（豊洲・浦安・春日部・渋谷・みなとみらい・名古屋駅・越谷）
出なかった                   3 / 10（浅草・品川・大阪梅田。明治期の地図に区分が無い）
区分の字                     河川・湖沼・海面 ×3 ／ 田 ×3 ／ 泥地 ×1
```

## 決めたこと

- 明治期が**面の分類**で読めたとき（見出しが「○○ でした」と言い切るのと同じ条件。`0109`）だけ、
  値を控えに残す（`meiji`）。⚠ 文ではなく値。⚠ 字は画面が `answer.js` から作る
- 一覧では、町名の下に 1 行「**明治期の地図では ○○**」と出す
- 控えていない行（前からの控え・線型・読めなかった場所）は、いままでどおり。⚠ 「無かった」とは言わない
- 合言葉で別の端末へ渡すときも運ぶ（並びの末尾に足す。版は上げない）
- ⚠ **320px では 1 行に収まらない。**⚠ **省略（…）にせず、⚠ 名乗りのあとで折る。**⚠ 区分名は割らない

```text
実測（2026-11-21・手元・Chromium・/saved）
幅      行の本文に使える幅   「明治期の地図では 河川・湖沼・海面」
320px   178px                13px で 211px ／ 12px に下げても 195px   → 2 行
360px   211px                13px で 211px                           → ぎりぎり 1 行
375px   211px                同上
```

  ⚠ 字を小さくしても 320px では収まらない。⚠ 省略すると区分名が欠ける（見出しの答えそのもの）。

## 選ばなかった案

```text
B  ここは ○○ でした     地図の見出しと同じ字。⚠ 一覧ではすぐ下に「氾濫平野・海岸平野」が並び、
                        ⚠ 「田」のように短い区分だと、どちらが昔の話か読めない
C  明治期: ○○           短いが、「明治期」が資料なのか時代なのかがぼやける
```

A は出典名（`SOURCE.meiji`）を借りるので、新しい語を増やさない。
