# 0062. 出典を「何を答えるか」で 3 段に分ける

- 状態: 採用（⚠ **決めたのは Owner。**⚠ 2026-08-29）
- 日付: 2026-08-29

⚠ **`docs/adr/0058`（⚠ 可用性は出典ごとに持つ）の続き。**
⚠ **あちらは「取れたか」の軸。**⚠ **こちらは「何を答えるか」の軸。**

## 決めたこと

```text
地形分類        ⚠ **ここはどんな土地か**
明治期低湿地    ⚠ **ある時点でここは何だったか**
将来の別データ  ⚠ **いつ変わったか**
```

⚠ **出典を、⚠ 答える問いで並べる。**⚠ **どれも「昔の話」だが、⚠ 答えている問いが違う。**

## ⚠ これが、⚠ 3 回のテストで出た問題を説明する

⚠ **利用者役 3 名が、⚠ 3 回とも「いつ」を求めた**（⚠ 0/3 のまま解けていない）。

```text
⚠ **地形分類には「いつ」が無い**（`docs/adr/0060` で実測）。
⚠ **明治期の低湿地を足したが、⚠ 3/3 が「まだ分からない」と答えた。**

A  ⚠ 「明治期は…」は明治のときの状態で、⚠ **「いつ陸にされたか」ではない**
B  ⚠ **知りたいのは「いつ陸地になったか」**
C  ⚠ **足りないのは新しい側の年**
```

⚠ **理由が、⚠ この 3 段で説明できる**:

```text
⚠ **1 段目も 2 段目も、⚠ 「いつ変わったか」には答えられない。**
⚠ **3 段目のデータを、⚠ まだ持っていない。**
```

⚠ **足す出典を増やしても、⚠ 段が同じなら答えは変わらない。**

## ⚠ 空中写真は、⚠ 2 段目（⚠ 3 段目ではない）

⚠ **2026-08-29 に足した。**⚠ **「1936–42 の写真が残っています」と言う。**

```text
⚠ **これは「いつ変わったか」ではない。**
⚠ **「その時点の資料がある」＝ ⚠ **ある時点でここは何だったか**の側。**
```

⚠ **写真の中身は見ない**（Owner 判断・2026-08-29）。
⚠ **見ると、⚠ 「1961 年には陸だった」と言うことになり、⚠ 推定を実測のように見せる**
（⚠ 白黒写真で海と屋根を見分けられるかは未検証）。

⚠ **できるのは挟みこむことだけ**:

```text
明治期の地図から   河川・湖沼・海面 でした
空中写真から       1936–42 の写真が残っています
```

⚠ **「明治期は水、⚠ 1936 年には写真がある」まで。**⚠ **利用者が挟み撃ちで見当をつける。**

## ⚠ 3 段目に、⚠ 何が要るか（⚠ 決めていない）

```text
⚠ **「いつ変わったか」を持つ出典が要る。**
⚠ **いま持っている 3 つは、⚠ どれも 1 段目か 2 段目。**
```

⚠ **候補**（⚠ どれも未調査）:

```text
⚠ 埋立の竣工年（⚠ 港湾・自治体の資料）
⚠ 旧版地形図の年代（⚠ 複数年代を並べれば、⚠ 変わった時期が挟める）
⚠ 建物の建設年（⚠ β 版が持っているが、⚠ 建物の年であって土地の年ではない）
```

⚠ **3 段目が無い間は、⚠ 「いつ変わったか」に答えない。**⚠ **答えたふりをしない**（掟 §1）。

## ⚠ 画面は、⚠ この 3 段のとおりに並んでいる

```text
いまの地形から     ここは、かつて水面で、その後陸地にされた土地   ⚠ 1 段目
明治期の地図から   河川・湖沼・海面 でした                        ⚠ 2 段目
空中写真から       1936–42 の写真が残っています                   ⚠ 2 段目
```
