# 0060. 説明を主にし、「いつ」は言えるものだけ言う

- 状態: 採用（⚠ **決めたのは Owner。**⚠ 2026-08-29）
- 日付: 2026-08-29

⚠ **最初の縦切りを、⚠ 利用者役 3 名に見せて出た指摘への答え**（`docs/adr/0059` の実装フェーズ）。
⚠ **3 名とも実在の利用者ではない**（`ui-ux-review` §6）。

## ⚠ ① 説明を主に、⚠ 区分名を従にする

```text
⚠ **前**   ここは 旧水部
           かつて水面で、その後陸地にされた土地   ⚠ 小さく・薄く

⚠ **後**   ここは、かつて水面で、その後陸地にされた土地
           国土地理院の区分：旧水部                ⚠ 小さく
```

⚠ **利用者役 2 名が、⚠ 別々に同じことを言った**:

```text
A  ⚠ **分かる言葉を小さいほうに置いているのが逆**
   ⚠ 「旧水部」で読み方に一瞬止まった。⚠ **5 秒では足りなかった**
C  ⚠ **かみ砕いたほうが読みにくいのは逆**
```

⚠ **区分名は消さない。**⚠ **消すと、⚠ 何を根拠に言っているかが分からなくなる**
（⚠ B が「出典が無いのは気になる」と言っている）。⚠ **「国土地理院の区分：」と添える。**

⚠ **`docs/adr/0054`（⚠ 区分の言い換えを運ぶ）は変えない。**⚠ **どちらを主にするかを、⚠ ここで決めた。**

⚠ **利用者役 3 名とも「押せるように見えない」と言った。**

⚠ **前**   凡例の中に、⚠ ただの字として並べていた
⚠ **後**   ⚠ **枠のあるボタン**（⚠ 44px 以上）。⚠ 押すと bottom sheet に全区分

⚠ **`docs/adr/0026` は「押しても何も起きない導線を作らない」。**
⚠ **その逆側 ──⚠ 押せるのに押せなく見える ── も同じ問題。**

## ⚠ ③ 「いつ」は、⚠ 言えるものだけ言う

⚠ **利用者役 3 名が全員「いつの話か分からない」と言った。**

```text
A  ⚠ 江戸？戦前？昭和？ どこにも書いていない
B  ⚠ **いつの「旧」なのか分からない。**⚠ 豊洲と浦安と松江を同じ括りにしていいのか
C  ⚠ **「その後陸地にされた」の“その後”がいつなのか、⚠ 最後まで分からない**
```

### ⚠ 調べた（⚠ 実測 2026-08-29）

```bash
node scripts/survey-when.mjs
```

⚠ **数字は書き写さない。**⚠ **判断が変わったところだけ書く。**

| 出典 | ⚠ 「いつ」を持っているか | 粒度 |
|---|---|---|
| ⚠ **地形分類** | ⚠ **持っていない** | ⚠ **属性は `code` だけ。**⚠ 説明文にも年は無い |
| 明治期の低湿地 | ⚠ **出典名だけ** | ⚠ 「明治期」という幅。⚠ 点ごとの年は無い |
| 空中写真 | ⚠ 持っている | ⚠ 撮影年代。⚠ **点ごとではなく年代ごとの面** |
| Wikidata の点 | ⚠ 持っている | ⚠ **点ごとに違う年** |
| 自然災害伝承碑 | ⚠ 持っている | ⚠ **点ごとに違う年**（⚠ 建立年 ＋ 災害の発生年月日） |

### ⚠ だから、⚠ こうする

```text
⚠ **地形分類には「いつ」が無い。**⚠ **無いものを画面で言わない**（掟 §1）。
⚠ **「その後陸地にされた」の「その後」は、⚠ どこからも取れない。**
```

⚠ **推し量って年を書かない。**⚠ **「昭和の埋立てでしょう」は、⚠ 推定を実測のように見せることになる。**

⚠ **言えるのは、⚠ 出典が持っている分だけ**:

```text
⚠ 明治期の低湿地   →  ⚠ 「明治期は…」と言える（⚠ 幅として）
⚠ 空中写真         →  ⚠ 「1936 年の写真では…」と言える
⚠ 点（Wikidata・伝承碑）→ ⚠ **点ごとの年を言える**
```

⚠ **地形分類だけで語る画面では、⚠ 「いつ」を言わない。**⚠ **言えないことを、⚠ 言えるふりをしない。**

### ⚠ これは、⚠ v0.1.0 の作り方に効く

⚠ **利用者が知りたい「いつ」に答えるには、⚠ 地形分類だけでは足りない。**
⚠ **明治期の低湿地・空中写真・点を、⚠ 重ねる必要がある。**

⚠ **`docs/adr/0058`（⚠ 可用性は出典ごとに持つ）の形が、⚠ ここでも効く。**
⚠ **「いつ」も出典ごとに持ち、⚠ 言える出典だけが言う。**

## ⚠ 決めていないこと

```text
⚠ 「いつ」を、⚠ 画面のどこで言うか（⚠ この縦切りには、⚠ まだ低湿地も写真も入っていない）
⚠ 地形分類だけの土地で、⚠ 「いつ」の不在をどう扱うか（⚠ 断るか、⚠ 黙るか）
⚠ 豊洲・浦安・松江が同じ「旧水部」でよいか（⚠ B の指摘。⚠ 出典の区分なので、⚠ こちらでは変えられない）
```
