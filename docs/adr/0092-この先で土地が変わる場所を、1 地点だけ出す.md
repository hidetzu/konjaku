- 状態: 決めた

## 何を決めたか

⚠ **`/deep` の末尾に、⚠ 「この先で、土地が変わる」を 1 地点だけ出す。**

```text
出す      いまの区分 → 変わった先の区分 ／ 距離 ／ 方角
出さない  ⚠ 所要時間（⚠ 実測していない。⚠ 歩く速さも道のりも知らない）
          ⚠ 2 地点以上 ／ ⚠ 一覧 ／ ⚠ 検索 ／ ⚠ 押せる導線
```

## ⚠ `/peel` の規則を動かした

⚠ **`.claude/rules/domain.md` は「別の場所を探す導線を足さない」と決めていた。**
⚠ **このテーマのために動かした**（2026-09-05。Owner 判断）。

⚠ **かわりに、⚠ ガードレールを検査で固定する。**⚠ **規則だけでは約束にしかならない。**

```text
1 地点だけ        ⚠ 行き先の器は 1 つ（⚠ 静的・実描画の両方で数える）
一覧にしない      ⚠ ul / ol / li を置かない
押せる導線なし    ⚠ a / button / input を置かない
```

⚠ **ここは「行き先」ではなく「そこに在るという事実」。**
⚠ **押しても何も起きない導線を置かない**（[`0026`](<0026-押しても何も起きない導線を置かない.md>)）。

