# 0092. この先で土地が変わる場所を、1 地点だけ出す

- 状態: 決めた
- 日付: 2026-09-05
- ⚠ **v0.3.0 のテーマ「調べた場所から、次に歩く場所が見つかる」の最初の実装**（Owner 判断）。

## 何を決めたか

⚠ **`/deep` の末尾に、⚠ 「この先で、土地が変わる」を 1 地点だけ出す。**

```text
出す      いまの区分 → 変わった先の区分 ／ 距離 ／ 方角
出さない  ⚠ 所要時間（⚠ 実測していない。⚠ 歩く速さも道のりも知らない）
          ⚠ 2 地点以上 ／ ⚠ 一覧 ／ ⚠ 検索 ／ ⚠ 押せる導線
```

## ⚠ `/peel` の規則を動かした

⚠ **`.claude/rules/domain.md` は「別の場所を探す導線を足さない」と決めていた。**
⚠ **このテーマのために動かした**（2026-09-05。Owner 判断）。

⚠ **かわりに、⚠ ガードレールを検査で固定する。**⚠ **規則だけでは約束にしかならない。**

```text
1 地点だけ        ⚠ 行き先の器は 1 つ（⚠ 静的・実描画の両方で数える）
一覧にしない      ⚠ ul / ol / li を置かない
押せる導線なし    ⚠ a / button / input を置かない
```

⚠ **ここは「行き先」ではなく「そこに在るという事実」。**
⚠ **押しても何も起きない導線を置かない**（[`0026`](<0026-押しても何も起きない導線を置かない.md>)）。

## ⚠ 新しいデータを作っていない

⚠ **地形分類は、⚠ すでにベクトル（GeoJSON の面）で取っている。**
⚠ **境目は、⚠ その面の縁そのもの。**⚠ **事前処理を増やさずに出せる**（`CLAUDE.md` §3）。

```text
public/border.js   ⚠ DOM も地図も fetch も持たない。⚠ Node から呼べる
public/verify.js   ⚠ 取りに行くのはここ（z16 の 3×3 タイル）
public/answer.js   ⚠ 字はここだけ
```

## ⚠ どれくらいの土地で出せるか（⚠ 実測 2026-09-04）

⚠ **`scripts/survey-border.mjs`。**⚠ **z16・3×3 タイル・上限 600m。**

```text
出せる        17 地点  71%
足元が無い     7 地点  29%   ⚠ 地形分類そのものが無い（山間 2・離島 3・稚内・軽井沢）
```

⚠ **標本 24 地点は日本全体ではない。**⚠ **既存の調査と同じ地点なので、⚠ 都市に偏る。**
⚠ **数はここに書かない**（⚠ 上は測った日の値。⚠ 走者が出す）。

## ⚠ 「次に歩く」とは言わない

⚠ **実測（17 地点）で 9〜283m・中央値 100m。**

```text
試作で見せた値   210m 〜 450m
実測             9m 〜 283m
```

⚠ **歩いて向かう場所ではなかった。**⚠ **多くの土地で、⚠ 境目はすぐそこにある。**
⚠ **見出しは「この先で、土地が変わる」**（2026-09-05。Owner 判断）。
⚠ **9m でも 283m でも嘘にならない。**

## ⚠ 「地面」とは言わない

⚠ **変わった先が「水部」のことがある**（⚠ 実測: 春日部 20m 北東）。
⚠ **そこは地面ではない。**⚠ **「地面が変わる」と書くと、⚠ その先が陸だと読まれる。**

## ⚠ 出せないときは、節ごと出さない

⚠ **2026-09-05。Owner 判断。**⚠ **出せない理由を書くと、
⚠ できないことから書き始めることになる**（`CLAUDE.md` §4-1）。

⚠ **`border.js` は 4 通りを言い分ける**（掟の一行目）。

```text
ok          境目が上限内に在り、⚠ 向こう側の区分も読めた
遠い        境目は在るが、⚠ 上限より遠い
見えない    ⚠ 読み込んだ範囲に別の区分が無い（⚠ 「無い」とは言えない）
足元が無い  ⚠ この点に地形分類が無い（⚠ 対象範囲の外）
```

## ⚠ fallback は入れない

⚠ **「境目が無い土地だけ碑へ落とす」は、⚠ この回は入れない**（2026-09-05。Owner 判断）。
⚠ **先に、⚠ 境目だけで測る。**

## ⚠ 途中で踏んだこと

### 1. ⚠ 同じ区分の継ぎ目を、⚠ 境目と数えていた

⚠ **`toCode !== 自分` を見ていなかった。**

```text
直す前   高知 1m ／ 長野 9m ／ 網走 14m   ⚠ どれも同じ区分の面の継ぎ目
直した後 高知 36m ／ 長野 9m ／ 網走 37m  ⚠ 区分が本当に変わるところ
```

⚠ **測って初めて分かった。**⚠ **字を読むだけでは気づけない。**

### 2. ⚠ 検査が、⚠ 自分の説明を拾っていた（2 回）

⚠ **`deep.js` のコメントに書いた「この先で、土地が変わる」を、
⚠ 「画面のコードが字を決めている」と読んだ**（`CLAUDE.md` §5）。
⚠ **`border.js` の JSDoc に書いた `{ state:"足元が無い" }` も同じ。**
⚠ **後者は、⚠ わざと壊しても素通りした。**

### 3. ⚠ 404 / 500 では、⚠ 境目の分岐まで届かない

⚠ **地形分類そのものが読めないので、⚠ `/deep` は判定の前で止まる。**
⚠ **わざと「境目はありません」と書かせても素通りした。**
⚠ **だから、⚠ 「判定は出るが境目だけ出せない」形で突く**
（⚠ どのタイルも同じ区分 1 つで埋める）。

⚠ **「氾濫平野」は無く、⚠ 実物は「氾濫平野・海岸平野」だった。**
