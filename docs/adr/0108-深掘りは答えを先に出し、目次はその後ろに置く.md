## 決めたこと

⚠ **狭い幅では、⚠ 目次を答えの後ろへ置く。**⚠ **DOM の順を入れ替えるだけ。**

```text
前   目次 → 地図で見る → ラベル → 答え
後   地図で見る → ラベル → 答え → 目次 → 各節
```

⚠ **広い幅は 1px も動かない**（⚠ `position:fixed` で柱の右。⚠ DOM 順は位置に効かない）。
⚠ **読み上げと Tab の順も、⚠ 答えが先になる。**
