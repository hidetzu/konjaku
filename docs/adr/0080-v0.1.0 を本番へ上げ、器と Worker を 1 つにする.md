# 0080. v0.1.0 を本番へ上げ、器と Worker を 1 つにする

- 状態: 決めた
- 日付: 2026-09-01

## 何を決めたか

⚠ **`public-next/` を `public/` の正本にし、⚠ β 版を本番から降ろす。**

```text
前  konjaku       wrangler.jsonc       public/       worker.js       ← β 版（本番）
    konjaku-next  wrangler.next.jsonc  public-next/  worker-next.js  ← v0.1.0（dev）

後  konjaku       wrangler.jsonc       public/       worker.js       ← v0.1.0（本番）
```

⚠ **[ADR 0050](<0050-v0.1.0 は別の Worker で作り、β 版に触らない.md>) の前提が変わる。**
⚠ **あれは「β 版に一切触らない」ための分離だった。**⚠ **その役目は終わった。**

⚠ **Owner の言葉（2026-09-01）**:

> これは単純な public-next → public のコピーではなく、v0.1.0 の本番昇格として実施してください。
> 最終状態は public/ と worker.js が唯一の本番正本です。

## ⚠ 単純なコピーでは動かなかった（実測）

⚠ **7 つ引っかかった。**⚠ **どれも、⚠ 測る前には見えていなかった。**

| # | 何が起きるか |
|---|---|
| 1 | ⚠ **`public/data` と `public-next/data` は別物**（⚠ β は建物 28MB、⚠ v0.1.0 は碑・記録・表） |
| 2 | ⚠ **31 個の検査ファイルが `public/` を読んでいた** |
| 3 | ⚠ **Worker が違う**（⚠ `/t` は `worker.js`、⚠ `/api/handoff/*` は `worker-next.js`） |
| 4 | ⚠ **v0.1.0 は検索よけがかかったまま**（⚠ `Disallow: /` ／ noindex ／ 全 7 画面の meta） |
| 5 | ⚠ **公開に要る資産が無い**（⚠ OGP ／ アイコン ／ manifest ／ sw） |
| 6 | ⚠ **`Referrer-Policy` が 1 つも無い**（⚠ β は `_headers` と meta の両方で持っていた） |
| 7 | ⚠ **β の計測 `/t` が ADR 0047 の観測に乗っている** |

## 決めたこと（1 つずつ）

### 1. 検索よけは外す。⚠ AI の学習拒否は分けて残す

```text
public/robots.txt   ⚠ 消した（⚠ β 版と同じ形へ戻した）
_headers            ⚠ X-Robots-Tag: noindex, nofollow を外した
全 7 画面           ⚠ <meta name="robots" content="noindex"> を外した
```

⚠ **AI ボット 9 種の拒否は、⚠ Cloudflare の Managed robots.txt が zone 全体に対して持っている。**
⚠ **こちらのファイルではないので、⚠ 消しても残る。**⚠ **分離できた。**

⚠ **`robots.txt` を置かないほうが、⚠ 何が効いているかが 1 か所で読める**
（⚠ 置くと同じ `User-agent: *` の塊に連結され、⚠ `Allow` が勝ちうる。⚠ ADR 0070 の実測）。

### 2. Worker は 1 つ。`worker.js` が本番の入口

```text
/t              ⚠ 計測（⚠ そのまま）
/api/handoff*   ⚠ 合言葉で荷物を手渡す（⚠ 中身は handoff.js。⚠ 入口が借りるだけ）
```

⚠ **`worker-next.js` は畳んで消した。**⚠ **`wrangler.next.jsonc` も消した。**
⚠ **入口から `export default` 以外を出さない**という制約は引き継いでいる（⚠ 検査が見張る）。

### 3. PWA とオフラインは引き継がない。⚠ ただし移行用の SW は要る

⚠ **Owner 判断**: ⚠ **OGP とアイコンだけ作る。**⚠ **`manifest.webmanifest` と控えは持たない。**

⚠ **`public/sw.js` は残す。**⚠ **ただし中身は「自分を消すためだけの SW」。**

```text
install   ⚠ skipWaiting（⚠ 古い SW をすぐ置き換える）
activate  ⚠ 控えを全部消す → ⚠ unregister() → ⚠ 開いている頁を読み直させる
fetch     ⚠ 持たない（⚠ 何も横取りしない）
```

⚠ **なぜ要るか**: ⚠ **β 版は `/sw.js` を root scope で登録していた**
（⚠ `index.html` と `peel.html` の両方）。⚠ **一度でも β 版を開いた端末には残っている。**
⚠ **SW は配信より先に応答するので、⚠ 消さないと β 版の `/` が出続ける。**

⚠ **「404 になれば登録も消える」という挙動はあるが、⚠ こちらでは確かめていない。**
⚠ **確かめていないことに頼らない**（`CLAUDE.md` §1）。⚠ **自分で消す。**

⚠ **`_headers` で `/sw.js` は `no-store`。**⚠ **持たれると、⚠ 消しに来た本人が古いまま残る。**

### 4. ⚠ `Referrer-Policy` は `same-origin`（⚠ `no-referrer` ではない）

⚠ **v0.1.0 は、⚠ これを 1 つも持っていなかった**（⚠ `_headers` にも meta にも）。
⚠ **外向きのリンクは `rel="noopener"` だけで、⚠ `noreferrer` は付いていない。**
⚠ **そのまま上げると、⚠ 国土地理院や GitHub を押した先へ `?ll=` の座標が届いていた。**

⚠ **最初 `no-referrer` にしたら、⚠ 実描画が落ちた。**

```text
✗ 深掘り画面から、来た画面へ戻れる — 同じサイトから来たのに、直前へ返す字でない
```

⚠ **`no-referrer` は、⚠ 同じサイトの中の `document.referrer` まで消す。**
⚠ **`/deep` が「どこから来たか」を読めなくなり、⚠ 「← ひとつ前へ」が出なくなった**（`back.js`）。

⚠ **`same-origin` にした。**⚠ **外へ 1 本も送らないのは同じで、⚠ 中では残る。**
⚠ **検査も「字」ではなく「外へ送らない方針か」で見るようにした。**

### 5. 内部のリンクは拡張子なし

⚠ **実測（2026-09-01・`dev.konjaku.hidetzu.work`）**:

```text
/about.html    307 → /about
/saved.html    307 → /saved
/privacy.html  307 → /privacy
/about         200
/deep          200
```

⚠ **v0.1.0 は両方を混ぜていた**（⚠ `./about.html` と、⚠ `./deep` / `./saved`）。
⚠ **8 ファイル・45 か所を拡張子なしへ揃えた。**⚠ **転送が 1 段減る。**

### 6. 出典・ライセンス

- ⚠ **出典を求めるのは、⚠ 地理院タイルを読む画面だけ**（⚠ 前は全 HTML）。
  ⚠ **v0.1.0 は 7 枚あり、⚠ 規約・保存一覧・受け取り口は地図を出さない。**
  ⚠ **読み込んでいる JavaScript まで辿る**（⚠ タイルを引くのは `land.js` / `verify.js`）。
- ⚠ **`LICENSES.md` の表を、⚠ v0.1.0 が配るデータへ差し替えた**
  （⚠ 地形分類 ／ 自然災害伝承碑 ／ 市区町村 ／ 土地利用コード ／ 地域の記録）。

### 7. 段の名前をやめ、版の番号を突き合わせる

```text
前  画面「今昔 β」 ／ README「β 版」 ／ SPEC「β 版」
後  画面「今昔 v0.1.0」（about の 1 か所） ／ README「v0.1.0」 ／ SPEC「v0.1.0」
```

⚠ **開発の段を表す言い方は使わない**（⚠ 「作りかけ」を消したのと同じ理由。ADR 0078 の追記）。
⚠ **画面の正本は `about.html` の 1 か所**（⚠ 静的検査 ⑱ が守る）。

### 8. ⚠ 検索の並べ替えが、⚠ 落ちていた

⚠ **cutover の途中で見つけた。**⚠ **β 版が実測で直した不具合が、⚠ v0.1.0 で戻っていた。**

⚠ **地理院の住所検索は関連度で返さない。**⚠ **都道府県コードの昇順（北→南）で返る。**

```text
実測（2026-09-01・本物の応答）
  豊洲  1 番目 青森県八戸市豊洲     （東京都江東区豊洲は 2 番目）
  渋谷  1 番目 福島県猪苗代町渋谷   （東京都渋谷区は 3 番目）
  新宿  1 番目 山形県朝日町新宿     ⚠ 東京都新宿区は 12 番目 ＝ 先頭 8 件に入らない
```

⚠ **v0.1.0 は `list.slice(0, 8)` で、⚠ 応答をそのまま出していた。**
⚠ **「新宿」と打つと、⚠ 東京都新宿区が画面に 1 度も出ない。**

⚠ **`places.js` を運んだ。**⚠ **β 固有ではない**（⚠ DOM も地図も持たない。⚠ 応答の 4 フィールドだけで決める）。
⚠ **外へのリクエストは増えていない**（⚠ 1 検索 1 リクエストのまま）。
⚠ **`test/search-check.mjs`（42 語）も、⚠ 消さずに残した。**

### 9. ⚠ こちらの不具合を「通信できません」と言っていた

⚠ **同じところで、⚠ もう 1 つ踏んだ。**

```js
// 前
try {
  const list = await finder.search(s);   // ⚠ 取りに行く
  hits.innerHTML = …                     // ⚠ 描く（⚠ ここも同じ try の中）
} catch (err) {
  kickText.textContent = whyOf(err);     // ⚠ 「通信できません」
}
```

⚠ **`places()` の返りを取り違えただけ**（⚠ `{rows, pick}` を配列として `.map()` した）**なのに、
⚠ 画面は「通信できません」と言った。**

⚠ **押し直しても直らないのに、⚠ 待てば直るように読める。**
⚠ **こちらの都合を、⚠ 回線の都合のように言わない**（`CLAUDE.md` §4-1）。
⚠ **取りに行くところだけを `try` で包むように分けた。**

### 10. ⚠ 読み込みの順を、⚠ 誰も見ていなかった

⚠ **`places.js` を `gsi-address-search.js` より先に置いた。**
⚠ **`places.js` は読み込んだ時点で `TIMEOUT_MS` を読む**ので、⚠ `undefined` になり、
⚠ **ページのスクリプトが丸ごと止まった**（⚠ 実描画 83 件中 46 件が、⚠ 同じ 1 行で落ちた）。
⚠ **静的検査は緑のままだった。**

⚠ **字面では見分けられなかった**（⚠ 一度そう書いて、⚠ わざと壊しても素通りした）。
⚠ **依存を読む行は関数の中にあり、⚠ 呼ぶのが最上位**だった。

⚠ **実際に順に読み込んで、⚠ 落ちるかを見る形にした**（`test/check/next.mjs` ⑳。⚠ ブラウザ不要）。
⚠ **DOM は作りもので埋めるが、⚠ `Konjaku*` は埋めない**
（⚠ 埋めると、⚠ 捕まえたい不具合をこの検査自身が隠す。⚠ **実際にそう書いて素通りした**）。

## ⚠ 消した検査と、⚠ 代わりを持たない保護

⚠ **黙って消さない。**⚠ **ここに全部書く。**

### 代わりがあるもの

| 消した節 | 代わり |
|---|---|
| `color.mjs` | ⚠ `next.mjs` ⑩（⚠ 色は 1 か所か。⚠ どの色みでも読めるか） |
| `privacy.mjs` | ⚠ `next.mjs` ⑲（⚠ v0.1.0 の `/privacy` を見る） |
| `words.mjs` / `roles.mjs` / `vocab.mjs` | ⚠ `docs.mjs`（⚠ 言葉の持ち主を v0.1.0 のものへ差し替えた） |

### ⚠ 代わりを持たないもの（⚠ これは失われた）

| 消した節 | 何を守っていたか |
|---|---|
| `motion.mjs` | ⚠ **`prefers-reduced-motion` を無視していないこと**（⚠ β の 3D 用だったが、⚠ 主張自体は普遍） |
| `style.mjs` | ⚠ **文字の根元が `rem`（⚠ 文字サイズ設定に追いてくる）／ 同じ値が 2 か所に無い** |
| `era.mjs` / `land.mjs` / `place.mjs` / `answer.mjs` / `data.mjs` | ⚠ β の画面・データ固有（⚠ v0.1.0 に対応物が無い） |
| `deliver.mjs` の SW / version の節 | ⚠ **控える一覧と配信中の版**（⚠ v0.1.0 は両方持たない） |

⚠ **`motion` と `style` は、⚠ v0.1.0 でも意味がある。**⚠ **別の課題として置く。**
⚠ **この ADR では戻さない**（⚠ 範囲を広げない。`CLAUDE.md` §7-4）。

## ⚠ 人が確かめること（⚠ 検査では止められない）

⚠ **Cloudflare の Workers Builds が、⚠ `konjaku` をこちらの検査と無関係に出している。**
⚠ **ダッシュボードの設定なので、⚠ このリポジトリからは止められない。**

```text
切っていない場合   ⚠ 検査の緑を待たずに本番が出る経路が残る（⚠ 二重に出る）
切った場合         ⚠ 本番は .github/workflows/check.yml の `deploy` だけが出す
                   ⚠ 門番 3 つ（静的・検索・実描画）が全部緑のときだけ走る
```

⚠ **ADR 0070 が「Cloudflare 側は検査の緑を待てない」と書いている。**⚠ **その理由は変わっていない。**
