# 0073. 合言葉の荷物は、β 版と同じ D1 に置く

- 状態: 採用（⚠ **決めたのは Owner。**⚠ 2026-08-29）
- 日付: 2026-08-29
- 関連: [`0050`](<0050-v0.1.0 は別の Worker で作り、β 版に触らない.md>)（⚠ **一部を差し替える**）、
  [`0072`](<0072-端末をまたぐのは引換券にし、アカウントを作らない.md>)、
  [`0047`](<0047-保存の仮説は、明示・配置・計測の順で確かめる.md>)
- ⚠ **根拠の種別**: ⚠ **Owner 判断**（⚠ 実測ではない）。

## 決めたこと

⚠ **合言葉の荷物（`handoff` / `handoff_attempt`）を、⚠ β 版と同じ D1（`konjaku`）に置く。**

```text
⚠ 変わった   別の DB を作る      →  ⚠ **同じ DB を使う**（⚠ database_id は wrangler.jsonc と同じ）
⚠ 変わらない ⚠ **表は分ける**（`handoff` / `handoff_attempt` ／ β は `tick` / `health`）
⚠ 変わらない ⚠ **β の表には触らない**
⚠ 変わらない ⚠ **Worker は別**（`konjaku-next` ／ β は `konjaku`）
⚠ 変わらない ⚠ **配るものは別**（`public-next/` ／ β は `public/`）
```

## ⚠ 何を取り下げたか

⚠ **[`0050`](<0050-v0.1.0 は別の Worker で作り、β 版に触らない.md>) と
[`../sync-api.md`](../sync-api.md) §5 は、⚠ 「別の DB を作る」を MUST にしていた。**
⚠ **理由は「β 版の計測（`tick` / `health`）と混ざると、⚠ 分母が壊れる」**（`CLAUDE.md` §6）。

⚠ **その MUST を取り下げる。**⚠ **取り下げたことを、⚠ 書かずに済ませない。**

⚠ **`test/check/next.mjs` には「β と同じ D1 を繋いでいたら落とす」検査が在った。**
⚠ **消したのではなく、⚠ 主張を移した**（⚠ 下の「境界は検査が見る」）。

## ⚠ 何が変わらないか（⚠ Owner 判断）

⚠ **表が分かれているので、⚠ `tick` の行は混ざらない。**⚠ **計測への影響は無い**
（2026-08-29。Owner 判断）。

```text
handoff / handoff_attempt   ⚠ v0.1.0 が読み書きする
tick / health               ⚠ β 版が読み書きする   ⚠ **v0.1.0 は触らない**
```

⚠ **`docs/adr/0047` の 3〜5 段目が乗っている観測は、⚠ そのまま続く。**

## ⚠ 何は共有するか

⚠ **枠は DB 単位**（⚠ 書き込み 10万行/日 ／ 容量 5GB）。⚠ **そこだけは分けられない。**

⚠ **いまは効かない。**⚠ **v0.1.0 にはまだ利用者がいない**（`docs/adr/0050`）。
⚠ **効き始めるのは、⚠ 手渡しの書き込みが 1 日 10万行に近づいたとき。**
⚠ **そのとき起きるのは、⚠ 上限に当たった日に `tick` が欠けること**
（⚠ 欠けた日は「使われなかった」と区別がつかない。`CLAUDE.md` §1）。

⚠ **これは検査では止められない。**⚠ **止めているように書かない。**
⚠ **効き始めたら、⚠ 下の「戻すとき」を回す。**

⚠ **もう 1 つ、⚠ 枠とは別に。**⚠ **β 版の DB に、⚠ 利用者の座標入りの `payload` が入る**
（⚠ 期限まで）。⚠ **これは「読まれる」の話ではなく、⚠ 「どこに在るか」の話**
（`../sync-api.md` §1）。⚠ **画面が言うのは、⚠ そのどちらでもなく「何を預けるか」。**

## ⚠ 境界は検査が見る

⚠ **「別の DB か」は、⚠ もう主張できない。**⚠ **代わりに、⚠ まだ守れるものを見る。**

```text
⚠ βの表（tick / health）に触っていないか
   ⚠ worker-next.js と migrations/*.sql を読む（⚠ 0001_tick.sql は除く）
   ⚠ FROM / INTO / UPDATE / TABLE / JOIN のあとに tick・health が来たら落とす
```

⚠ **ここが破れると、⚠ 分母が壊れるどころではない。**⚠ **計測そのものが書き換わる。**

⚠ **枠の共有は、⚠ 検査では止められない**（⚠ 上の「何は共有するか」）。
⚠ **止められないものを、⚠ 止めているように書かない。**

## ⚠ 戻すとき

⚠ **枠が実際に足りなくなったら、⚠ 別の DB へ移す**（⚠ いまは足りている）。

```text
1  konjaku-next を作る
2  wrangler.next.jsonc の database_id を差し替える
3  migrations/0002_handoff.sql を、そちらへ当てる
4  ⚠ 古い荷物は運ばない（⚠ 期限つきなので、⚠ 待てば空になる）
```

⚠ **`handoff` は期限つきなので、⚠ 移行にデータの持ち越しが要らない。**
⚠ **これが「あとから戻せる」ことの根拠**（⚠ `tick` はそうではない）。

## ⚠ 決めていないこと

```text
⚠ 枠をどこで見張るか   ⚠ 書き込み数を測る仕組みは無い。⚠ 上限に当たるまで分からない
⚠ Cron での掃除        ⚠ 置いていない（`../sync-api.md` §4）。⚠ だから「消えます」と言わない
```
