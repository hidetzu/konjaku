# 0121. 規則の本文は `.claude/rules/` へ置き、`CLAUDE.md` は目次と宛先として残す

- 日付: 2026-10-11
- 状態: 採用
- 決めた人: Owner
- ⚠ **Owner の指示**: 「`CLAUDE.md` に書いているところは、ルール等のファイル分割はしておいてもいい」

## 困っていたこと

⚠ **`CLAUDE.md` が、目次と本文の両方を持っていた**（⚠ 実測 2026-10-11・分割前）。

```text
CLAUDE.md             306 行 / 24,883 バイト
  §9 踏んだ落とし穴    4,126 バイト   ⚠ いちばん大きい
  §7 進め方            2,126
  §8 git               1,467
  §4 言葉              1,303
.claude/rules/        6 ファイル / 493 行
```

⚠ **`.claude/rules/git.md` は 31 行で、⚠ 冒頭に「許可の正本は `CLAUDE.md` §8」と書いてあった。**
⚠ **1 つの主題が 2 つのファイルに分かれていて、⚠ どちらを読めばよいか決まっていない。**

⚠ **`hidetzu/claude-dev-template` は既に分けてある**（`evidence.md` / `git.md` /
`owner-decisions.md` / `verification.md`）。⚠ **今昔とは構造が違うので、⚠ 規則を行き来させるたびに
手で突き合わせることになっていた**（⚠ 2026-10-11 に実際に競合した）。

## 決めたこと

```text
.claude/rules/   規則の本文
CLAUDE.md        目次 ＋ 実際に踏んだこと（§9）
```

| 移したもの | 行き先 | 宛先として残した見出し |
|---|---|---|
| 掟・数字の書き方 | `evidence.md` | §1・§6 |
| 画面に出す言葉 | `words.md` | §4・§4-1 |
| 自分で決める／人に聞く・`ready-for-ai`・Issue の書き換え | `owner-decisions.md` | §7-1〜§7-3 |
| コミットと push の許可・外に出す文 | `git.md`（既存へ寄せた） | §8・§8-1 |

⚠ **`CLAUDE.md` に残したもの**: 前文 ／ §2 検査（回し方は `verify`） ／ §3 アーキテクチャの境界 ／
§5 コメント ／ §7 の 1〜4 ／ ⚠ **§9 踏んだ落とし穴**。

⚠ **実測（分割後）**: `CLAUDE.md` 183 行。⚠ **静的検査は 312 件で、⚠ 分割前と同じ。**

## ⚠ 節番号は、宛先として残す

⚠ **これが決め手。**⚠ **既存の記録が `CLAUDE.md` の節番号で規則を指している**
（⚠ 実測 2026-10-11・追跡ファイル）:

```text
§9  114 本    §1  94 本    §3  62 本    §6  50 本    §5  44 本
§4-1 26 本    §8-1 12 本   §2  10 本    §7-1 8 本    §4   8 本
```

⚠ **ADR は、⚠ そのとき何を根拠に決めたかの記録。**⚠ **後から一括置換しない**
（`CLAUDE.md` §4 の「一括置換しない」と同じ理由）。
⚠ **だから見出しは消さず、⚠ 「正本は〜」の 2 行に置き換えた。**
⚠ **`CLAUDE.md` §1 と書いた既存の参照は、⚠ そのまま読める。**

⚠ **ただし `.claude/rules/` の中だけは、⚠ 直接指すように直した**（6 か所）。
⚠ **同じディレクトリの中で「正本は別のファイルの中の節」と書くと、
⚠ 「正本」という語が 2 か所を指してしまう。**

## ⚠ 検査が見ていたものを、見えるままにした

⚠ **`test/check/guard.mjs` は `CLAUDE.md` に `ready-for-ai` の字があることを見ていた。**
⚠ **宛先の行にもその字は出るので、⚠ 置き換えたあとも緑のままになる**
（⚠ **何も見ていないのに緑**。`CLAUDE.md` §9 の「別の文を拾って素通りした」と同じ形）。

⚠ **正本のファイルを見るようにし、⚠ 「付けるのは人」まで書かれていることを見る形にした。**
⚠ **わざと壊して確かめた**（⚠ 実測 2026-10-11）:

```text
「付けるのは人だけ」を消す   →  ✗ 落ちた（⚠ 狙った理由で落ちている）
リンク先を消えたファイルへ   →  ✗ 落ちた（.claude/rules/ も link 検査の網に入っている）
```
