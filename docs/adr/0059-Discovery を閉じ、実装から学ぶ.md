⚠ **「決める前に作らない」で通した。**

```text
0045  最小体験に「別の端末で続きから」を足す
0046  決めるものを絞り、β 版の構成を引き継がない
0047  保存の仮説は、明示・配置・計測の順で確かめる
0048  散歩と家を分け、端末をまたぐのは URL で始める

0052  深掘り地点を、過去性のある具体物に限定する
0053  ピンが無い土地は足元を言い切り、「へえ」が無い地点を許容する

0056  明治期の低湿地の状態を 3 つに分けて言い分ける
0057  地形分類の「整備範囲外」は、粗くなるのであって無くならない
0058  可用性は出典ごとに持ち、場所の型は保存しない
```

### ⚠ スマホトップの姿（⚠ 字で確定した）

```text

  ■ 旧水部　■ 水部　■ 盛土地･埋立地　ほか n 種

  ♡ あとで見る    PC で詳しく →

地図      ⚠ 主役。⚠ viewport に映る分を色で塗る。⚠ 未整備は斜線
ピン      ⚠ 1km 以内・⚠ 近い順に最大 3 件。⚠ **無くても画面は成立する**
凡例      ⚠ 最大 3 種。⚠ **現在地を必ず含める**。⚠ 残りは面積順
位置情報   ⚠ 起動直後に求めない。⚠ **押したときに求める**
標高      ⚠ **出さない**
```
