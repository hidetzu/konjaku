# 答えの区分名には、意味を 1 行そえる

- 状態: 採用
- 日付: 2026-08-22
- 関連: [0030](0030-土地の答えは確実性の高い順に3層で出す.md) §4-5 の一部を置き換える

## 決めたこと

判定カードの第1層（`この土地は 旧水部` ／ `人の手で 盛土地･埋立地 になっています`）で、
**区分名の直下に、平易な補助説明を 1 行そえる**。

```
この土地は 旧水部
  かつて水面で、その後陸地にされた土地      ← ここ
人の手で 盛土地･埋立地 になっています
  土を盛ったり、埋め立てたりした土地        ← ここ
```

| # | 決めたこと |
|---|---|
| 1 | ⚠ **押さなくても、区分名の意味が分かる** |
| 2 | ⚠ **区分名の直下に 1 行。**⚠ 答えより弱い格（`--ink-dim` の 12px） |
| 3 | ⚠ **18 字まで。**⚠ 伝えるのは**意味だけ** |
| 4 | ⚠ **答えに出うる区分は全部持つ。**⚠ 特定の区分だけを例外にしない |
| 5 | ⚠ **原典の置き換えではない。**⚠ 意味を強めたり弱めたりしない |

## なぜ

⚠ **実測（2026-08-21・利用者役 4 名・⚠ 実在の利用者ではない・画面だけを見せた）。**

```
「5 秒見て、何が分かりましたか」
  4/4 が「この土地は旧水部で、埋立地だと分かった」と答えた
  ⚠ ただし初見の 1 名だけが、見せ方の 3 案すべてで
    ⚠ 「旧水部の意味が分からない」と言った
```

⚠ **配置の話ではなく、語そのものの話だった**（3 案とも同じことが起きている）。

⚠ **説明が無かったのではない。**⚠ 「なぜそう言える？」を押すと、原典が出典つきで出ていた。
⚠ **押さないと出ない所にあった**、というだけ。

⚠ **答えの主語が読めないと、その下の写真も割合も何の話か決まらない**（掟の一行目）。

## 0030 §4-5 の、どこを置き換えるか

⚠ 0030 §4-5 は「⚠ **原典の語をそのまま出し、意味は押したときに出す**」だった。

| | 0030（2026-08-19） | ⚠ ここ（2026-08-22） |
|---|---|---|
| 区分名 | ⚠ **原典の語をそのまま出す** | ⚠ **変えない**（そのまま） |
| 意味 | 押したときに出す | ⚠ **押さずに 1 行で出す** |
| 厳密な定義・成因・災害リスク・出典 | 押したときに出す | ⚠ **変えない**（押したときに出す） |

⚠ **`もとは 水だった土地（旧水部）` へ戻したのではない**（0030 §4-3。3/4 が第2層と取り違えた）。
⚠ **区分名は原典のまま**で、⚠ **意味は別の行**に置く。⚠ 時間の語は使わない。
