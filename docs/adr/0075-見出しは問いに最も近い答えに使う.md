# 見出しは、問いに最も近い答えに使う（v0.1.0 のトップ）

- 状態: 採用
- 日付: 2026-08-31
- 範囲: **v0.1.0（`public-next/`）のトップ画面だけ。**
  **v0.1.0 の深掘り画面（`/deep`）も、β 版の `/peel` も
  [0030](0030-土地の答えは確実性の高い順に3層で出す.md) のまま**（範囲を広げない）

## 何が問題だったか

名乗りは「この土地は、昔なんだったのか？」。
それに対して、いちばん大きい字に出ていたのは **でき方**（地形分類）だった。

```
春日部   ここは、川や海が運んだ土砂でできた低い平地     ← いちばん大きい字
         明治期は 田                                     ← その下の小さい行
```

**春日部は「昔は田だった」という答えを、すでに持っていた。**
見出しでなかっただけで、データは足りていた。

豊洲だけが通っていたのは、地形分類が偶然「旧水部＝かつて水面」で、
**見出しがそのまま昔の答えになっていた**から。

## 何を測ったか

**利用者役 5 名中 3 名**が、春日部と軽井沢で「これは昔の答えではない」と読んだ
（2026-08-30。**実在の利用者ではない**）。

3 地点は、3 つの状態を代表していた（2026-08-31・375×667・暗い色み・実測）。

```
豊洲     地形分類が昔を名指す（旧水部）＋ 明治期あり（河川・湖沼・海面）
春日部   地形分類はでき方 ＋ 明治期あり（田）        ← 答えを持っていた
軽井沢   地形分類はでき方 ＋ 明治期の資料そのものが無い
```

**明治期は、地形分類の 0〜30ms 後に届いていた**（手元・実測 2026-08-31）。
見出しが明治期を待っても、待ち時間はほとんど増えない。

## 決めたこと

**順序の理由を「確実性の高さ」から「問いへの近さ」に替える。**

```
1  明治期に区分がある      明治期、ここは 田 でした
2  地形分類が昔を名指す    ここは、かつて水面で、その後陸地にされた土地
3  どちらも無い            なぜ無いかを、状態ごとに言い分ける
```

- **地形分類・成り立ちは 2 行目へ降ろす**（消さない）
- **2 の区分は 3 つだけ**（旧水部・旧河道・干拓地）。
  「切土地」「農耕平坦化地」は入れない。**前の姿を名詞で名指しておらず、
  何になったかしか言っていない**
- **3 の字は 3 通り**（[0056](<0056-データの状態を 3 つに分けて言い分ける.md>)）。**1 文にまとめない**
- **見出しには主語を書く。**「なぜそう言える？」の中では行の見出しが主語を補うが、
  見出しには補うものが無い。**同じ字を両方で使う**
- **明治期を、地形分類と同時に取りに行く。**順に取ると往復が 2 回直列になる
- 詳しい成り立ち（`landform.json` の `why`）は「なぜそう言える？」の中へ

**出典と確かさの扱いは弱めない。**順番を変えただけで、
推定を実測のように見せることはしない。名乗りも変えない。

## そうしなかったこと

- **名乗り「この土地は、昔なんだったのか？」を、答えられる範囲に合わせて言い直す**
  … [`docs/DOMAIN.md`](../DOMAIN.md)・[0064](<0064-v0.1.0 の前提を固め、保存までを範囲に入れる.md>)・
  `test/render/top-reach.mjs` など 6 か所が動く。**問いは正しい。答え方が違っていた**
- **36 区分の言い換えを「〜てできた」の形にそろえる** …
  [0030](0030-土地の答えは確実性の高い順に3層で出す.md) §4-3・§4-5 が
  「第1層で `もとは` を使わない」「時間の語を使わずに済む」と決めている。
  **`もとは 水だった土地` にしたら 3/4 が第2層（明治期）と取り違えた**という実測が根拠
  （[0031](0031-答えの区分名には意味を1行そえる.md) も同じことを言い直している）。
  時間の答えは、**明治期と名乗って見出しに出せばよい**。この決定はそれを崩さない
- **「この資料では、昔の姿までは分かりません」と 1 文でまとめる** …
  読みやすいが、**「資料が無い」「区分が無い」「読めなかった」が混ざる**（0056）
- **明治期の 14 区分に言い換えを足す** … 今回はしない。資料の語をそのまま使う
- **β 版の `/peel` も同じ順に変える** … 範囲を広げない。0030 はそちらで生きている
