# Architecture Decision Records

ここには、現在の実装を理解・変更するときに必要な恒久的な判断だけを残す。
作業記録、実測結果の控え、未採用案は置かない。現在の仕様は [`../SPEC.md`](../SPEC.md)、
再現可能な実測は検査コードとその出力を正とする。

番号は識別子であり、欠番は削除・統合した記録を再利用しないために残している。

- [0001: 取れなかったことを「無い」と言わない](0001-取れなかったを無いと言わない.md)
- [0004: 主題は成り立ち。明治期は手法のひとつ](0004-主題は成り立ちで明治期は手法のひとつ.md)
- [0007: 根拠のないことは書かず、引用には出典を添える](0007-根拠のないことは書かず断定は引用にする.md)
- [0008: 地名も座標も送らない](0008-地名も座標も送らない.md)
- [0010: 唯一の指標は共有率](0010-唯一の指標は共有率.md)
- [0011: 外部 API は止まりうる依存として扱う](0011-外部APIは止まりうる依存として扱う.md)
- [0020: 数字は主張範囲の分母で書く](0020-数字は主張範囲の分母で書く.md)
- [0021: 同じ問いに答える実装を2つ持たない](0021-同じ問いに答える実装を2つ持たない.md)
- [0028: 配信用データと計測データを分離する](0028-配信用データと計測データを分離する.md)

上記以外の ADR も採用中である。変更時は対象機能に近いファイルを確認する。
