# Architecture Decision Records

ここには、現在の実装を理解・変更するときに必要な恒久的な判断だけを残す。
作業記録、実測結果の控え、未採用案は置かない。現在の仕様は [`../SPEC.md`](../SPEC.md)、
再現可能な実測は検査コードとその出力を正とする。

番号は識別子であり、欠番は削除・統合した記録を再利用しないために残している。

## ⚠ 本文に出てくる `tmp/…` について

⚠ **Owner が書いた原文の置き場だった。**⚠ **`tmp/` は git に追跡していない。**
⚠ **上書き・削除されても誰も気づけないので、⚠ 実際に読めなくなったものがある。**

⚠ **実測（2026-08-31。⚠ 追跡ファイルからの参照を数えた）**:

```
tmp/tmp2.md              12 件が参照   ⚠ 読めない
tmp/tmp3.md               1 件が参照   ⚠ 読めない
tmp/measure-urllen.mjs    2 件が参照   ⚠ 読めない
tmp/tmp.md                2 件が参照   ⚠ 別の内容に上書きされていた
```

⚠ **決めたことは、⚠ ADR 本文が持っている。**⚠ **失われたのは原文のほう。**
⚠ **2026-09-02 に `tmp/` を片づけた。**⚠ **消す前に、⚠ 行き先を作った。**

```text
docs/ へ移した   仮想利用者レビュー          → docs/v0.1.0-仮想利用者レビュー.md
```

⚠ **これから参照する文書は、⚠ `docs/` に置く**
