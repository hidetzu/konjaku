## 決めたこと

⚠ **[`0092`](<0092-この先で土地が変わる場所を、1 地点だけ出す.md>) の 1 行が指している場所を、
⚠ 地図の上に点で示す。**⚠ **`/` だけ。**

```text

出さない  ⚠ 線 ／ ⚠ 向き ／ ⚠ 2 点以上 ／ ⚠ 字 ／ ⚠ 押せる導線
```

### ⚠ なぜ線ではなく点か

- ⚠ **線は形を主張する。**⚠ **面の縁の位置精度は公表されていない。**
  ⚠ **線を引くと「この向きに、この形で境が走っている」と形まで主張してしまう**
  （`docs/SPEC.md`「⚠ **地図の上で区分が変わる場所。**⚠ **現地の見た目が変わるとは限らない**」）
- ⚠ **`border()` が返す `deg` は足元から境目への向きで、⚠ 境界線の接線ではない。**
  ⚠ **「向きを示す短い線」は、⚠ こちらが捏造した向きになる**
- ⚠ **大きさを m で決めると、⚠ 知らない位置精度を主張する。**⚠ **だから px で決める**
- ⚠ **線は全部の境目を引くので、⚠ 画面が「区分境界図」になる。**
  ⚠ **1 行が指している 1 本と、⚠ それ以外が同じ太さで並ぶ**（⚠ 0092 の 1 地点が壊れる）
- ⚠ **閉じたリングを引くと、⚠ 読んでいない範囲の縁（タイルの切り口）まで線になる**
  （⚠ 「その外は『読んでいない』であって『無い』ではない」を、⚠ **絵が破る**）

### ⚠ なぜ細い輪か（2026-10-10。⚠ **絵を 3 案並べて Owner が選んだ**）

⚠ **実測で境目は 9〜283m・中央値 100m。**⚠ **z16 では 4.6〜146px。**
⚠ **「ここ」の印は半径およそ 22px。**⚠ **9m（4.6px）は、⚠ その内側に完全に入る。**

⚠ **塗った丸だと、⚠ 近いときに「ここ」と溶けて 1 つに見える。**
⚠ **輪なら、⚠ 重なっても両方の形が読める。**⚠ **下の面の色も隠さない。**

### ⚠ 0052 に当たらない理由（⚠ **ここを書かないとレビューで止まる**）

- ⚠ **0052 が禁じたのは「この土地そのものが昔どうだったか」をピンにすること。**
  ⚠ **この印が指すのは「区分が変わる場所」で、⚠ [`0092`](<0092-この先で土地が変わる場所を、1 地点だけ出す.md>) が別の節として既に採用している事実**

## ⚠ 作り

```text

```

⚠ **canvas に描かない。**⚠ **`drawFace` は `drawSeq`、⚠ `drawEdge` は `境目の番` と、
⚠ 別の世代印を持っている。**⚠ **同じ canvas を 2 人で書くと、⚠ どちらが最後か決まらない。**

⚠ **色は `top.css` に置く**（⚠ `--pin-ring`。⚠ **`theme.css` に 1 行も足していない**）。
⚠ **`top.js` の色は、⚠ どの検査も見ていない**（⚠ 検査は `public/` の `.css` だけを走査する）。
⚠ **canvas に描くと、⚠ そこへ 4 つ目の色が増えて、⚠ 誰も見張らない。**

⚠ **出す条件は 1 つ**: ⚠ **`#edge` が出ていて、⚠ 写真を出していないとき。**
⚠ **`#edge` の出す／出さないは `drawEdge` が決める。**⚠ **印はそれに従うだけ**（⚠ 正本を 2 つ持たない）。

⚠ **画面の外には置かない。**⚠ **`#map` は `overflow:hidden` を持っていない**ので、
⚠ **外に子を置くと横にあふれる。**⚠ **上限 600m は z16 で 309px で、⚠ 375px の半分を超えうる。**

⚠ **字を持たない。**⚠ **方角も距離も区分名も、⚠ `#edge` が字で全部言っている**
（⚠ 印に字を足すと、⚠ 同じことを 2 か所で言う）。⚠ **だから `aria-hidden`。**

## ⚠ 測れないことを承知で採る

⚠ **これがいちばん大事な断り。**

⚠ **[`0112`](<0112-成長は流入で測り、健康は率で測る.md>) の枠組みでは、⚠ この施策は落ちる側**
（⚠ 「落ちる 来た人の体験を良くする施策 ⚠ 健康が安定しているので、効果を判定できない」）。
⚠ **Owner が「少し実験をしよう」と決めたので採る。**

⚠ **判定に使う数字は「自分で場所を選んだ率」**（⚠ `npm run gate` が出す。⚠ 入口が `map` / `search` / `here`）。

```text
入れる前   32 / 79 = 40.5%   ⚠ 2026-09-06〜10-08
最小の分母 訪問 50           ⚠ docs/adr/0112
```

⚠ **ただし、⚠ 数で採否を決められない。**

- ⚠ **分母 79 訪問のうち 44 は `direct`。**⚠ **`direct` はこちらの作業と区別できない。**
  ⚠ **率の分母の半分以上が、⚠ 利用者かどうか分からない**
- ⚠ **大きく動けば読めるが、⚠ 数 % の差は読めない。**⚠ **その差を「効いた」と言わない**
- ⚠ **数で見るのは「壊していないか」だけ**（⚠ 4 率の下振れ。⚠ **損切りの網であって、⚠ 効いた証明ではない**）

⚠ **これを書いておかないと、⚠ 3 週間後に小さい分母で「効いていない」と言うことになる**
（⚠ 0112 が「踏んだ」と書いているのと同じ失敗）。
