# 0091. 狭い幅では、写真と根拠を畳んで地図を返す

- 状態: 決めた
- 日付: 2026-09-03
- ⚠ **[`0083`](<0083-初見にはトップの3手と、読み物の about の両方を持つ.md>) は維持する**
  （⚠ **3 手の帯は残す**。2026-09-03。Owner 判断）。

## 何が起きていたか

⚠ **実測（2026-09-03・`main`・375×667・春日部）。**

```text
答えの板        377px   ⚠ 画面の 57%
見える地図      130px   ⚠ 検索欄の下から、板の上まで
```

⚠ **「散歩中に数秒で答えを知る」道具なのに、⚠ 「どこの話か」を地図から読み取れない。**
⚠ **春日部は凡例が 2 段になる**ので、⚠ **豊洲より板が高い。**

## 何を決めたか

⚠ **狭い幅だけ、⚠ 立ち止まって読むものを畳む。**

```text
畳まない   答え ／ 出典（明治期の地図） ／ 2 行目（成り立ち） ／ 名乗り（どこの話か）
           保存 ／ 3 手の帯
畳む       写真の年代 ／ 「なぜそう言える？」 ／ 凡例 ／ もっと見る
```

⚠ **口は「くわしく見る ▾」。**⚠ **`<details>` で作る**（⚠ 開閉を自前で持たない）。

## ⚠ 覚えない

⚠ **開いた状態は残さない**（Owner 判断）。⚠ **場所が変わったら閉じる。**
⚠ **前の場所で開いた続きを、⚠ 次の場所に持ち込まない**
（⚠ 板の中身は場所ごとに入れ替わるので、⚠ 開いたままだと別の場所の話が伸びた状態で出る）。

## ⚠ 広い幅は変えない

⚠ **圧迫していないので畳まない。**⚠ **押す口も出さない**
（⚠ 押しても何も起きない導線を置かない。[`0026`](<0026-押しても何も起きない導線を置かない.md>)）。

## ⚠ 幅の数は 1 か所

⚠ **`700px` は CSS だけが持つ**（`.fold::before` の `content`）。
⚠ **JavaScript は `getComputedStyle` でそれを読むだけ。**
⚠ **一度 `matchMedia("(min-width:700px)")` と書いて、⚠ 静的検査に落とされている**
（`CLAUDE.md` §3。⚠ 同じ問いに答える実装を 2 つ持たない）。

## ⚠ 当てたあとの実測（2026-09-03）

```text
                        板            見える地図
春日部 375×667  前 377px(57%)  →  後 215px(32%)      130px → 292px
春日部 320×640                     215px(34%)              265px
豊洲   375×667                     215px(32%)              292px
PC     1280×800                    357px(38%)   ⚠ 畳まない  489px
```

⚠ **押すと 215 → 413px に伸び、⚠ 年代 5 つ・凡例・根拠が出る。**
⚠ **地図を動かすと 215px へ戻る。**⚠ **明るい色み・暗い色みの両方で確かめた。**

## ⚠ 落とした案

```text
案A  板を画面の下 1/3 に固定し、⚠ 引き上げて開く
     ⚠ 引き上げる操作を覚えてもらう必要がある。⚠ 押す口が字で出ない
案C  凡例だけを畳む
     ⚠ 春日部で 377 → 320px。⚠ 地図は 190px。⚠ まだ足りない
```

## ⚠ これで守れないこと

⚠ **写真の年代が、⚠ 初期表示から見えなくなる。**
⚠ **狭い幅では、⚠ 「くわしく見る」を押さないと年代を切り替えられない。**
⚠ **答えそのものは畳んでいない**ので、⚠ 掟 §1 には触れない
（⚠ **出典と 2 行目は畳まない**。⚠ **根拠を隠して答えだけ見せる形にはしない**）。

## 検査

```text
静的      `test/check/next.mjs` ㉓   ⚠ 器の中身の割り振り ／ 幅の数が 1 か所 ／ 覚えない
実描画    `test/render/next.mjs`     ⚠ 3 幅。⚠ 閉じている → 押すと開く → 場所を変えると閉じる
```

⚠ **どちらも、⚠ わざと壊して落ちることを確かめた**（⚠ 静的 7 本・実描画 7 本）。

## ⚠ 途中で踏んだこと（2026-09-03）

⚠ **既存の検査が 14 件落ちた。**⚠ **別セッションとの取り合いではなく、⚠ こちらの変更だった。**

### 1. ⚠ 畳んだ中身を、⚠ 検査が押しに行っていた（11 件）

⚠ **`.era` / `.why__sum` / `#deepLink` / `#more` が、⚠ 狭い幅では畳まれた中にある。**
⚠ **利用者と同じ手順で開く助け（`ひらく`）を足した**（⚠ 15 か所）。
⚠ **`fold.open = true` と直に書かない。**⚠ **押しても開かない形になったら、⚠ 落ちてほしい。**

### 2. ⚠ `[hidden]` を打ち消していた（1 件）

```css
.fold{display:block}   /* ⚠ class と属性は詳細度が同じ。⚠ あとに書いたほうが勝つ */
```

⚠ **`hidden` を付けても消えなかった。**⚠ **`.fold:not([hidden])` に直した。**
⚠ **既存の検査が捕まえた。**

### 3. ⚠ `checkVisibility()` は `overflow` の切り取りを見ない（1 件）

⚠ **実測（320×640・文字 20px・豊洲）。**

```text
card   238–560     ⚠ 中身 1001px（⚠ 板の中で送る）
.kick   68–112     ⚠ 板より上 ＝ ⚠ 送られて板の外へ出ている
q       65–109     ⚠ そこと矩形だけが重なる
```

⚠ **重なってはいない。**⚠ **板に切り取られていて、⚠ 画面には出ていない。**
⚠ **送る器で切ってから測る形に直した。**

⚠ **さらに、⚠ わざと本物の重なりを作ったら素通りした。**
⚠ **`position:fixed` まで切っていた**（⚠ 実際には送る器に切り取られない）。
⚠ **`fixed` と `absolute` を分けたら、⚠ 捕まえるようになった。**

```text
保存を検索窓へ fixed で重ねる    ✗ q × ☆保存
保存を板の外へ absolute で出す   ✗ q × ☆保存
そのまま                        ✓ 重なり 0
```

⚠ **`CLAUDE.md` §9 の「検査を足すときは、⚠ その主張が本当に正しいかを疑う」を、⚠ もう一度踏んだ。**

### 4. ⚠ 器ではなく結果を待つ（⚠ 手元で通り、⚠ CI で落ちた）

⚠ **`waitAnswer` のあと 1200ms 固定で待っていた。**
⚠ **手元 106/106 緑・⚠ CI で「PC で中身が出ていない」1 件。**
⚠ **PC は画面が広く、⚠ 読む枚数が多い。**⚠ **遅い側で間に合わなかった。**

⚠ **年代のチップと凡例の行が出るまで待つ形に直した。**
⚠ **確かめ方は「遅らせる」**（`CLAUDE.md` §9）:

```text
凡例を 3 秒遅らせる    ✓ 通る    ⚠ 前の 1200ms では間に合わない遅さ
凡例を出さない        ✗ 落ちる  「凡例が出ないまま 30 秒たった」
```

⚠ **落ちたときに、⚠ どれが出ていないかまで言うようにした**（年代／凡例／なぜ）。
