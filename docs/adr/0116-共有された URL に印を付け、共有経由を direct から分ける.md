# 0116. 共有された URL に印を付け、共有経由を direct から分ける

- 日付: 2026-10-10
- 状態: 採用
- 決めた人: Owner（⚠ **「他を進める」の指示のもとで AI が起案**）

## 何が起きていたか

⚠ **共有が効いたかどうかを、⚠ 読めなかった。**

⚠ **実測（2026-10-09・`npm run gate`。⚠ 全期間・訪問 96 件）**:

```text
共有を押した                10 件
場所つき URL で始まった訪問  13 件
  入口が direct            12 件   ⚠ 外から開いたのか、⚠ こちらの作業かを区別できない
  入口が外（検索・掲載）     0 件
  入口が konjaku           1 件   ⚠ サイト内の移動
判定                       ⚠ 外から開かれたかは読めない
```

### ⚠ なぜ `direct` に落ちるか

⚠ **共有された URL に、⚠ こちらの印が付いていなかった**（`public/top.js` の `shareUrl`）。

```text
出していた URL   https://konjaku.hidetzu.work/?q=…&ll=…
```

⚠ **SNS のアプリ内ブラウザは Referer を送らないことが多い。**
⚠ **印が無く Referer も無いので、⚠ `流入元()` は `direct` を返す**（`public/measure.js`）。

⚠ **`direct` は「どこからも来ていない」の意味で、⚠ `npm run gate` は成長に数えない**
（⚠ こちらの作業と区別できないため。[`0112`](<0112-成長は流入で測り、健康は率で測る.md>)）。

⚠ **つまり、⚠ 共有から来た人は、⚠ 数えられないところへ落ちていた。**

## 決めたこと

⚠ **「送る」から出た URL に `?from=share` を付ける。**⚠ **`share` を列挙に足す。**

```text
public/top.js      shareUrl() が &from=share を足す
public/measure.js  SOURCES と FROM に share
events.js          SOURCES に share（⚠ 画面と受け側がずれたら検査が落とす）
```

⚠ **`gate` の変更は要らない。**⚠ **外からの訪問は `referrer NOT IN ('direct','konjaku')` で数えており、
⚠ `share` は自動でそこに入る。**

### ⚠ handoff には付けない

⚠ **共有の口は 2 つある。**⚠ **別のもの。**

```text
public/top.js        「送る」      ⚠ 他人に場所を送る        ⚠ 印を付ける
public/saved-page.js 「リンクを作って送る」 ⚠ 自分の別の端末へ渡す  ⚠ 付けない
```

⚠ **画面自身が「このリンクは自分あてに送るもの」と言っている**（`public/saved-page.js`）。
⚠ **混ぜると、⚠ 自分の端末間の移動を「共有経由の流入」として数えてしまう。**

## ⚠ 測れないもの

⚠ **自分で「送る」を押して、⚠ 自分でその URL を開いた場合は区別できない。**
⚠ **`direct` よりは区別できている**（⚠ `?from=share` が付くのは、⚠ 誰かが「送る」を押した URL だけ）。
⚠ **実描画は URL を写すところまでしか進まない**（⚠ 開かない）ので、⚠ 検査の分は混ざらない。

⚠ **効いたかどうかは、⚠ [`0112`](<0112-成長は流入で測り、健康は率で測る.md>) の線に届くまで言わない**
（⚠ 14 日で 7 件。⚠ いま 2 件）。

## ⚠ 共有された URL が、⚠ また共有されたとき

⚠ **`?from=share` が付いた URL から来た人が、⚠ もう一度「送る」を押すと、
⚠ `shareUrl()` が同じ印を付け直す。**⚠ **2 次共有も「共有から来た」なので、⚠ 意味は変わらない。**

⚠ **一方で、⚠ 掲載先（`?from=app-village`）から来た人が共有すると、
⚠ 出て行く URL の印は `share` になる。**⚠ **元の流入元は失われる。**
⚠ **それでよい。**⚠ **その URL を開いた人は、⚠ 掲載先ではなく共有から来ている。**

## 何を見張るか

**静的**（`test/check/safety.mjs`）:

```text
?from=share が share として読まれる
Referer があっても印が勝つ（⚠ 共有先のホスト名ではなく、⚠ 共有だと読む）
画面（measure.js）と受け側（events.js）の列挙が同じ（⚠ 既存の節）
```

**実描画**（`test/render/next.mjs`「場所のリンクも、共有シートへ URL だけを渡す」）:

```text
渡す URL に共有の印が付いている
⚠ 渡すのは url だけ（⚠ 既存の主張。⚠ 題や説明を添えない）
```

⚠ **2 通りのわざと壊しで、⚠ 狙った理由で落ちることを確かめた**（2026-10-10）。

```text
共有 URL から印を外す      → ✗ 実描画「渡した URL に共有の印が無い」
印を share として読まない   → ✗ 静的（2 件）
```
