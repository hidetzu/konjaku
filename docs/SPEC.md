# 今昔 — 仕様

いま何ができて、何をどこまで言えるか。判断の経緯は `docs/adr/` にある。

---

## 1. 何をするサービスか

場所を指すと、**その土地が昔なんだったか**を国土地理院の資料から判定し、
読んだ資料を根拠として画面に出す。
Google マップが「いまそこに何があるか」に答えるのに対し、これは「そこがどういう土地なのか」に答える。

**判定はブラウザが実行時に画素を読んで行う。** サーバは 2 つの口しか持たない（§6）。

## 3. 主張と、その裏づけ

この文書の核心。**ここに無いことは、画面でも言わない。**

| 何を言っているか | 何を根拠にしているか | どこまで言えるか |
|---|---|---|
| **ここは ○○ でした**（明治期） | 明治期の低湿地タイルの画素 rgba を直読み。凡例 `lw_legend.pdf` の **14 区分**（うち水域は 2 つ＝干潟・砂浜 / 河川・湖沼・海面）。参照タイルURLと画素の位置を画面に出す | 整備は全国主要都市周辺のみ。凡例に「かなりの位置誤差を含む」とあるため、**街区単位まで**。⚠ **いつ陸になったかは、この資料からは分からない** |
| **いまの地形は ○○** | 地形分類ベクトルタイル（地理院・提供実験）の図式コードを直読み。**36 区分**。成因・災害リスクの文は**国土地理院の記述をそのまま**使い、こちらで書かない | 詳細版（z16）が無い土地は広域版（z13）に落ち、画面に「（広い区分）」と書く |
| **いまの標高は N m** | `dem5a`（5mメッシュ）を直読み。数値そのもの | 読めた地点だけ。読めなければ何も言わない。⚠ **まわりの高さではない**（1 点の値） |
| **残っている空中写真は N 年代** | タイルの実在＋「写っているか」の空白判定（明>250 かつ σ<1 は空白） | 7年代（1936–42 / 1945–50 / 1961–69 / 1974–78 / 1979–83 / 1984–86 / 1987–90）＋現在 |
| **この一帯は、明治期にこうでした** | 約 1.2km × 0.8km の範囲で画素を数える | ⚠ **点ではなく面。**⚠ **分母を必ず添える**（数えられなかった透明の画素があるため）。⚠ **1% に満たない区分は出さない** |
| **この近くに残る災害の記録** | 国土地理院「自然災害伝承碑」。⚠ **配っているのは z8 タイル 58 枚・2,469 件**。災害名・種別・碑文は**出典の字のまま** | ⚠ **半径 5.0km 以内・最大 3 件。**⚠ **碑があることと、その地点が被災したことは別**（画面がそう言う）。⚠ **深掘りでだけ出す**（`docs/adr/0076`。⚠ 実測で半径 1km では 15 地点中 0 件だった） |
| **この先で、土地が変わる**（1 地点だけ） | 地形分類ベクトルタイル（z16）の面の縁。⚠ **足元と違う区分の面までの最短距離と方角**。⚠ **新しいデータは作っていない** | ⚠ **地図の上で区分が変わる場所。**⚠ **現地の見た目が変わるとは限らない。**⚠ **上限 600m・読むのは 3×3 タイルまで。**⚠ **その外は「読んでいない」であって「無い」ではない。**⚠ **止まった理由は分けない。**⚠ **出せない土地では節ごと出さない**（`docs/adr/0092`） |
| **この地域について、資料にこう書かれている** | 東京都港湾局「東京港の歴史」／浦安市「浦安市の海面埋め立て」から写した **2 範囲・17 件** | ⚠ **地点の記録ではない。**⚠ **原典に座標が無く、範囲の矩形はこちらが引いたもの。**⚠ **「この場所がいつ陸になったか」は、これでも分からない** |

**言わないと決めているもの**（測って、出せなかった）:

- 「いつ陸になったか／いつ埋め立てられたか」… 空中写真の輝度・分散・彩度では**水陸すら分離しない**（皇居の森 明24.1 が東京湾 明85.7 より暗い）
- 「この土地が大きく変わったのは1960〜70年代です」… 連続する2年代の正規化相互相関では、**変わった土地と対照が重なる**（対照の最大 0.94 が、変わった土地の大半の区間を上回る）
- 確率・確信度… 根拠の無い数値は「検証器の顔をした生成」になる

⚠ **β 版が持っていた主張は、⚠ v0.1.0 では言わない**（⚠ 建物ごとの足元・建物の高さ・建設年・年代の分かる事物）。
⚠ **データも機能も運んでいないので、⚠ 画面のどこにも出ない。**

## 5. 掟

1. **取れなかったことを「無い」と言わない。** 取得結果は `ok` / `absent`（**404 だけ**＝本当に無い）/ `unreachable`（通信断・8秒のタイムアウト・**403 などの拒否**・5xx）の3状態。`unreachable` のときは断定せず、根拠UIも出さず、再試行を出す。
   ⚠ **403 を `absent` に入れない。** 拒まれたのは「見せてもらえなかった」であって「無い」ではない。
   実測（2026-08-16 / 5地点 × 6経路 = 30本）では、不在の応答は全部 404 で 403 は 0 本だった
2. **索引は「見た範囲」であって「1件でも入った範囲」ではない。** 見ていない区画について何も言わない
3. **出すのは実測値そのものと、その取り方と、既知の限界だけ。** 確率は出さない。断定ではなく引用のときは出典を必ず添え、要約しない
4. **数字は必ず主張範囲の分母で書く。** 別の範囲の数字を持ち込むと、その数字自体が嘘になる
5. **利用状況の計測には、地名も座標も送らない。** Cookie も識別子も使わない。Referer も止めてある。
   ⚠ IP は保存せず、利用者の識別にも使わない（基盤（Cloudflare）が接続元 IP を扱うことは避けられない）
   ⚠ **主語は「計測」。** 調べた場所は **URL に載る**（戻る・共有するため）。その URL を開けば、
   アドレスの一部として**配信元（Cloudflare）には届く**。以前この掟を主語なしで書いていたため、
   画面に「こちらのサーバーには送りません」と**事実でないこと**が出ていた（2026-08-15 に実測して修正）
6. **同じ問いに答える実装を2つ持たない。** やむを得ず持つときは、機械で突き合わせる
7. **押しても何も起きない導線を置かない**

これらは人の目に頼らず、`npm run check`（静的）と `npm run render`（実描画）で見る。
⚠ **件数はここに書かない**（2026-08-22。⚠ **走らせた結果が正**）。
⚠ **数は走者が出力する。**`check.mjs` は `✓` を数え、`render.mjs` はケース数を数えて、⚠ **その場で名乗る。**
⚠ **理由**: 検査を 1 件足すたびにこの行を手で書き換えることになり、
⚠ **良い変更を並行して 2 本走らせると必ず競合した**（2026-08-22 に同じ日で 3 回）。
⚠ **競合中は CI が走らない**ので、⚠ 「CI が出ない」という形で詰まる。
⚠ **書き戻せないよう、静的検査が見張っている**（⚠ 件数を書くと落ちる）。

⚠ **画面の寸法（`px`・`y=`）も、ここに書かない**（2026-08-22）。
⚠ **理由は件数と違う。**⚠ **競合ではなく、⚠ 黙って古くなる。**
⚠ **実際に古くなった**: hidetzu/konjaku#194 が年代の箱と畳むボタンを消したのに、
⚠ この文書は「年代の箱の頭は細く保つ／開閉は記号だけ」と言い続けていた
（⚠ 4 幅で測ったところ、⚠ **どの幅にも存在しなかった**）。
⚠ **消すのは数字であって、主張ではない**（掟 §1）。⚠ 「1 行に収める」「刻みは的にしない」は残す。
⚠ **いまの姿は検査が持ち、⚠ 経緯は `docs/adr/` と Issue が持つ。**
⚠ **`44×44` は寸法ではなく決まり**なので、⚠ `px` を付けずに書く。
⚠ **これも静的検査が見張っている**（⚠ 寸法を書くと落ちる）。

⚠ **配っているデータの件数は、ここに書く**（⚠ 掟 4 が分母を求めるため）。
⚠ **ただし静的検査が現物と突き合わせる**（⚠ 違うと落ちる。掟 6）。
⚠ **取り込み直したら、⚠ この文書も直す。**
`render` は通信を落とした状態と、**403（拒否）を返された状態**で「整備対象外」「データが無い」と
断定しないことまで確かめる。
⚠ 実描画は 2 群に分かれている。`--group=core`（外へ検索に出ない）と
`--group=search`（地理院の住所検索が返らないと成立しない）。
CI は両方を回す。**core が落ちたら外部のせいにできない**＝こちらの不具合。
search 群だけ 1 回やり直す（やり直した回数は必ず出力する）。
実測（2026-08-17）: 住所検索の応答は速いとき 0.4 秒・遅いとき **8.2 秒**。
アプリは 8 秒で中断する（上の掟1）ので、遅い回は**アプリが正しく中断したのに検査だけが落ちる**。
検索の並びは `npm run check-search`（**42語**）で見る。

## 6. サーバが持つ 2 つの口

⚠ **`worker.js` が本番の入口**（2026-09-01。`docs/adr/0080`）。
⚠ **静的アセットに一致する要求では起動しない。**⚠ **ページの表示は素の配信。**

### `/api/handoff*` — 合言葉で荷物を手渡す

⚠ **これが、⚠ v0.2.0 で唯一こちらへ何かを送る道。**
⚠ **利用者が自分で「PC やタブレットでも見る」を押したときだけ。**

- 預けるのは、保存した場所（緯度・経度・町名・足元の区分・保存した時刻）
- ⚠ **合言葉そのものは預からない**（照合するための別の字に変えて持つ）
- ⚠ **期限を過ぎると合言葉は使えなくなる。**⚠ **ただし、⚠ その時点で消えることは保証しない**
  （⚠ 掃除は預かるときのついでで、⚠ 上限つき。`docs/sync-api.md` §4）
- 詳しくは [`docs/sync-api.md`](sync-api.md)

### `/t` — 計測（⚠ **いまは誰も叩いていない**）

⚠ **口は生きているが、⚠ v0.1.0 の画面は 1 件も送っていない**（2026-09-01 実測）。
⚠ **β 版の画面が叩いていたもので、⚠ v0.1.0 へは運んでいない。**

⚠ **画面は「誰がどこを見たかは、数えていません」と書いている**（`/privacy`）。⚠ **これは正しい。**

⚠ **だから `docs/adr/0047`（判定が 100 件たまるまで共有率を読まない）は、
⚠ いまの形では条件を満たさない。**⚠ **数えるかどうかは、⚠ 改めて決める。**
⚠ **決めるまで、⚠ 「計測している」と書かない。**

⚠ **口の仕様そのものは変えていない**（⚠ 固定文字列だけ・48 バイトまで・
Origin が自分でないものは 204 で落とす・D1 に日ごとの件数を 1 行）。

⚠ **実行時に話す相手は、⚠ 国土地理院だけ**（2026-09-01。⚠ β 版が話していた
