# JavaScript

⚠ **`MUST` = 必須、`SHOULD` = 原則、`MAY` = 任意。**

## 責務

```text
取得  →  Domain へ変換  →  表示用へ変換  →  描く
```

- MUST: ⚠ **1 つの関数は、このどれか 1 つを主にする。**
- MUST: ⚠ **外部データの生値を、そのまま画面のコードへ流さない。**
- MUST: ⚠ **表示の文言を Domain のデータへ混ぜない。**
- SHOULD: ⚠ **DOM も地図も持たない形に切り出す**（⚠ **Node から呼べると、検査がブラウザ抜きで回せる**）。

⚠ **この repo には、その形が既に 7 つある**: `photos.js` / `words.js` / `prov.js` /
`swale.js` / `ground.js` / `land.js` / `verify.js`。⚠ **新しく切り出すときは、⚠ これに倣う。**

## DOM

- SHOULD: JavaScript だけが使う目印は `data-*`。
- SHOULD: `id` は ⚠ **本当に 1 つしかない要素**に限る。
- MUST NOT: ⚠ **状態管理のためだけに class を増やさない。**
- MUST NOT: ⚠ **同じ要素へ、複数の場所からイベントを足さない。**

## 状態

- MUST: ⚠ **同じ意味の状態を、変数と DOM 属性の 2 か所に持たない。**
- MUST: ⚠ **表示の状態と Domain の状態を混ぜない。**
- SHOULD: ⚠ **正本を 1 つ決める**（URL・選んだ場所・いまの年代）。

## 命名

- MUST: 関数名は ⚠ **動作**を表す。
- MUST: 真偽値は `is` / `has` / `can` / `should`。
- AVOID: `data1` / `tmp` / `obj` / `info2` / `flag1`。
- SHOULD: ⚠ **行数ではなく、⚠ 責務が混ざっているか**で分ける。

## 欠損・失敗

- MUST: ⚠ **「無い」と「取れなかった」を区別する**（正本は `CLAUDE.md` §1）。
- MUST: ⚠ **補助データが 1 つ取れないだけで、画面全体を止めない。**
- MUST: ⚠ **例外を握りつぶさない。**⚠ 追える形で残す。

## 非同期

⚠ **観点の正本は [`change-review`](../skills/change-review/SKILL.md) §4。**⚠ ここでは繰り返さない。

- MUST: ⚠ **古い結果で、いまの画面を上書きしない。**
- MUST: ⚠ **始まり・成功・空・失敗を必要に応じて分ける。**

## 変える前に

- MUST: ⚠ **呼び出し元と依存先を見る。**
- MUST: ⚠ **「ついでのリファクタ」で範囲を広げない**（正本は `CLAUDE.md` §7）。
