# Component

⚠ **`MUST` = 必須、`SHOULD` = 原則、`MAY` = 任意。**

⚠ **ここが持つのは、`public/components/` の下に置くものの境界だけ。**
⚠ **責務の分け方・命名・非同期は [`javascript.md`](javascript.md)、class と Token は [`css.md`](css.md) が正本。**
⚠ **ここには書き写さない。**

## ⚠ これは何のためにあるか

⚠ **`javascript.md` は「DOM も地図も持たない形に切り出す」を `SHOULD` にしている。**
⚠ **`MUST` ではない。**⚠ だから ⚠ **DOM を所有する UI 部品を認めても矛盾しない。**

⚠ **認めるかわりに、条件を強くする**（2026-08-22。Owner 判断）。
⚠ **条件を満たせないものは、⚠ `components/` に置かない。**

## ⚠ 何を単位にするか

- MUST: ⚠ **画面の上の箱ではなく、⚠ 責務で切る。**
- MUST: ⚠ **「この部品は何をするか」を 1 文で言えること。**言えないなら切り方が違う。
- AVOID: ⚠ **`Hud` / `Panel` / `Footer` のような、⚠ 置き場所の名前。**

⚠ **実例**: hidetzu/konjaku#171 は、⚠ **`HUD` ではなく「年代の表示と操作」に境界を置いた**
（`EraControlPanel`）。⚠ 同じ HUD の中にあった補足や答えは、⚠ **一緒に運ばなかった。**

## ⚠ 満たすこと（4 つ）

```text
1  自分の root 配下の DOM だけ持つ
2  Domain の状態を所有しない
3  MapLibre / URL / fetch を直接触らない
4  入力 = update(state) ／ 出力 = callback（⚠ 一方向）
```

- MUST: ⚠ **`document.getElementById` を使わない。**⚠ **`root` の中から引く。**
- MUST: ⚠ **正本は画面が持つ**（いまの年代・選んだ場所・URL）。⚠ 部品は ⚠ **渡されたものを描くだけ。**
- MUST: ⚠ **取りに行かない。**⚠ 整備の有無・幅の判断・開いているかも、⚠ **画面から受け取る。**
- MUST NOT: ⚠ **部品の中で `input` を投げて、⚠ 自分の変更を自分で拾い直さない**（⚠ 環になる）。
- MUST: ⚠ **字を決めない。**⚠ 文言は `public/words.js` / `public/prov.js` が持つ（`domain.md`）。

## ⚠ 置き方

```text
public/components/<name>/<name>.js      globalThis.create<Name>
public/components/<name>/<name>.css
```

- MUST: ⚠ **`public/sw.js` の SHELL に両方入れる。**
  ⚠ 動的キャッシュの規則は ⚠ **直下の `.js` しか一致しない**（`/^\/[\w.-]+\.js$/`）。
  ⚠ **入れ忘れると、オフラインでその部品だけ出ない。**
- MUST: ⚠ **外の最上位宣言に頼らない。**⚠ classic script は最上位の `const` を共有するので、
  ⚠ **実物のページでは動いてしまう**（⚠ hidetzu/konjaku#171 で `esc` が実際にそうだった。⚠ **単体で開いて初めて落ちた**）。
- MUST: ⚠ **外の reset に頼らない。**⚠ `box-sizing` も同じ形で踏んでいる
  （⚠ hidetzu/konjaku#171: 単体だとノブが 6px ずれ、⚠ **真ん中を押しただけで値が動いた**）。

## ⚠ 検査

- MUST: ⚠ **部品だけを、⚠ 地図もネットも無しで開く検査を持つ。**
  ⚠ **切り出しただけでは境界は保証されない。**⚠ 上の 2 つは、⚠ **これでしか見つからなかった。**
- MUST: ⚠ **境界を静的検査でも見る**（禁じる語・触ってよい id）。
- MUST NOT: ⚠ **部品の内部状態（`slider.value` など）を、検査の的にしない。**
  ⚠ **見るのは、⚠ 部品が返す値のほう**（⚠ hidetzu/konjaku#171: `#t.value` を見ていた 4 ケースは、
  ⚠ **返す処理を丸ごと消しても緑のままだった**）。

⚠ **実測（2026-08-22・`main` = `ffe53ca`）**: 地図を立ち上げる検査は 1 件 10〜30 秒。
⚠ **部品単体は 95ms・引いた URL 5 本・地図 0 本。**

## ⚠ 移すとき

- MUST: ⚠ **見た目を変えない。**⚠ 規則の順もコメントもそのまま運ぶ。
- MUST: ⚠ **「ついでの改名」「ついでの統一」を混ぜない**（正本は `CLAUDE.md` §7）。
- MUST: ⚠ **既存の `#id` セレクタを、⚠ 移設と同時に class へ寄せない**（`css.md`）。
