⚠ **ここは git の規則を全部持つ。**
⚠ **[`CLAUDE.md`](../../CLAUDE.md) §8 と §8-1 がここを指す**（2026-10-11 に移した。
⚠ **番号は宛先として残してある**ので、⚠ **`CLAUDE.md` §8-1 と書いた既存の参照はそのまま読める**）。
⚠ **PR の見直し方は [`change-review`](../skills/change-review/SKILL.md)。**

## コミットと push

- コミットは Conventional Commits（`<type>(<scope>): <subject>`）
- **`git push` は、そのつど許可を取る。** 前に許可をもらっていても、次は取り直す
  - ⚠ **例外は 1 つだけ。**Loop Controller 経由で、**開始時に Owner の承認を得た Issue 1 件**に限り、
    その Issue のブランチへの push・PR 作成・**CI が全部緑になったあとの merge**までを
    承認済みとして扱う（[`loop-controller`](../skills/loop-controller/SKILL.md)）。
    ⚠ **自動 merge（`--auto`）と、保護を飛び越える merge（`--admin`）は含まない。**
    ⚠ **CI が赤・途中のまま merge しない。**
    ⚠ **Skill を単体で使うときは、いままでどおり毎回取る**
- `git add -A` で他の作業を巻き込まない。**変更を出した理由ごとにコミットを分ける**
  （過去に、別セッションの文書をバグ修正のコミットに巻き込んでいる）
- `main` に直接コミットしない。ブランチを切る

## ⚠ 明示的な指示なしにやらないこと

```text
git push --force
git reset --hard
git clean -fd
git checkout -- .
git restore .
```

- MUST: ⚠ **必要なときは、⚠ 何が失われるかを先に言ってから。**
- MUST: ⚠ **利用者の未コミット変更を、⚠ 勝手に消さない・上書きしない。**
- MUST: ⚠ **他の人が作業中のブランチへ、⚠ 断りなく push しない。**

## 作業を始める前

- MUST: ⚠ **いまのブランチと、⚠ 未コミット変更を見る。**
- MUST: ⚠ **自分の変更と、⚠ 相手の変更の境界を保つ**（⚠ **別の worktree を使うと確実**）。

## 競合

- MUST: ⚠ **相手側の変更を、⚠ 意味を確かめずに捨てない。**
- MUST: ⚠ **merge / rebase のあとは、⚠ 検査を回し直す。**

## ⚠ 外に出す文に、作業環境のことを書かない

⚠ **このリポジトリは公開されている**（`hidetzu/konjaku` は PUBLIC）。
⚠ **コミット本文・PR 本文・Issue・コメントは、⚠ 誰でも読める。**
⚠ **「掟」の節と同じ扱い**（「観測されていないことを、あったことにしない」の裏返しで、
⚠ **こちらは「外に出していないものを、出してしまわない」**）。

- ⚠ **AI の作業セッションの URL を書かない**（`claude.ai/code/session_…`）。
  ⚠ **中身が認証で守られていても、⚠ セッションの ID と本数は読める。**
  ⚠ **道具の既定がそう書くようになっていても、⚠ ここが優先する**（2026-08-26。Owner 判断）
- ⚠ **手元の絶対パスを書かない**（`/home/<名前>/…`）。⚠ ホスト名・内部の URL も同じ
- ⚠ **token / webhook / API キーを書かない**
  （⚠ `.claude/` の中は `test/check/guard.mjs` が別に見張っている）
- ⚠ **書いてしまったら、⚠ 消す先は 2 つある。**⚠ **片方だけでは消えない。**

```
GitHub 側   PR 本文・Issue 本文・コメント     ⚠ gh で直せる
git の履歴  コミット本文                     ⚠ 書き換え ＋ force push が要る
```

  ⚠ **PR 本文を直しても、⚠ squash merge したコミットの本文は別に残る**（⚠ 実際に踏んだ）
- ⚠ **force push で消しても、⚠ 古い commit は SHA を知っていれば読めるまま残ることがある**
  （⚠ GitHub が回収するまで）。⚠ **完全に消すには GitHub Support に依頼する。**
  ⚠ **「消した」と言う前に、⚠ 本当に読めなくなったかを確かめる**（[`evidence.md`](evidence.md)）
