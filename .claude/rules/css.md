# CSS

⚠ **`MUST` = 必須、`SHOULD` = 原則、`MAY` = 任意。**

## ⚠ どこから適用するか（⚠ **これを先に読む**）

⚠ **新しく作るものから適用する**（2026-08-22。Owner 判断）。

```text
既存の CSS には #id セレクタが多数ある。
一括移行せず、⚠ 触った範囲から class へ寄せる。
```

⚠ **既存はこの形で組まれている。**⚠ **一括で書き換えない。**
⚠ **触るときに、その範囲だけ寄せる。**⚠ **「ついでの改名」で範囲を広げない。**

⚠ **ここに件数を書かない**（2026-08-22。Owner 判断）。
⚠ **以前は「`peel.html` 130 か所」と書いてあったが、⚠ 数え方が定義されていなかった。**
⚠ **再現できない数字を規則の本文に置かない**（`CLAUDE.md` §6）。
⚠ どうしても数字が要るなら、⚠ **先に数え方をコードにしてから**書く。

## class

⚠ **新しく作るコンポーネントは、BEM に近い形。**

```text
component
component__element
component--modifier
```

- MUST: 名前は ⚠ **役割**を表す（見た目ではない）。
- AVOID: `.box` / `.area` / `.big` / `.small` / `.left` / `.right` / `.text1` / `.panel2`。
- SHOULD: 状態は modifier で表す。

## セレクタ

- MUST: ⚠ **新しい CSS で `#id` セレクタを使わない**（⚠ 既存は上のとおり）。
  ⚠ **逐語で移しただけのファイルは「新しい CSS」ではない**（[`components.md`](components.md)）。
  ⚠ **移設と改名を同時にやらない。**⚠ **その旨をファイルの冒頭に書く。**
- MUST NOT: ⚠ **CSS のためだけに `id` を足さない。**
- SHOULD: `id` は ⚠ **一意の識別・`aria-*` の紐づけ・アンカー**に限る。
- MUST NOT: 理由なく `!important` を足さない。
- MUST: 既存の `!important` を消すときは、⚠ **何を上書きしていたか**を確かめる。

## Token

- SHOULD: ⚠ **複数の画面で意味が共有される値だけ**をグローバルにする。
- SHOULD: 1 つのコンポーネント専用の値は、⚠ **その中へ閉じる。**
- MUST: ⚠ **値ではなく意味で名づける**（`--space-sm`。`--8px` ではない）。
- MUST: ⚠ **`--pad-sm` / `--pad-md` に在る値を、⚠ 規則へ直に書かない**（⚠ 検査が落とす）。
- MUST NOT: ⚠ **`padding` の段を増やさない。**⚠ **箱の内側は段にしないと決めてある**
  （[`docs/adr/0041`](../../docs/adr/0041-余白は縦の間だけ段にし、箱の内側は段にしない.md)）。
  ⚠ **測った結果、⚠ 揃える根拠が無かった**（⚠ 縦の値が 13 種でほぼ平坦。⚠ 揃えると最大 13px 動く）。
  ⚠ **`--pad-sm` / `--pad-md` は「くり返されていた 2 つ」だけ**で、⚠ 尺度ではない。
- MUST: ⚠ **余白の段は `rem`**（`--gap-*` / `--pad-*`）。⚠ **文字サイズ設定に追いてこさせる。**
  ⚠ **`--tap` だけは `px`。**⚠ **指の大きさは文字設定と連動しない**
  （⚠ 実測: `2.75rem` だと文字 12px の人で **33px**。⚠ 下の 44px の MUST を割る）。
- MUST: ⚠ **縦の間は、⚠ 役割の段から選ぶ**（`--gap-sub` / `--gap-row` / `--gap-block`）。
  ⚠ **段に無い値を書かない**（⚠ 検査が落とす）。
  ⚠ **段に無い値が要るなら、⚠ それは段のほうを見直す合図**（hidetzu/konjaku#312 の Owner Decisions）。
  ⚠ **決めた上で残すものは、⚠ 検査の一覧に理由と一緒に書く。**
- SHOULD: ⚠ **役割の名前は、⚠ 同じ意味のものが 2 つ現れてから足す**
  （[`domain.md`](domain.md)）。⚠ **段（大きさ）と役割（意味）を分ける**
  — ⚠ 文字が `--text-*` → `--fs-*` でそうしているのと同じ形。

## 色

⚠ **経緯は [`docs/adr/0039`](../../docs/adr/0039-色を1か所に集め、色みを定義だけ置く.md)。**⚠ ここには書き写さない。

- MUST: ⚠ **色の値は `public/css/theme.css` にしか書かない。**
  ⚠ **2 か所に持つと、⚠ 色みを足したとき片方だけ切り替わる。**
- MUST: ⚠ **意味を持つ色の「濃さ違い」を、⚠ 規則へ直に書かない。**
  ⚠ **その色から作る**: `color-mix(in srgb, var(--evidence) 9%, transparent)`。
  ⚠ **`in srgb` と `transparent` の形でだけ、⚠ 元の `rgba()` と同じ画素になる**
  （⚠ `in oklab` にすると値が変わる）。
  ⚠ **直書きすると落ちない。**⚠ **色みを変えたとき、⚠ その帯だけ前の色のまま残る。**
- MUST: ⚠ **これは検査が見ている**（`test/check/color.mjs`）。⚠ **決めた上で残すものは、
  ⚠ そこの一覧に理由と一緒に書く。**
- MUST: ⚠ **面や枠を「起こす」ための白は `--wash`、⚠ 影とスクリムは `--shadow`。**
  ⚠ **`--wash` は色みで反転する**（暗い色みでは白、明るい色みでは暗い側）。
  ⚠ **`--shadow` は反転しない**（⚠ 明るい色みでも影は暗い）。
  ⚠ **どちらも単独では使わない。**⚠ 必ず濃さを指定して使う。
- MUST NOT: ⚠ **`mask-image` の中の色を、⚠ 色みへ寄せない。**
  ⚠ **あれは色ではなく「隠す／出す」の指定**（⚠ 検査も、そこは見ていない）。
- MUST: ⚠ **「その色の帯の上で読む文字」は `--<色>-ink`**（`--estimate-ink` `--water-ink` ほか）。
  ⚠ **`--ink` を流用しない。**⚠ 乗る相手が違う。
- MUST: ⚠ **`--action` の上に載る文字は `--action-ink`。**⚠ **色みで反転する。**
  ⚠ **地に対して測っても意味がない**ので、⚠ **検査は乗る相手に対して測っている。**
- MUST: ⚠ **文字の灰は、⚠ 段から選ぶ**（強い順）。⚠ **新しい中間色を作らない。**

  ```text
  --ink  >  --ink-2  >  --ink-3  >  --ink-dim  >  --ink-faint  >  --ink-ghost
  ```

  ⚠ **`--ink-ghost` は文字として読ませない**（⚠ 区切りの点。⚠ **ここに文を入れない**）。
- MUST: ⚠ **面は `--bg` / `--surface` / `--surface-2` の 3 段。**
  ⚠ **`--surface-2` は「もう一段」**（⚠ 暗い色みでは明るい側、⚠ 明るい色みでは沈む側）。
- MUST: ⚠ **色みは `@media (prefers-color-scheme: light)` の 1 か所に書く。**
  ⚠ **`[data-theme]` を併記しない**（⚠ 同じ値が 2 か所になる）。経緯は
  [`docs/adr/0040`](../../docs/adr/0040-色みは端末の設定に従い、選ぶ操作は後回しにする.md)。
- MUST: ⚠ **`theme-color`（ブラウザの枠の色）は、⚠ 色みごとに `media` を付ける。**
  ⚠ **1 行だけだと、⚠ 明るい端末で枠だけ暗いまま残る。**⚠ 値は検査が `--bg` と突き合わせる。
- MUST NOT: ⚠ **半透明のトークンに `color-mix` を掛けない。**⚠ **透明度が掛け算になる。**
  ⚠ 実測（2026-08-26。⚠ 実際に踏んだ）: `/peel` の `--surface` は `rgba(12,16,22,.84)` で、
  ⚠ `color-mix(… 82%, transparent)` にしたら ⚠ **0.84 × 0.82 = 0.688** になった。

## レスポンシブ

- MUST: PC とスマホで同じ概念なら、⚠ **同じ名前**を使う。
- SHOULD: `.foo-pc` / `.foo-sp` を作らず、⚠ **media query で差を出す。**
- MUST: ⚠ **押せるものは 44×44 を割らない**（測り方は [`ui-ux-review`](../skills/ui-ux-review/SKILL.md) §3）。
- MUST NOT: ⚠ **レスポンシブのためだけに、⚠ 同じ責務の DOM を 2 つ持たない。**

⚠ **この画面は「狭い幅が既定」**（広い幅だけ `@media(min-width:681px)` で足す）。
⚠ **既定に書いたものは PC にも効く。**⚠ **PC 側で打ち消し忘れると消える**
（2026-08-22 に実際に踏んだ。⚠ 補足が PC で 0×0 になった）。

## 変えるとき

- MUST: ⚠ **対象と無関係な CSS を一括整形・一括改名しない。**
- MUST: ⚠ **JavaScript が参照している `id` / class を変える前に、⚠ 参照箇所を見る。**
